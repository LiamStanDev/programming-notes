## 1. 智能指針概述

### 1.1 為什麼需要智能指針?

**手動記憶體管理的問題**:

```cpp
// ❌ 手動管理 (容易出錯)
void bad_example() {
    int* p = new int(42);
    process(p);
    delete p;  // 如果 process 拋出異常,不會執行!
}

// ❌ 記憶體洩漏
void memory_leak() {
    int* p = new int(42);
    if (error_condition) {
        return;  // 忘記 delete!
    }
    delete p;
}

// ❌ 懸空指針
void dangling_pointer() {
    int* p = new int(42);
    delete p;
    *p = 10;  // UB! Use-after-free
}

// ❌ 雙重釋放
void double_free() {
    int* p = new int(42);
    delete p;
    delete p;  // UB! Double-free
}
```

**智能指針的解決方案**:

```cpp
// ✅ RAII (自動管理)
void good_example() {
    auto p = std::make_unique<int>(42);
    process(p.get());
    // 離開作用域自動釋放,即使異常
}
```

### 1.2 智能指針類型對比

| 指針類型          | 所有權     | 開銷     | 執行緒安全 | 適用場景          |
| ----------------- | ---------- | -------- | ---------- | ----------------- |
| `std::unique_ptr` | 唯一所有權 | 零開銷   | N/A        | 默認選擇,獨佔資源 |
| `std::shared_ptr` | 共享所有權 | 原子計數 | 計數安全   | 多個所有者        |
| `std::weak_ptr`   | 非所有權   | 無       | 觀察安全   | 打破循環引用      |
| 原始指針 (`T*`)   | 借用       | 零開銷   | N/A        | 觀察者,不負責釋放 |

## 2. unique_ptr - 獨占所有權

### 2.1 基本用法

```cpp
#include <memory>

// 創建方式
auto p1 = std::make_unique<int>(42);  // C++14 (推薦)
std::unique_ptr<int> p2(new int(42)); // C++11

// 訪問
*p1 = 10;
int value = *p1;

// 獲取裸指針 (不轉移所有權)
int* raw = p1.get();

// 移動 (轉移所有權)
auto p3 = std::move(p1);  // p1 變為 nullptr
// *p1;  // Error! p1 已無效

// 釋放並獲取裸指針
int* raw2 = p3.release();  // p3 變為 nullptr,不會 delete
delete raw2;  // 需手動刪除

// 重置
p3.reset(new int(100));  // 刪除舊值,持有新值
p3.reset();  // 刪除並變為 nullptr

// 檢查是否為空
if (p3) {
    // p3 非空
}
```

### 2.2 數組版本

```cpp
// 動態數組
auto arr = std::make_unique<int[]>(10);  // C++14
arr[0] = 42;
arr[9] = 100;

// 自動調用 delete[]

// ⚠️ 注意: unique_ptr<T[]> 不支持 * 和 -> 運算符
// int x = *arr;  // Error!
int x = arr[0];  // OK
```

### 2.3 自定義刪除器

```cpp
// 文件描述符管理
auto fd_deleter = [](int* pfd) {
    if (pfd && *pfd >= 0) {
        ::close(*pfd);
        std::cout << "Closed fd: " << *pfd << "\n";
    }
    delete pfd;
};

std::unique_ptr<int, decltype(fd_deleter)>
    fd_ptr(new int(::open("file.txt", O_RDONLY)), fd_deleter);

// 使用函數對象
struct FileDeleter {
    void operator()(FILE* fp) const {
        if (fp) {
            std::fclose(fp);
            std::cout << "Closed file\n";
        }
    }
};

std::unique_ptr<FILE, FileDeleter>
    file_ptr(std::fopen("data.txt", "r"));

// C 資源管理
struct MallocDeleter {
    void operator()(void* ptr) const {
        std::free(ptr);
    }
};

std::unique_ptr<char, MallocDeleter>
    buffer(static_cast<char*>(std::malloc(1024)));
```

### 2.4 工廠函數模式

```cpp
class Widget {
public:
    virtual ~Widget() = default;
    virtual void draw() = 0;
};

class Button : public Widget {
public:
    void draw() override { /* ... */ }
};

class TextBox : public Widget {
public:
    void draw() override { /* ... */ }
};

// ✅ 工廠函數返回 unique_ptr
std::unique_ptr<Widget> create_widget(const std::string& type) {
    if (type == "button") {
        return std::make_unique<Button>();
    } else if (type == "textbox") {
        return std::make_unique<TextBox>();
    }
    return nullptr;
}

// 使用
auto widget = create_widget("button");
if (widget) {
    widget->draw();
}
```

### 2.5 性能特性

```cpp
// unique_ptr 是零開銷抽象
static_assert(sizeof(std::unique_ptr<int>) == sizeof(int*));

// 編譯後與裸指針等價
void process_raw(int* p) {
    delete p;
}

void process_unique(std::unique_ptr<int> p) {
    // 自動 delete
}

// 生成的機器碼幾乎相同!
```

## 3. shared_ptr - 共享所有權

### 3.1 基本用法

```cpp
// 創建
auto p1 = std::make_shared<int>(42);  // 推薦 (單次分配)
std::shared_ptr<int> p2(new int(42)); // 兩次分配

// 引用計數
std::cout << p1.use_count() << "\n";  // 1

// 共享所有權
auto p3 = p1;  // 引用計數 +1
std::cout << p1.use_count() << "\n";  // 2

{
    auto p4 = p1;  // 引用計數 +1
    std::cout << p1.use_count() << "\n";  // 3
}  // p4 銷毀,計數 -1

std::cout << p1.use_count() << "\n";  // 2

// 重置
p3.reset();  // 計數 -1
std::cout << p1.use_count() << "\n";  // 1

p1.reset();  // 計數歸零,對象被刪除
```

### 3.2 控制塊 (Control Block)

```cpp
// shared_ptr 內部結構:
// - 指向對象的指針
// - 指向控制塊的指針

// 控制塊包含:
// - 強引用計數 (shared_ptr 數量)
// - 弱引用計數 (weak_ptr 數量)
// - 刪除器
// - 分配器

// make_shared: 一次分配 (對象 + 控制塊)
auto p1 = std::make_shared<Data>(args);

// 構造函數: 兩次分配 (對象一次,控制塊一次)
std::shared_ptr<Data> p2(new Data(args));

// 性能影響:
// - make_shared 更快,cache 友好
// - 但對象與控制塊綁定,可能延遲釋放記憶體
```

### 3.3 自定義刪除器

```cpp
// shared_ptr 的刪除器不影響類型
auto deleter = [](int* p) {
    std::cout << "Custom delete: " << *p << "\n";
    delete p;
};

std::shared_ptr<int> p1(new int(42), deleter);
std::shared_ptr<int> p2(new int(100), deleter);

// p1 和 p2 類型相同,可以互相賦值
p1 = p2;  // OK

// 對比 unique_ptr:
// std::unique_ptr<int, decltype(deleter1)> u1(...);
// std::unique_ptr<int, decltype(deleter2)> u2(...);
// u1 = u2;  // Error! 類型不同
```

### 3.4 enable_shared_from_this

```cpp
class Node : public std::enable_shared_from_this<Node> {
    std::vector<std::shared_ptr<Node>> children_;

public:
    void add_child(std::shared_ptr<Node> child) {
        children_.push_back(child);

        // ❌ 錯誤: 從 this 創建 shared_ptr
        // child->set_parent(std::shared_ptr<Node>(this));

        // ✅ 正確: 使用 shared_from_this()
        child->set_parent(shared_from_this());
    }

    void set_parent(std::shared_ptr<Node> parent) {
        // ...
    }
};

// 使用
auto root = std::make_shared<Node>();
auto child = std::make_shared<Node>();
root->add_child(child);
```

### 3.5 性能開銷

```cpp
// 引用計數是原子操作 (執行緒安全)
std::shared_ptr<int> p = std::make_shared<int>(42);

// 每次拷貝都有原子操作開銷
void process(std::shared_ptr<int> p) {  // 拷貝: atomic++
    // ...
}  // 銷毀: atomic--

// ✅ 優化: 使用 const 引用
void process_ref(const std::shared_ptr<int>& p) {
    // 無原子操作
}

// ✅ 或使用裸指針 (僅觀察)
void process_raw(int* p) {
    // 零開銷
}
```

## 4. weak_ptr - 弱引用

### 4.1 解決循環引用

```cpp
// ❌ 循環引用導致記憶體洩漏
class Node {
public:
    std::shared_ptr<Node> next;  // 強引用
    std::shared_ptr<Node> prev;  // 強引用
};

auto n1 = std::make_shared<Node>();
auto n2 = std::make_shared<Node>();

n1->next = n2;  // n1 -> n2
n2->prev = n1;  // n2 -> n1 (循環!)

// n1 和 n2 永遠不會被釋放!

// ✅ 使用 weak_ptr 打破循環
class Node {
public:
    std::shared_ptr<Node> next;  // 強引用
    std::weak_ptr<Node> prev;    // 弱引用,不增加計數
};

auto n1 = std::make_shared<Node>();
auto n2 = std::make_shared<Node>();

n1->next = n2;  // n1 -> n2
n2->prev = n1;  // n2 觀察 n1 (不增加計數)

// 正常釋放
```

### 4.2 基本用法

```cpp
auto shared = std::make_shared<int>(42);
std::weak_ptr<int> weak = shared;

// weak_ptr 不增加引用計數
std::cout << shared.use_count() << "\n";  // 1

// 檢查對象是否存活
if (weak.expired()) {
    std::cout << "Object destroyed\n";
} else {
    std::cout << "Object alive\n";
}

// 安全訪問: 升級為 shared_ptr
if (auto locked = weak.lock()) {  // 嘗試提升
    // 對象仍存活,locked 是 shared_ptr
    std::cout << *locked << "\n";
} else {
    // 對象已銷毀
    std::cout << "Cannot access\n";
}

// 銷毀 shared_ptr
shared.reset();

// weak_ptr 檢測到對象已銷毀
if (weak.expired()) {
    std::cout << "Object destroyed\n";  // 輸出
}
```

### 4.3 觀察者模式

```cpp
class Subject;

class Observer {
    std::weak_ptr<Subject> subject_;

public:
    void set_subject(std::shared_ptr<Subject> subject) {
        subject_ = subject;
    }

    void notify() {
        if (auto subject = subject_.lock()) {
            // Subject 仍存在
            subject->process();
        } else {
            // Subject 已銷毀
            std::cout << "Subject no longer exists\n";
        }
    }
};

class Subject {
    std::vector<std::weak_ptr<Observer>> observers_;

public:
    void attach(std::shared_ptr<Observer> observer) {
        observers_.push_back(observer);
    }

    void notify_all() {
        // 清理已銷毀的觀察者
        observers_.erase(
            std::remove_if(observers_.begin(), observers_.end(),
                [](const std::weak_ptr<Observer>& wp) {
                    return wp.expired();
                }),
            observers_.end()
        );

        // 通知存活的觀察者
        for (auto& weak_obs : observers_) {
            if (auto obs = weak_obs.lock()) {
                obs->update();
            }
        }
    }

    void process() { /* ... */ }
};
```

## 5. 智能指針最佳實踐

### 5.1 選擇指南

```cpp
// ✅ 默認使用 unique_ptr
std::unique_ptr<Widget> create_widget() {
    return std::make_unique<Widget>();
}

// ✅ 確實需要共享所有權才用 shared_ptr
class Cache {
    std::map<std::string, std::shared_ptr<Data>> cache_;

public:
    std::shared_ptr<Data> get(const std::string& key) {
        return cache_[key];  // 共享所有權
    }
};

// ✅ 函數參數: 使用引用或裸指針
void process(const Widget& w);  // 推薦
void process(Widget* w);        // 可空時使用
void process(Widget& w);        // 不可空時使用

// ❌ 不要接受智能指針 (除非要轉移/共享所有權)
void bad(std::unique_ptr<Widget> w);  // 強制轉移
void bad(std::shared_ptr<Widget> w);  // 強制共享 + 原子操作

// ✅ 只在需要時轉移/共享所有權
void take_ownership(std::unique_ptr<Widget> w);
void share_ownership(std::shared_ptr<Widget> w);
```

### 5.2 異常安全

```cpp
// ❌ 不安全: 可能洩漏
process(std::shared_ptr<Widget>(new Widget()),
        std::shared_ptr<Gadget>(new Gadget()));

// 問題: 執行順序可能是:
// 1. new Widget()
// 2. new Gadget()  <- 如果這裡拋出異常
// 3. shared_ptr<Widget>(...) <- 不會執行,Widget 洩漏!

// ✅ 安全: 使用 make_shared/make_unique
process(std::make_shared<Widget>(),
        std::make_shared<Gadget>());
```

### 5.3 避免從 this 創建 shared_ptr

```cpp
class Bad {
public:
    std::shared_ptr<Bad> get_shared() {
        // ❌ 錯誤: 創建獨立的控制塊
        return std::shared_ptr<Bad>(this);
    }
};

auto p1 = std::make_shared<Bad>();
auto p2 = p1->get_shared();  // 兩個獨立的控制塊!
// p1 和 p2 都認為自己擁有對象,會雙重釋放!

// ✅ 正確: 使用 enable_shared_from_this
class Good : public std::enable_shared_from_this<Good> {
public:
    std::shared_ptr<Good> get_shared() {
        return shared_from_this();
    }
};

auto p1 = std::make_shared<Good>();
auto p2 = p1->get_shared();  // 共享同一個控制塊
std::cout << p1.use_count() << "\n";  // 2
```

### 5.4 unique_ptr 轉 shared_ptr

```cpp
// ✅ unique_ptr 可以轉為 shared_ptr
std::unique_ptr<Widget> unique = std::make_unique<Widget>();
std::shared_ptr<Widget> shared = std::move(unique);  // OK

// ❌ shared_ptr 不能轉為 unique_ptr
std::shared_ptr<Widget> shared2 = std::make_shared<Widget>();
// std::unique_ptr<Widget> unique2 = std::move(shared2);  // Error!
```
