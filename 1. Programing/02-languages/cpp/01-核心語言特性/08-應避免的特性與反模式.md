## 1. 應避免的語言特性

### 1.1 手動記憶體管理

```cpp
// ❌ 避免: 手動 new/delete
int* p = new int(42);
delete p;

int* arr = new int[10];
delete[] arr;

// ✅ 使用智能指針
auto p = std::make_unique<int>(42);
auto arr = std::make_unique<int[]>(10);

// ✅ 或使用容器
std::vector<int> vec(10);
```

### 1.2 C 風格轉換

```cpp
// ❌ 避免: C 風格轉換
double x = (double)42;
Base* b = (Base*)derived_ptr;

// ✅ 使用具名轉換
double x = static_cast<double>(42);
Base* b = static_cast<Base*>(derived_ptr);

// 為什麼避免 C 風格轉換?
// 1. 不明確: 無法知道執行哪種轉換
// 2. 難以搜索: 無法用工具查找所有轉換
// 3. 可能執行多個轉換
// 4. 破壞類型安全
```

### 1.3 裸指針管理資源

```cpp
// ❌ 避免: 裸指針管理
class Bad {
    int* data_;
public:
    Bad() : data_(new int[100]) {}
    ~Bad() { delete[] data_; }  // 容易忘記!
    // 還需要定義拷貝/移動...
};

// ✅ 使用 RAII
class Good {
    std::vector<int> data_;
public:
    Good() : data_(100) {}  // 自動管理
};
```

### 1.4 goto 語句

```cpp
// ❌ 避免: goto
void bad() {
    if (error) goto cleanup;
    // ...
cleanup:
    // 清理
}

// ✅ 使用 RAII
void good() {
    Resource res;
    if (error) return;  // 自動清理
    // ...
}
```

### 1.5 多重繼承 (大多數情況)

```cpp
// ❌ 避免: 多重繼承 (除了介面)
class Bad : public Base1, public Base2 {
    // 菱形繼承問題
};

// ✅ 介面多重繼承可接受
class Good : public IObserver, public ISerializable {
    // 純虛函數介面
};

// ✅ 或使用組合
class Better {
    Base1 component1_;
    Base2 component2_;
};
```

## 2. 性能陷阱

### 2.1 std::endl

```cpp
// ❌ 避免: std::endl (會 flush)
for (int i = 0; i < 1000; ++i) {
    std::cout << i << std::endl;  // 每次都 flush,慢!
}

// ✅ 使用 '\n'
for (int i = 0; i < 1000; ++i) {
    std::cout << i << '\n';  // 不 flush,快!
}
// 最後手動 flush
std::cout << std::flush;
```

### 2.2 按值傳遞大對象

```cpp
// ❌ 避免: 按值傳遞
void process(std::vector<int> vec) {  // 拷貝!
    // ...
}

// ✅ 使用 const 引用
void process(const std::vector<int>& vec) {
    // ...
}

// ✅ 或右值引用 (接受移動)
void process(std::vector<int>&& vec) {
    // ...
}

// ✅ Sink 參數 (需要拷貝時)
void store(std::vector<int> vec) {
    data_ = std::move(vec);
}
```

### 2.3 不必要的拷貝

```cpp
// ❌ 避免: 容器循環拷貝
for (std::string s : vec) {  // 每次都拷貝!
    // ...
}

// ✅ 使用引用
for (const auto& s : vec) {
    // ...
}

// ❌ 避免: map 查找拷貝
std::map<std::string, Data> map;
Data d = map["key"];  // 拷貝!

// ✅ 使用引用
const Data& d = map.at("key");

// ✅ 或使用 find
auto it = map.find("key");
if (it != map.end()) {
    const Data& d = it->second;
}
```

### 2.4 字符串拼接

```cpp
// ❌ 避免: 重複拼接
std::string result;
for (const auto& s : strings) {
    result += s;  // 每次都重新分配!
}

// ✅ 預分配
std::string result;
size_t total_size = 0;
for (const auto& s : strings) {
    total_size += s.size();
}
result.reserve(total_size);
for (const auto& s : strings) {
    result += s;
}

// ✅ 或使用 ostringstream
std::ostringstream oss;
for (const auto& s : strings) {
    oss << s;
}
std::string result = oss.str();
```

### 2.5 容器預分配

```cpp
// ❌ 避免: 不預分配
std::vector<int> vec;
for (int i = 0; i < 1000; ++i) {
    vec.push_back(i);  // 多次重新分配!
}

// ✅ 預分配
std::vector<int> vec;
vec.reserve(1000);
for (int i = 0; i < 1000; ++i) {
    vec.push_back(i);
}

// ✅ 或直接構造
std::vector<int> vec(1000);
for (int i = 0; i < 1000; ++i) {
    vec[i] = i;
}
```

## 3. 已棄用的特性

### 3.1 std::auto_ptr

```cpp
// ❌ std::auto_ptr (C++11 棄用,C++17 移除)
std::auto_ptr<int> p(new int(42));

// ✅ 使用 unique_ptr
auto p = std::make_unique<int>(42);
```

### 3.2 std::bind

```cpp
// ❌ std::bind (C++11 後少用)
auto f = std::bind(func, _1, 42);

// ✅ 使用 lambda
auto f = [](int x) { func(x, 42); };

// 為什麼 lambda 更好?
// 1. 更清晰易讀
// 2. 可內聯優化
// 3. 類型安全
// 4. 支持完美轉發
```

### 3.3 register 關鍵字

```cpp
// ❌ register 關鍵字 (C++17 棄用)
register int x = 42;

// ✅ 讓編譯器優化
int x = 42;
```

### 3.4 throw() 異常規範

```cpp
// ❌ throw() 異常規範 (C++11 棄用,C++17 移除)
void func() throw();

// ✅ 使用 noexcept
void func() noexcept;
```

### 3.5 原始陣列

```cpp
// ❌ 原始陣列
int arr[10];
arr[10] = 42;  // 越界!

// ✅ 使用 std::array
std::array<int, 10> arr;
arr.at(10);  // 拋出異常

// ✅ 或使用 std::vector
std::vector<int> vec(10);
```

## 4. 特定場景應避免

### 4.1 高性能/低延遲場景

```cpp
// ⚠️ 避免: 異常 (有開銷)
try {
    // ...
} catch (...) {
    // ...
}

// ✅ 使用錯誤碼
std::optional<Result> try_operation();

// ⚠️ 避免: RTTI/虛函數 (間接調用)
dynamic_cast<Derived*>(base_ptr);

// ✅ 使用 std::variant
std::variant<TypeA, TypeB> obj;

// ⚠️ 避免: shared_ptr (原子操作開銷)
std::shared_ptr<int> p;

// ✅ 使用 unique_ptr 或裸指針
std::unique_ptr<int> p;
int* raw_ptr;  // 僅觀察
```

### 4.2 嵌入式系統

```cpp
// ⚠️ 避免: 動態分配
std::vector<int> vec;  // 動態分配

// ✅ 使用固定大小容器
std::array<int, 100> arr;

// ⚠️ 避免: 異常
throw std::runtime_error("error");

// ✅ 使用錯誤碼
return ErrorCode::INVALID_INPUT;

// ⚠️ 避免: RTTI
typeid(obj);

// ✅ 編譯期類型識別
if constexpr (std::is_same_v<T, int>) { }
```

## 5. 常見反模式

### 5.1 不必要的拷貝

```cpp
// ❌ 返回時拷貝
std::vector<int> get_data() {
    std::vector<int> data = load_data();
    return std::move(data);  // 多餘的 move,阻礙 RVO!
}

// ✅ 依賴 RVO
std::vector<int> get_data() {
    std::vector<int> data = load_data();
    return data;  // 編譯器優化
}
```

### 5.2 過度使用 shared_ptr

```cpp
// ❌ 不必要的 shared_ptr
void process(std::shared_ptr<Widget> w) {  // 強制共享 + 原子操作
    w->do_something();
}

// ✅ 使用引用或裸指針
void process(Widget& w) {  // 零開銷
    w.do_something();
}

void process(Widget* w) {  // 可空時使用
    if (w) w->do_something();
}
```

### 5.3 忽略返回值

```cpp
// ❌ 忽略錯誤
file.read(buffer, size);  // 忽略返回值

// ✅ 檢查返回值
if (!file.read(buffer, size)) {
    // 處理錯誤
}

// ✅ 使用 [[nodiscard]]
[[nodiscard]] bool read(char* buffer, size_t size);
```

### 5.4 不安全的類型轉換

```cpp
// ❌ reinterpret_cast 濫用
int x = 42;
float* p = reinterpret_cast<float*>(&x);
*p = 3.14f;  // UB! Strict aliasing violation

// ✅ 使用 memcpy
float f;
std::memcpy(&f, &x, sizeof(float));

// ✅ 或使用 union (C++20)
union {
    int i;
    float f;
} u;
u.i = 42;
float f = u.f;
```

### 5.5 懸空引用

```cpp
// ❌ 返回局部變數引用
const int& dangerous() {
    int x = 42;
    return x;  // UB! x 在函數結束後銷毀
}

// ✅ 返回值
int safe() {
    int x = 42;
    return x;  // OK
}

// ❌ 臨時對象的引用
const std::string& bad() {
    return std::string("hello");  // UB! 臨時對象立即銷毀
}

// ✅ 返回值
std::string good() {
    return std::string("hello");  // OK
}
```

### 5.6 迭代器失效

```cpp
// ❌ 迭代器失效
std::vector<int> vec = {1, 2, 3};
auto it = vec.begin();
vec.push_back(4);  // 可能重新分配
*it = 10;          // UB! it 已失效

// ✅ 預分配避免重新分配
std::vector<int> vec;
vec.reserve(100);
auto it = vec.begin();
vec.push_back(4);  // 不會重新分配
*it = 10;  // OK (如果 vec 未滿)

// ✅ 或重新獲取迭代器
auto it = vec.begin();
vec.push_back(4);
it = vec.begin();  // 重新獲取
*it = 10;
```

### 5.7 數據競爭

```cpp
// ❌ 數據競爭
int counter = 0;

// 執行緒 1
counter++;  // UB! 非原子

// 執行緒 2
counter++;  // UB! 數據競爭

// ✅ 原子操作
std::atomic<int> counter{0};
counter.fetch_add(1, std::memory_order_relaxed);

// ✅ 或使用 mutex
std::mutex mtx;
int counter = 0;
{
    std::lock_guard<std::mutex> lock(mtx);
    counter++;
}
```
