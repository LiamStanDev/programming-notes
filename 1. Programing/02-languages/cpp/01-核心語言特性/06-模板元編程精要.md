## 1. 函數模板

### 1.1 基本函數模板

```cpp
// 基本函數模板
template<typename T>
T max_value(T a, T b) {
    return a > b ? a : b;
}

// 使用
max_value(10, 20);      // T = int
max_value(3.14, 2.71);  // T = double

// 顯式指定
max_value<double>(10, 20.5);  // T = double
```

### 1.2 模板特化

```cpp
// 通用版本
template<typename T>
void print(T value) {
    std::cout << value << "\n";
}

// 完全特化
template<>
void print<const char*>(const char* value) {
    std::cout << "String: " << value << "\n";
}

// 使用
print(42);        // 通用版本
print("hello");   // 特化版本
```

### 1.3 多個模板參數

```cpp
template<typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}

// C++14 後可省略返回類型
template<typename T, typename U>
auto add(T a, U b) {
    return a + b;
}

auto result = add(10, 3.14);  // double
```

### 1.4 非類型模板參數

```cpp
template<typename T, size_t N>
class Array {
    T data_[N];

public:
    constexpr size_t size() const { return N; }
    T& operator[](size_t i) { return data_[i]; }
};

Array<int, 10> arr;  // 編譯期確定大小
```

## 2. 類模板

### 2.1 基本類模板

```cpp
template<typename T>
class Stack {
    std::vector<T> data_;

public:
    void push(const T& item) { data_.push_back(item); }
    void push(T&& item) { data_.push_back(std::move(item)); }

    T pop() {
        T item = std::move(data_.back());
        data_.pop_back();
        return item;
    }

    bool empty() const { return data_.empty(); }
};

Stack<int> int_stack;
Stack<std::string> str_stack;
```

### 2.2 類模板特化

```cpp
// 主模板
template<typename T>
struct Serializer {
    static std::vector<uint8_t> serialize(const T& value) {
        // 通用序列化
        return {reinterpret_cast<const uint8_t*>(&value),
                reinterpret_cast<const uint8_t*>(&value) + sizeof(T)};
    }
};

// 完全特化: 針對 std::string
template<>
struct Serializer<std::string> {
    static std::vector<uint8_t> serialize(const std::string& str) {
        std::vector<uint8_t> result(4 + str.size());
        uint32_t size = str.size();
        std::memcpy(result.data(), &size, 4);
        std::memcpy(result.data() + 4, str.data(), str.size());
        return result;
    }
};

// 偏特化: 針對所有指針類型
template<typename T>
struct Serializer<T*> {
    static std::vector<uint8_t> serialize(T* ptr) {
        return Serializer<uintptr_t>::serialize(
            reinterpret_cast<uintptr_t>(ptr));
    }
};
```

### 2.3 成員函數模板

```cpp
class Printer {
public:
    template<typename T>
    void print(const T& value) {
        std::cout << value << "\n";
    }

    template<typename T, typename... Args>
    void print(const T& first, const Args&... args) {
        std::cout << first << " ";
        print(args...);
    }
};

Printer p;
p.print(1, 2.5, "hello", 'c');
```

## 3. 變參模板

### 3.1 基本變參模板

```cpp
// 遞歸終止
void print() {}

// 變參模板
template<typename T, typename... Args>
void print(T first, Args... args) {
    std::cout << first << " ";
    print(args...);  // 遞歸展開
}

print(1, 2.5, "hello", 'c');  // 1 2.5 hello c
```

### 3.2 Fold Expression (C++17)

| **類型**                   | **語法結構**          | **聚合順序**                                                        | **範例 (假設參數包 P)**   |
| ------------------------ | ----------------- | --------------------------------------------------------------- | ------------------ |
| **一元左折疊** (Unary Left)   | `(... op P)`      | $(((p_1 \text{ op } p_2) \text{ op } p_3) \text{ op } \dots)$   | `(... + args)`     |
| **一元右折疊** (Unary Right)  | `(P op ...)`      | $(\dots \text{ op } (p_{n-1} \text{ op } p_n))$                 | `(args + ...)`     |
| **二元左折疊** (Binary Left)  | `(I op ... op P)` | $(((I \text{ op } p_1) \text{ op } p_2) \text{ op } \dots)$     | `(0 + ... + args)` |
| **二元右折疊** (Binary Right) | `(P op ... op I)` | $(\dots \text{ op } (p_{n-1} \text{ op } (p_n \text{ op } I)))$ | `(args + ... + 0)` |

```cpp
// 左折疊
template<typename... Args>
auto sum(Args... args) {
    return (... + args);  // ((arg1 + arg2) + arg3) + ...
}

sum(1, 2, 3, 4);  // 10

// 右折疊
template<typename... Args>
auto sum_right(Args... args) {
    return (args + ...);  // arg1 + (arg2 + (arg3 + ...))
}

// 帶初始值的折疊
template<typename... Args>
auto sum_with_init(Args... args) {
    return (0 + ... + args);
}
```

### 3.3 參數包展開

```cpp
// 展開到函數調用
template<typename... Args>
void call_functions(Args... args) {
    (process(args), ...);  // 展開為: process(arg1), process(arg2), ...
}

// 展開到容器
template<typename... Args>
std::vector<int> make_vector(Args... args) {
    return {args...};  // 展開為: {arg1, arg2, arg3, ...}
}

// 展開到初始化列表
template<typename... Args>
void init_array(Args... args) {
    int arr[] = {args...};
}
```

## 4. SFINAE 與 enable_if

### 4.1 SFINAE 基礎

**SFINAE**: Substitution Failure Is Not An Error

```cpp
#include <type_traits>

// 只對整數啟用
template<typename T>
typename std::enable_if<std::is_integral<T>::value, T>::type
process(T value) {
    return value * 2;
}

// 只對浮點啟用
template<typename T>
typename std::enable_if<std::is_floating_point<T>::value, T>::type
process(T value) {
    return value * 1.5;
}

process(10);    // 調用整數版本
process(3.14);  // 調用浮點版本
```

### 4.2 if constexpr (C++17)

```cpp
// 更簡潔的寫法
template<typename T>
auto process(T value) {
    if constexpr (std::is_integral_v<T>) {
        return value * 2;
    } else if constexpr (std::is_floating_point_v<T>) {
        return value * 1.5;
    } else {
        static_assert(sizeof(T) == 0, "Unsupported type");
    }
}
```

### 4.3 類型特徵 (Type Traits)

```cpp
// 檢查類型
template<typename T>
void check_type() {
    if constexpr (std::is_integral_v<T>) {
        std::cout << "Integral type\n";
    }
    if constexpr (std::is_floating_point_v<T>) {
        std::cout << "Floating point type\n";
    }
    if constexpr (std::is_pointer_v<T>) {
        std::cout << "Pointer type\n";
    }
    if constexpr (std::is_class_v<T>) {
        std::cout << "Class type\n";
    }
}

// 類型轉換
template<typename T>
void convert() {
    using U = std::remove_const_t<T>;      // 移除 const
    using V = std::remove_reference_t<T>;  // 移除所有引用 (左/右)
    using W = std::decay_t<T>;             // 獲取純淨類型
}
```

##### `std::decay_t` 說明
|**原始類型 T**|**結果類型 W (std::decay_t<T>)**|**說明**|
|---|---|---|
|`const int&`|`int`|移除引用、移除 `const`|
|`char[10]`|`char*`|陣列衰變為指標|
|`void(int)`|`void(*)(int)`|函數衰變為函數指標|
|`int* const`|`int*`|移除指標的 `const`|

## 5. Concepts (C++20)

### 5.1 定義 Concept

```cpp
#include <concepts>

// 定義概念
template<typename T>
concept Numeric = std::is_arithmetic_v<T>;

template<typename T>
concept Addable = requires(T a, T b) {
    { a + b } -> std::convertible_to<T>;
};

// 使用概念約束
template<Numeric T>
T add(T a, T b) {
    return a + b;
}

add(1, 2);      // OK
add(1.5, 2.5);  // OK
// add("a", "b");  // Error! 不滿足 Numeric
```

### 5.2 Requires 子句

```cpp
// requires 表達式
template<typename T>
concept Comparable = requires(T a, T b) {
    { a < b } -> std::convertible_to<bool>;
    { a > b } -> std::convertible_to<bool>;
    { a == b } -> std::convertible_to<bool>;
};

// 使用 requires 子句
template<typename T>
    requires Comparable<T>
T max_value(T a, T b) {
    return a > b ? a : b;
}

// 或使用尾隨 requires
template<typename T>
T max_value(T a, T b) requires Comparable<T> {
    return a > b ? a : b;
}
```

### 5.3 標準 Concepts

```cpp
#include <concepts>

// 常用標準 concepts
template<std::integral T>
void process_int(T value) {}

template<std::floating_point T>
void process_float(T value) {}

template<std::copyable T>
void process_copyable(T value) {}

template<std::movable T>
void process_movable(T value) {}
```

## 6. 模板元編程實戰

### 6.1 編譯期計算

```cpp
// 編譯期階乘
template<int N>
struct Factorial {
    static constexpr int value = N * Factorial<N - 1>::value;
};

template<>
struct Factorial<0> {
    static constexpr int value = 1;
};

static_assert(Factorial<5>::value == 120);

// C++14 後更推薦使用 constexpr 函數
constexpr int factorial(int n) {
    return n <= 1 ? 1 : n * factorial(n - 1);
}

constexpr int fac5 = factorial(5);  // 編譯期計算
```

### 6.2 型別列表

```cpp
// 實現簡化版 tuple
template<typename... Types>
struct TypeList {};

// 取得第 N 個型別
template<size_t N, typename List>
struct GetType;

template<size_t N, typename Head, typename... Tail>
struct GetType<N, TypeList<Head, Tail...>> {
    using type = typename GetType<N - 1, TypeList<Tail...>>::type;
};

template<typename Head, typename... Tail>
struct GetType<0, TypeList<Head, Tail...>> {
    using type = Head;
};

using MyTypes = TypeList<int, double, std::string>;
using SecondType = typename GetType<1, MyTypes>::type;  // double
```

### 6.3 高頻交易: 編譯期訊息路由

```cpp
// 編譯期建立訊息類型 -> 處理器映射
template<typename MsgType>
struct MessageHandler;

template<>
struct MessageHandler<NewOrderMsg> {
    static void handle(const NewOrderMsg& msg) {
        // 處理新訂單
    }
};

template<>
struct MessageHandler<CancelOrderMsg> {
    static void handle(const CancelOrderMsg& msg) {
        // 處理取消訂單
    }
};

// 統一入口: 編譯期分發
template<typename MsgType>
void dispatch_message(const MsgType& msg) {
    MessageHandler<MsgType>::handle(msg);  // 零開銷分發
}
```

### 6.4 編譯期單位檢查

```cpp
// 防止單位混淆
template<typename Unit>
struct Quantity {
    double value;

    explicit constexpr Quantity(double v) : value(v) {}

    constexpr Quantity operator+(Quantity other) const {
        return Quantity(value + other.value);
    }

    constexpr Quantity operator-(Quantity other) const {
        return Quantity(value - other.value);
    }
};

struct PriceUnit {};
struct QuantityUnit {};

using Price = Quantity<PriceUnit>;
using Size = Quantity<QuantityUnit>;

Price p1(100.0);
Price p2(50.0);
Price total = p1 + p2;  // OK

Size s(1000);
// Price wrong = p1 + s;  // 編譯錯誤: 單位不匹配!

// 定義有意義的運算
constexpr double notional_value(Price price, Size size) {
    return price.value * size.value;
}
```

### 6.5 定點數模板

原理：將一個浮點數乘以一個巨大的比例因子 (Scale Factor)，然後將結果四捨五入為整數，**將浮點運算轉化為純粹的整數運算**。

```cpp
// 使用模板實現定點數運算
// BaseType(基礎類型): 儲存定點數值的底層整數類型，例如 `int64_t`。由於定點數運算需要保留足夠的精度，通常會選擇一個較大的整數類型（如 64 位整數）來避免溢出。
// FracBits(小數位元數): 決定了小數部分的精度。這個值表示比例因子 SCALE 實際上是 2FracBits。
template<typename BaseType, int FracBits>
class FixedPoint {
    BaseType value_;

    static constexpr BaseType SCALE = BaseType(1) << FracBits;

public:
    constexpr FixedPoint() : value_(0) {}

    constexpr explicit FixedPoint(double d)
        : value_(static_cast<BaseType>(d * SCALE)) {}

    constexpr FixedPoint operator+(FixedPoint other) const {
        FixedPoint result;
        result.value_ = value_ + other.value_;
        return result;
    }

    constexpr FixedPoint operator*(FixedPoint other) const {
        FixedPoint result;
		// - P1​ 代表 d1​×SCALE    
		// - P2​ 代表 d2​×SCALE
		// - 直接相乘 P1​×P2​=(d1​×SCALE)×(d2​×SCALE)=(d1​×d2​)×SCALE^2
		// 所以最後要除以 SCALE
        result.value_ = (value_ * other.value_) >> FracBits;
        return result;
    }

    constexpr double to_double() const {
        return static_cast<double>(value_) / SCALE;
    }
};

using Price = FixedPoint<int64_t, 16>;  // 16 位元小數

Price p1(100.25);
Price p2(50.50);
Price total = p1 + p2;  // 編譯期類型安全,運行時整數運算
```
