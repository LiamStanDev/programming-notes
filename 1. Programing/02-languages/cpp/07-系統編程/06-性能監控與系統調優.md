# 性能監控與系統調優 (Performance Monitoring & System Tuning)

在高頻交易系統中,持續的性能監控和系統調優是保證穩定低延遲的關鍵。本章深入探討 Linux 性能監控工具、系統參數調優以及 HFT 生產環境的完整優化策略。

## 1. 性能監控工具

### 1.1 perf - Linux 性能分析利器

**⭐⭐⭐ perf** 是 Linux 內核自帶的強大性能分析工具,可以分析 CPU、緩存、分支預測等硬件事件。

**核心功能**:
- CPU 性能計數器 (Performance Counters)
- 調用棧採樣 (Call Stack Profiling)
- 硬件事件監控 (Cache Miss, Branch Miss 等)
- 實時性能監控

### 1.2 perf 基本用法

```bash
# 記錄性能數據
sudo perf record -g ./trading_system

# 查看報告
sudo perf report

# CPU 周期分析
sudo perf stat ./trading_system

# 輸出範例:
# Performance counter stats for './trading_system':
#   2,345.67 msec task-clock                #    0.998 CPUs utilized          
#     12,456      context-switches          #    5.311 K/sec                  
#        123      cpu-migrations            #   52.438 /sec                   
#      1,234      page-faults               #  526.012 /sec                   
# 7,890,123,456   cycles                    #    3.363 GHz                    
# 4,567,890,123   instructions              #    0.58  insn per cycle         
#   123,456,789   branches                  #   52.613 M/sec                  
#     1,234,567   branch-misses             #    1.00% of all branches        

# 實時監控
sudo perf top

# 緩存未命中分析
sudo perf stat -e cache-misses,cache-references ./trading_system

# 監控特定事件
sudo perf stat -e dTLB-load-misses,dTLB-store-misses ./trading_system

# 記錄運行中的進程
sudo perf record -p <PID> -g -- sleep 10

# 火焰圖生成 (需要 FlameGraph 工具)
sudo perf record -F 99 -g -p <PID> -- sleep 30
sudo perf script | stackcollapse-perf.pl | flamegraph.pl > flame.svg
```

### 1.3 perf 高級用法

**⭐⭐⭐ HFT 關鍵指標監控**:

```bash
# 監控 L1/L2/L3 緩存未命中
sudo perf stat -e L1-dcache-load-misses,L1-dcache-loads,\
L1-icache-load-misses,LLC-load-misses,LLC-loads \
./trading_system

# 監控分支預測
sudo perf stat -e branches,branch-misses,branch-load-misses \
./trading_system

# 監控 TLB Miss (頁表緩存)
sudo perf stat -e dTLB-load-misses,dTLB-loads,iTLB-load-misses \
./trading_system

# 上下文切換監控
sudo perf stat -e context-switches,cpu-migrations -p <PID> sleep 10

# 記錄延遲分布
sudo perf stat -r 100 ./trading_system  # 運行 100 次取平均
```

## 2. /proc 文件系統監控

### 2.1 /proc 文件系統概述

**⭐⭐⭐ /proc** 是一個虛擬文件系統,提供進程和系統信息的實時視圖。

**關鍵文件**:
- `/proc/<PID>/stat` - 進程統計信息
- `/proc/<PID>/status` - 進程狀態
- `/proc/<PID>/smaps` - 內存映射詳細信息
- `/proc/<PID>/fd/` - 打開的文件描述符
- `/proc/meminfo` - 系統內存信息
- `/proc/cpuinfo` - CPU 信息
- `/proc/interrupts` - 中斷統計

### 2.2 讀取進程統計

```cpp
#include <fstream>
#include <iostream>
#include <string>
#include <sstream>

class ProcMonitor {
public:
    struct ProcessStats {
        char state;
        unsigned long minflt;   // Minor page faults
        unsigned long majflt;   // Major page faults
        unsigned long utime;    // User CPU time (jiffies)
        unsigned long stime;    // System CPU time (jiffies)
        long priority;
        long nice;
        long num_threads;
    };
    
    // 讀取 /proc/self/stat
    static ProcessStats read_stat() {
        std::ifstream stat_file("/proc/self/stat");
        ProcessStats stats;
        
        std::string comm;
        int ppid, pgrp, session, tty_nr, tpgid;
        unsigned long flags, cminflt, cmajflt;
        long cutime, cstime;
        
        stat_file >> comm >> comm >> stats.state >> ppid >> pgrp >> session 
                  >> tty_nr >> tpgid >> flags >> stats.minflt >> cminflt 
                  >> stats.majflt >> cmajflt >> stats.utime >> stats.stime 
                  >> cutime >> cstime >> stats.priority >> stats.nice 
                  >> stats.num_threads;
        
        return stats;
    }
    
    // 讀取內存使用情況
    static void print_memory_usage() {
        std::ifstream status_file("/proc/self/status");
        std::string line;
        
        std::cout << "內存使用情況:\n";
        while (std::getline(status_file, line)) {
            if (line.find("VmRSS:") == 0 ||    // 物理內存
                line.find("VmSize:") == 0 ||   // 虛擬內存
                line.find("VmPeak:") == 0 ||   // 虛擬內存峰值
                line.find("VmHWM:") == 0) {    // 物理內存峰值
                std::cout << "  " << line << "\n";
            }
        }
    }
    
    // 打印統計信息
    static void print_stats() {
        auto stats = read_stat();
        
        std::cout << "進程統計:\n"
                  << "  狀態: " << stats.state << "\n"
                  << "  Minor page faults: " << stats.minflt << "\n"
                  << "  Major page faults: " << stats.majflt << "\n"
                  << "  User time: " << stats.utime << " jiffies\n"
                  << "  System time: " << stats.stime << " jiffies\n"
                  << "  Priority: " << stats.priority << "\n"
                  << "  Nice: " << stats.nice << "\n"
                  << "  Threads: " << stats.num_threads << "\n";
    }
};

// 使用範例
void example_proc_monitor() {
    ProcMonitor::print_stats();
    ProcMonitor::print_memory_usage();
}
```

```cpp
namespace fs = std::filesystem;

void print_open_fds() {
    std::cout << "打開的文件描述符:\n";
    
    for (const auto& entry : fs::directory_iterator("/proc/self/fd")) {
        std::cout << "  FD " << entry.path().filename() << " -> ";

            auto link = fs::read_symlink(entry.path());

        } catch (...) {
            std::cout << "(無法讀取)\n";
        }
    }
}
```

## 3. strace - 系統調用追蹤

### 3.1 strace 基本用法

**⭐⭐⭐ strace** 追蹤程序執行的系統調用和信號。

```bash
# 追蹤系統調用
strace ./trading_system

# 統計系統調用
strace -c ./trading_system

# 輸出範例:
# % time     seconds  usecs/call     calls    errors syscall
# ------ ----------- ----------- --------- --------- ----------------
#  45.23    0.012345          12      1023           read
#  23.45    0.006789           7      1000           write
#  15.67    0.004321          43       100         5 open
#   8.90    0.002456          25        98           close
#   6.75    0.001890          19       100           mmap
# ------ ----------- ----------- --------- --------- ----------------
# 100.00    0.027801                  2321         5 total

# 追蹤特定系統調用
strace -e open,read,write ./trading_system

# 只顯示失敗的調用
strace -e trace=open -Z ./trading_system

# 追蹤運行中的進程
sudo strace -p <PID>

# 統計每個系統調用的時間
strace -T ./trading_system

# 過濾慢速調用 (>1ms)
strace -T -e trace=all ./trading_system 2>&1 | grep '<0.001'
```

### 3.2 使用 strace 找到性能瓶頸

```bash
# 找出最慢的系統調用
sudo strace -c -p <PID>

# 追蹤文件操作
sudo strace -e trace=file -p <PID>

# 追蹤網絡操作
sudo strace -e trace=network -p <PID>

# 追蹤內存操作
sudo strace -e trace=memory -p <PID>
```

## 4. 系統參數調優

### 4.1 中斷親和性 (IRQ Affinity)

**⭐⭐⭐ IRQ 親和性**: 將硬件中斷綁定到特定 CPU,避免干擾關鍵線程。

```bash
# 查看所有中斷
cat /proc/interrupts

# 查看網卡中斷
cat /proc/interrupts | grep eth0

# 輸出範例:
#            CPU0       CPU1       CPU2       CPU3       
#  42:    1234567          0          0          0   IR-PCI-MSI-edge      eth0-TxRx-0
#  43:          0    1234567          0          0   IR-PCI-MSI-edge      eth0-TxRx-1

# 設置中斷親和性到 CPU 0 (二進制: 0001 = 1)
echo 1 | sudo tee /proc/irq/42/smp_affinity

# 設置到 CPU 1 (二進制: 0010 = 2)
echo 2 | sudo tee /proc/irq/43/smp_affinity

# 設置到 CPU 0-1 (二進制: 0011 = 3)
echo 3 | sudo tee /proc/irq/44/smp_affinity

# 禁用 IRQ Balance (避免自動調整)
sudo systemctl stop irqbalance
sudo systemctl disable irqbalance

# 腳本: 將所有網卡中斷綁定到 CPU 0
for irq in $(grep eth0 /proc/interrupts | awk '{print $1}' | tr -d ':'); do
    echo 1 | sudo tee /proc/irq/$irq/smp_affinity
done
```

**⭐⭐⭐ HFT 中斷親和性策略**:

```
CPU 0: 網卡中斷 (eth0)
CPU 1: 系統服務、非關鍵任務
CPU 2-3: Trading Engine (隔離,無中斷)
CPU 4-5: Feed Handler (隔離,無中斷)
CPU 6-7: Risk Manager (隔離,無中斷)
```

### 4.2 內核參數調優

**⭐⭐⭐ sysctl 核心參數**:

```bash
# 編輯 /etc/sysctl.conf

# === 網絡優化 ===
# 增加接收/發送緩衝區大小
net.core.rmem_max = 134217728        # 128 MB
net.core.wmem_max = 134217728        # 128 MB
net.core.rmem_default = 16777216     # 16 MB
net.core.wmem_default = 16777216     # 16 MB

# TCP 緩衝區 (min, default, max)
net.ipv4.tcp_rmem = 4096 87380 67108864  # 64 MB
net.ipv4.tcp_wmem = 4096 65536 67108864  # 64 MB

# 增加 backlog 隊列

# TCP 優化

net.ipv4.tcp_tw_reuse = 1               # 允許 TIME_WAIT 重用
net.ipv4.tcp_fin_timeout = 15           # 縮短 FIN_WAIT 超時

# === 內存管理 ===
# 減少 swap (0-100, 越低越少用 swap)

# Dirty page 寫回控制
vm.dirty_ratio = 10              # 10% 內存
vm.dirty_background_ratio = 5    # 5% 內存

# === 文件系統 ===
# 增加文件描述符限制

# 增加 inotify 限制

# === 內核調度 ===
# 減少調度延遲
```

## 5. CPU 優化

### 5.1 CPU 頻率管理

**⭐⭐⭐ 禁用頻率調節**: 保證 CPU 始終全速運行,避免頻率變化導致的延遲抖動。

```bash
# 查看當前頻率策略
cat /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor

# 輸出可能為: powersave, performance, ondemand, conservative, userspace

# 設置為性能模式 (最高頻率)
for cpu in /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor; do
    echo performance | sudo tee $cpu
done

# 驗證
cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_governor
# 輸出: performance

# 查看當前頻率
cat /sys/devices/system/cpu/cpu0/cpufreq/scaling_cur_freq

# 禁用 Turbo Boost (可選,為了頻率穩定性)
echo 1 | sudo tee /sys/devices/system/cpu/intel_pstate/no_turbo

# 或對於 AMD
echo 0 | sudo tee /sys/devices/system/cpu/cpufreq/boost
```

### 5.2 禁用 C-States (電源管理狀態)

**⭐⭐ C-States**: CPU 空閑時的低功耗狀態,會增加喚醒延遲。

```bash
# 在 GRUB 配置中禁用 C-States
# 編輯 /etc/default/grub
GRUB_CMDLINE_LINUX="processor.max_cstate=0 intel_idle.max_cstate=0"

# 更新 GRUB
sudo update-grub
sudo reboot

# 驗證 (應該只有 C0)
cpupower idle-info
```

## 6. HFT 完整調優腳本

### 6.1 系統調優腳本

**⭐⭐⭐ 生產環境一鍵調優**:

```bash
#!/bin/bash
# hft_system_tune.sh - HFT 系統調優腳本

set -e

echo "=== HFT 系統調優 ==="

# 1. CPU 隔離 (需要在 GRUB 配置中設置,然後重啟)
echo "1. 檢查 CPU 隔離..."
if ! grep -q "isolcpus" /proc/cmdline; then
    echo "   警告: CPU 未隔離"
    echo "   編輯 /etc/default/grub:"
    echo "   GRUB_CMDLINE_LINUX=\"isolcpus=2-7 nohz_full=2-7 rcu_nocbs=2-7\""
    echo "   然後執行: sudo update-grub && sudo reboot"
else
    echo "   ✓ CPU 已隔離"
fi

# 2. CPU 頻率設置為性能模式
echo "2. 設置 CPU 性能模式..."
for cpu in /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor; do
    echo performance | sudo tee $cpu > /dev/null
done
echo "   ✓ CPU 頻率已設置為 performance"

# 3. 禁用 Turbo Boost (可選)
if [ -f /sys/devices/system/cpu/intel_pstate/no_turbo ]; then
    echo 1 | sudo tee /sys/devices/system/cpu/intel_pstate/no_turbo > /dev/null
    echo "   ✓ Turbo Boost 已禁用"
fi

# 4. 關閉透明大頁 (避免延遲抖動)
echo "4. 關閉透明大頁..."
echo never | sudo tee /sys/kernel/mm/transparent_hugepage/enabled > /dev/null
echo never | sudo tee /sys/kernel/mm/transparent_hugepage/defrag > /dev/null
echo "   ✓ 透明大頁已禁用"

# 5. 配置 Huge Pages (2GB = 1024 * 2MB 頁)
echo "5. 配置 Huge Pages..."
echo 1024 | sudo tee /proc/sys/vm/nr_hugepages > /dev/null
HUGE_FREE=$(grep HugePages_Free /proc/meminfo | awk '{print $2}')
echo "   ✓ Huge Pages 可用: $HUGE_FREE"

# 6. 網絡調優
echo "6. 網絡參數調優..."
sudo sysctl -w net.core.rmem_max=134217728 > /dev/null
sudo sysctl -w net.core.wmem_max=134217728 > /dev/null
sudo sysctl -w net.ipv4.tcp_rmem="4096 87380 67108864" > /dev/null
sudo sysctl -w net.ipv4.tcp_wmem="4096 65536 67108864" > /dev/null
sudo sysctl -w net.core.netdev_max_backlog=5000 > /dev/null
sudo sysctl -w net.ipv4.tcp_slow_start_after_idle=0 > /dev/null
echo "   ✓ 網絡參數已優化"

# 7. 減少 swap
echo "7. 減少 swap 使用..."
sudo sysctl -w vm.swappiness=1 > /dev/null
echo "   ✓ swappiness 設置為 1"

# 8. 文件描述符限制
echo "8. 增加文件描述符限制..."
sudo sysctl -w fs.file-max=2097152 > /dev/null
echo "   ✓ file-max 設置為 2097152"

# 9. 禁用 IRQ Balance
echo "9. 禁用 IRQ Balance..."
sudo systemctl stop irqbalance 2>/dev/null || true
sudo systemctl disable irqbalance 2>/dev/null || true
echo "   ✓ IRQ Balance 已禁用"

# 10. 設置網卡中斷親和性 (假設 eth0)
echo "10. 設置網卡中斷親和性..."
NIC=${HFT_NIC:-eth0}
if grep -q "$NIC" /proc/interrupts; then
    for irq in $(grep "$NIC" /proc/interrupts | awk '{print $1}' | tr -d ':'); do
        echo 1 | sudo tee /proc/irq/$irq/smp_affinity > /dev/null
    done
    echo "   ✓ $NIC 中斷已綁定到 CPU 0"
else
    echo "   警告: 未找到網卡 $NIC"
fi

# 11. 檢查實時內核
echo "11. 檢查實時內核..."
if uname -r | grep -q "rt"; then
    echo "   ✓ 使用實時內核"
else
    echo "   建議: 安裝實時內核 (linux-image-rt-amd64)"
fi

echo ""
echo "=== 調優完成 ==="
echo "建議重啟系統使所有設置生效"
```

## 7. HFT 調優檢查清單

### 7.1 必須項 (⭐⭐⭐)

- [ ] CPU 隔離 (`isolcpus=2-7 nohz_full=2-7 rcu_nocbs=2-7`)
- [ ] 實時調度 (`SCHED_FIFO`, 優先級 80-90)
- [ ] CPU 親和性 (關鍵線程綁定到隔離 CPU)
- [ ] 內存鎖定 (`mlockall(MCL_CURRENT | MCL_FUTURE)`)
- [ ] CPU 性能模式 (`scaling_governor=performance`)
- [ ] 禁用透明大頁 (`transparent_hugepage=never`)
- [ ] 網絡緩衝區優化 (128MB rmem/wmem)
- [ ] 禁用 IRQ Balance

### 7.2 推薦項 (⭐⭐)

- [ ] Huge Pages (2MB 頁面,1024 頁 = 2GB)
- [ ] 網卡中斷親和性 (綁定到非關鍵 CPU)
- [ ] 禁用 Turbo Boost (頻率穩定性)
- [ ] 禁用 C-States (減少喚醒延遲)
- [ ] 減少 swappiness (`vm.swappiness=1`)
- [ ] 增加文件描述符 (`fs.file-max=2097152`)
- [ ] 實時內核 (`linux-image-rt-amd64`)

### 7.3 可選項 (⭐)

- [ ] NUMA 感知內存分配
- [ ] cgroup 資源隔離
- [ ] 自定義 TCP 參數
- [ ] 關閉不必要的系統服務
- [ ] 禁用 ASLR (地址空間布局隨機化)

## 8. 性能提升總結

### 8.1 優化效果對比

| 優化技術 | 延遲改善 | 穩定性 | 複雜度 | HFT 推薦 |
| -------- | -------- | ------ | ------ | -------- |
| CPU 隔離 | 30-50% | 高 | 中等 | **必須** |
| 實時調度 | 20-40% | 高 | 低 | **必須** |
| CPU 親和性 | 15-30% | 高 | 低 | **必須** |
| 內存鎖定 (mlock) | 10-20% | 高 | 低 | **必須** |
| Huge Pages | 5-15% | 中等 | 中等 | 推薦 |
| 中斷親和性 | 10-30% | 中等 | 中等 | 推薦 |
| CPU 性能模式 | 5-10% | 高 | 低 | 必須 |
| 禁用透明大頁 | 穩定性提升 | 高 | 低 | 必須 |

### 8.2 延遲分布改善

**優化前**:
```

```

```
P50:   2 μs    (改善 60%)
P99:   10 μs   (改善 80%)
P99.9: 25 μs   (改善 95%!)

```
