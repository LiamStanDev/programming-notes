## 性能指標定義

### 核心指標

| 指標                   | 定義       | HFT目標      | 測量方法                             |
| -------------------- | -------- | ---------- | -------------------------------- |
| **延遲 (Latency)**     | 單個操作完成時間 | < 1μs      | `clock_gettime(CLOCK_MONOTONIC)` |
| **吞吐量 (Throughput)** | 單位時間處理量  | > 1M ops/s | 計數器 + 時間窗口                       |
| **P99延遲**            | 99%請求的延遲 | < 10μs     | 百分位統計                            |
| **抖動 (Jitter)**      | 延遲標準差    | < 100ns    | 標準差計算                            |

## Benchmark框架

### 延遲測試框架

```cpp
#include <chrono>
#include <vector>
#include <algorithm>
#include <numeric>
#include <iostream>
#include <cmath>

class LatencyBenchmark {
public:
    using Clock = std::chrono::high_resolution_clock;
    using Duration = std::chrono::nanoseconds;
    
    void record(Duration latency) {
        latencies_.push_back(latency.count());
    }
    
    void print_statistics() {
        if (latencies_.empty()) return;
        
        std::sort(latencies_.begin(), latencies_.end());
        
        size_t count = latencies_.size();
        double sum = std::accumulate(latencies_.begin(), latencies_.end(), 0.0);
        double mean = sum / count;
        
        // 計算標準差
        double variance = 0.0;
        for (auto lat : latencies_) {
            variance += (lat - mean) * (lat - mean);
        }
        double stddev = std::sqrt(variance / count);
        
        std::cout << "=== Latency Statistics ===\n";
        std::cout << "Count:  " << count << "\n";
        std::cout << "Min:    " << latencies_.front() << " ns\n";
        std::cout << "Max:    " << latencies_.back() << " ns\n";
        std::cout << "Mean:   " << mean << " ns\n";
        std::cout << "Stddev: " << stddev << " ns\n";
        std::cout << "P50:    " << latencies_[count * 50 / 100] << " ns\n";
        std::cout << "P95:    " << latencies_[count * 95 / 100] << " ns\n";
        std::cout << "P99:    " << latencies_[count * 99 / 100] << " ns\n";
        std::cout << "P999:   " << latencies_[count * 999 / 1000] << " ns\n";
    }
    
    void reset() {
        latencies_.clear();
    }
    
private:
    std::vector<uint64_t> latencies_;
};

// 使用示例
void benchmark_async_operation() {
    LatencyBenchmark bench;
    
    for (int i = 0; i < 10000; ++i) {
        auto start = LatencyBenchmark::Clock::now();
        
        // 執行異步操作
        perform_async_operation();
        
        auto end = LatencyBenchmark::Clock::now();
        auto latency = std::chrono::duration_cast<LatencyBenchmark::Duration>(end - start);
        
        bench.record(latency);
    }
    
    bench.print_statistics();
}
```

## 延遲測量與分析

### 高精度延遲測量

```cpp
#include <time.h>

class HighResolutionTimer {
public:
    static uint64_t now_ns() {
        struct timespec ts;
        clock_gettime(CLOCK_MONOTONIC, &ts);
        return ts.tv_sec * 1000000000ULL + ts.tv_nsec;
    }
    
    static uint64_t rdtsc() {
        unsigned int lo, hi;
        __asm__ volatile("rdtsc" : "=a"(lo), "=d"(hi));
        return ((uint64_t)hi << 32) | lo;
    }
};

// HFT關鍵路徑延遲測量
void measure_critical_path() {
    uint64_t start = HighResolutionTimer::rdtsc();
    
    // 關鍵操作: 訂單簿更新
    update_order_book();
    
    uint64_t end = HighResolutionTimer::rdtsc();
    
    // 假設CPU頻率2.4GHz
    double cycles = end - start;
    double ns = cycles / 2.4;
    
    std::cout << "Order book update: " << ns << " ns\n";
}
```

### 延遲分佈視覺化

```cpp
#include <map>

class LatencyHistogram {
public:
    void record(uint64_t latency_ns) {
        // 10ns為一個bucket
        uint64_t bucket = latency_ns / 10;
        histogram_[bucket]++;
    }
    
    void print() {
        std::cout << "=== Latency Histogram (10ns buckets) ===\n";
        
        for (const auto& [bucket, count] : histogram_) {
            uint64_t start_ns = bucket * 10;
            uint64_t end_ns = (bucket + 1) * 10;
            
            std::cout << "[" << start_ns << "-" << end_ns << " ns]: ";
            
            // 打印直方圖
            for (size_t i = 0; i < count / 100; ++i) {
                std::cout << "*";
            }
            std::cout << " (" << count << ")\n";
        }
    }
    
private:
    std::map<uint64_t, size_t> histogram_;
};
```

## 吞吐量優化

### 批量處理優化

```cpp
#include <liburing.h>
#include <vector>

class BatchedIOSubmitter {
public:
    BatchedIOSubmitter(size_t batch_size = 64) 
        : batch_size_(batch_size) {
        io_uring_queue_init(256, &ring_, 0);
    }
    
    ~BatchedIOSubmitter() {
        io_uring_queue_exit(&ring_);
    }
    
    // 批量提交讀取請求
    void submit_batch_reads(const std::vector<int>& fds, 
                            std::vector<char*>& buffers) {
        size_t count = std::min(fds.size(), batch_size_);
        
        for (size_t i = 0; i < count; ++i) {
            struct io_uring_sqe *sqe = io_uring_get_sqe(&ring_);
            io_uring_prep_read(sqe, fds[i], buffers[i], 4096, 0);
        }
        
        // 單次系統調用提交所有請求
        io_uring_submit(&ring_);
    }
    
    // 批量處理完成事件
    void process_completions() {
        struct io_uring_cqe *cqes[64];
        int count = io_uring_peek_batch_cqe(&ring_, cqes, 64);
        
        for (int i = 0; i < count; ++i) {
            // 處理結果
            io_uring_cqe_seen(&ring_, cqes[i]);
        }
    }
    
private:
    struct io_uring ring_;
    size_t batch_size_;
};
```

### 吞吐量測試

```cpp
#include <atomic>

class ThroughputBenchmark {
public:
    void start() {
        start_time_ = std::chrono::steady_clock::now();
        count_.store(0);
    }
    
    void record_operation() {
        count_.fetch_add(1, std::memory_order_relaxed);
    }
    
    void print_stats() {
        auto end_time = std::chrono::steady_clock::now();
        auto duration = std::chrono::duration_cast<std::chrono::seconds>(
            end_time - start_time_);
        
        uint64_t ops = count_.load();
        double throughput = ops / static_cast<double>(duration.count());
        
        std::cout << "Total ops: " << ops << "\n";
        std::cout << "Duration:  " << duration.count() << " s\n";
        std::cout << "Throughput: " << throughput << " ops/s\n";
    }
    
private:
    std::atomic<uint64_t> count_{0};
    std::chrono::steady_clock::time_point start_time_;
};
```

### 內置性能計數器

```cpp
#include <linux/perf_event.h>
#include <sys/ioctl.h>
#include <unistd.h>

class PerfCounter {
public:
    PerfCounter() {
        struct perf_event_attr pe;
        memset(&pe, 0, sizeof(pe));
        pe.type = PERF_TYPE_HARDWARE;
        pe.size = sizeof(pe);
        pe.config = PERF_COUNT_HW_CPU_CYCLES;
        pe.disabled = 1;
        pe.exclude_kernel = 1;
        
        fd_ = perf_event_open(&pe, 0, -1, -1, 0);
    }
    
    ~PerfCounter() {
        if (fd_ >= 0) close(fd_);
    }
    
    void start() {
        ioctl(fd_, PERF_EVENT_IOC_RESET, 0);
        ioctl(fd_, PERF_EVENT_IOC_ENABLE, 0);
    }
    
    uint64_t stop() {
        ioctl(fd_, PERF_EVENT_IOC_DISABLE, 0);
        
        uint64_t count;
        read(fd_, &count, sizeof(count));
        return count;
    }
    
private:
    int fd_;
    
    static int perf_event_open(struct perf_event_attr *attr,
                               pid_t pid, int cpu, int group_fd,
                               unsigned long flags) {
        return syscall(__NR_perf_event_open, attr, pid, cpu, group_fd, flags);
    }
};

// 使用示例
void measure_cycles() {
    PerfCounter counter;
    
    counter.start();
    // 執行操作
    perform_operation();
    uint64_t cycles = counter.stop();
    
    std::cout << "Cycles: " << cycles << "\n";
}
```

## 實戰優化案例

### 案例1: 市場數據處理優化

**優化前**:
```cpp
// ❌ 每次動態分配 + 字符串拷貝
void process_market_data_slow(const char* data, size_t len) {
    std::string msg(data, len);  // 拷貝
    auto fields = parse_fix(msg);  // 分配map
    update_order_book(fields);
}
```

**優化後**:
```cpp
// ✅ 零拷貝 + 預分配
struct FixField {
    const char* value;
    size_t len;
};

class ZeroCopyFixParser {
    std::array<FixField, 32> fields_;  // 預分配
    
public:
    const FixField* parse(const char* data, size_t len) {
        // 直接在原始buffer上解析,無拷貝
        // ...
        return fields_.data();
    }
};

void process_market_data_fast(const char* data, size_t len) {
    static ZeroCopyFixParser parser;  // 重用
    const FixField* fields = parser.parse(data, len);
    update_order_book(fields);
}
```

**性能提升**: 延遲從 ~500ns 降至 ~150ns (3.3x)

## 最佳實踐

1. **始終測量**: 優化前後都要測量
2. **熱路徑優先**: 專注於性能關鍵路徑
3. **批量處理**: 減少系統調用次數
4. **預分配**: 避免動態內存分配
5. **CPU親和性**: 綁定關鍵線程
6. **零拷貝**: 使用mmap、sendfile
7. **監控P99**: 不只看平均值
8. **回歸測試**: 防止性能退化
