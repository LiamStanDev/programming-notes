## 迭代器基礎

迭代器 (Iterator) 是連接容器與算法的橋樑。

### 1. 五種迭代器類型

| 迭代器類型        | 讀/寫 | 方向           | 訪問       | 示例容器                    |
| :---------------- | :---- | :------------- | :--------- | :-------------------------- |
| **Input**         | 只讀  | 單向 (++)      | \*it       | istream_iterator            |
| **Output**        | 只寫  | 單向 (++)      | \*it = val | ostream_iterator            |
| **Forward**       | 讀寫  | 單向 (++)      | \*it       | forward_list, unordered_map |
| **Bidirectional** | 讀寫  | 雙向 (++ / --) | \*it       | list, set, map              |
| **Random Access** | 讀寫  | 隨機 (+n / []) | it[n]      | vector, deque, array        |

### 2. 常用迭代器適配器

```cpp
#include <iterator>
#include <vector>
#include <algorithm>

std::vector<int> v = {1, 2, 3};

// 1. 插入迭代器 (Insert Iterator)
std::vector<int> dest;
std::copy(v.begin(), v.end(), std::back_inserter(dest)); // 調用 push_back

// 2. 流迭代器 (Stream Iterator)
std::copy(v.begin(), v.end(), std::ostream_iterator<int>(std::cout, " ")); // 輸出: 1 2 3

// 3. 反向迭代器 (Reverse Iterator)
auto rit = v.rbegin(); // 指向最後一個元素
```

### 3. 自定義迭代器實現

實現一個簡單的 `Range` 迭代器，用於類似 Python 的 `range(start, end)`。

```cpp
class Range {
    long start_, end_;
public:
    Range(long start, long end) : start_(start), end_(end) {}

    // 內部迭代器類
    class Iterator {
        long current_;
    public:
        using iterator_category = std::input_iterator_tag;
        using value_type = long;
        using difference_type = long;
        using pointer = const long*;
        using reference = const long&;

        explicit Iterator(long val) : current_(val) {}

        long operator*() const { return current_; }
        Iterator& operator++() { ++current_; return *this; }
        bool operator!=(const Iterator& other) const { return current_ != other.current_; }
    };

    Iterator begin() const { return Iterator(start_); }
    Iterator end() const { return Iterator(end_); }
};

// 使用
for (long i : Range(0, 5)) {
    // 0, 1, 2, 3, 4
}
```

## 非修改式算法

不改變容器內容，僅進行查詢或統計。

```cpp
std::vector<int> v = {1, 2, 3, 4, 5, 2};

// 1. 查找 (Find) - O(N)
auto it = std::find(v.begin(), v.end(), 3);

// 2. 條件查找 (Find If) - O(N)
auto it2 = std::find_if(v.begin(), v.end(), [](int x) { return x > 3; });

// 3. 計數 (Count) - O(N)
int c = std::count(v.begin(), v.end(), 2); // 2

// 4. 全匹配/任一匹配 (All/Any/None Of) - O(N)
bool all_pos = std::all_of(v.begin(), v.end(), [](int x) { return x > 0; });
```

## 修改式算法

會改變容器內容。

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};

// 1. 拷貝 (Copy)
std::vector<int> v2(5);
std::copy(v.begin(), v.end(), v2.begin());

// 2. 變換 (Transform) - 類似 map
std::transform(v.begin(), v.end(), v.begin(), [](int x) { return x * 2; });
// v: {2, 4, 6, 8, 10}

// 3. 替換 (Replace)
std::replace(v.begin(), v.end(), 2, 99);

// 4. 移除 (Remove) - Remove-Erase Idiom
// remove 只會移動元素，不會改變容器大小
auto new_end = std::remove(v.begin(), v.end(), 99);
v.erase(new_end, v.end()); // 真正刪除
```

## 排序與搜尋

### 1. 排序算法

```cpp
std::vector<int> v = {5, 1, 9, 2, 8};

// 1. 全排序 (Sort) - O(N log N)
std::sort(v.begin(), v.end());

// 2. 穩定排序 (Stable Sort) - O(N log N)
// 保留相等元素的相對順序
std::stable_sort(v.begin(), v.end());

// 3. 部分排序 (Partial Sort) - O(N log K)
// 只保證前 K 個元素有序且是最小的
std::partial_sort(v.begin(), v.begin() + 3, v.end());
// v: {1, 2, 5, ...}

// 4. 第 N 元素 (Nth Element) - O(N)
// 保證第 N 個位置是正確的，且左邊 <= 它，右邊 >= 它
std::nth_element(v.begin(), v.begin() + 2, v.end());
// v[2] 是第 3 小的元素
```

### 2. 二分搜尋 (Binary Search)

**前提**: 容器必須已排序。

```cpp
std::vector<int> v = {1, 3, 5, 7, 9};

// 1. 是否存在
bool exists = std::binary_search(v.begin(), v.end(), 5); // true

// 2. 下界 (Lower Bound) - 第一個 >= val
auto lb = std::lower_bound(v.begin(), v.end(), 5); // 指向 5

// 3. 上界 (Upper Bound) - 第一個 > val
auto ub = std::upper_bound(v.begin(), v.end(), 5); // 指向 7
```

## 數值算法

需要包含 `<numeric>`。

```cpp
std::vector<int> v = {1, 2, 3, 4};

// 1. 累加 (Accumulate)
int sum = std::accumulate(v.begin(), v.end(), 0); // 10

// 2. 前綴和 (Partial Sum)
std::vector<int> res(4);
std::partial_sum(v.begin(), v.end(), res.begin()); // {1, 3, 6, 10}

// 3. 遞增填充 (Iota)
std::iota(v.begin(), v.end(), 10); // {10, 11, 12, 13}
```

## C++20 Ranges

C++20 引入了 Ranges 庫，提供了更現代、可組合的視圖 (Views)。

```cpp
#include <ranges>
#include <vector>
#include <iostream>

void ranges_example() {
    std::vector<int> v = {1, 2, 3, 4, 5, 6};

    // 過濾偶數 -> 平方 -> 取前 2 個
    auto result = v | std::views::filter([](int n){ return n % 2 == 0; })
                    | std::views::transform([](int n){ return n * n; })
                    | std::views::take(2);

    for (int n : result) {
        std::cout << n << " "; // 4 16
    }
    // 注意: 這是惰性求值 (Lazy Evaluation)，不會產生中間容器
}
```

## 實戰案例

### 案例 1: 市場數據 Top-K 排序

**場景**: 從數萬個 Symbol 中找出漲幅最大的前 10 個。

**錯誤示範**:

```cpp
// ❌ 全排序: O(N log N)
std::sort(data.begin(), data.end(), compare_change);
// 取前 10 個
```

**正確實現**:

```cpp
// ✅ 部分排序: O(N log K)
// 只需保證前 10 個有序
std::partial_sort(data.begin(), data.begin() + 10, data.end(), compare_change);

// 或者如果不需要前 10 個內部有序，只需找出前 10 個:
// ✅ Nth Element: O(N)
std::nth_element(data.begin(), data.begin() + 10, data.end(), compare_change);
```

### 案例 2: 訂單簿價格查找

**場景**: 在 L2 Order Book (已按價格排序) 中查找特定價格的 Level，如果不存在則插入。

**實現**:

```cpp
struct Level { double price; double qty; };
std::vector<Level> bids; // 降序排列: 100, 99, 98...

void update_bid(double price, double qty) {
    // 使用二分查找
    // 注意: 因為是降序，比較器要反過來
    auto it = std::lower_bound(bids.begin(), bids.end(), price,
        [](const Level& l, double p) { return l.price > p; });

    if (it != bids.end() && it->price == price) {
        if (qty == 0) bids.erase(it);
        else it->qty = qty;
    } else if (qty > 0) {
        bids.insert(it, {price, qty});
    }
}
```

### 案例 3: VWAP 計算 (並行算法)

**場景**: 計算成交量加權平均價格 (VWAP)。
VWAP = Sum(Price \* Volume) / Sum(Volume)

**實現**:

```cpp
#include <execution> // C++17 並行算法

double calculate_vwap(const std::vector<Trade>& trades) {
    // 並行計算總成交額 (Price * Volume)
    double total_turnover = std::transform_reduce(
        std::execution::par_unseq, // 並行 + 向量化
        trades.begin(), trades.end(),
        0.0,
        std::plus<>(), // Reduce 操作
        [](const Trade& t) { return t.price * t.volume; } // Transform 操作
    );

    // 並行計算總成交量
    double total_volume = std::reduce(
        std::execution::par_unseq,
        trades.begin(), trades.end(),
        0.0,
        [](double sum, const Trade& t) { return sum + t.volume; }
    );

    return total_turnover / total_volume;
}
```

## 性能分析

### 1. 算法複雜度對照

| 算法            | 時間複雜度 | 說明                    |
| :-------------- | :--------- | :---------------------- |
| `find`          | O(N)       | 線性掃描                |
| `binary_search` | O(log N)   | 需有序                  |
| `sort`          | O(N log N) | 快排/堆排/插排混合      |
| `partial_sort`  | O(N log K) | 堆排序                  |
| `nth_element`   | O(N)       | 快速選擇 (Quick Select) |
| `push_heap`     | O(log N)   | 堆操作                  |

### 2. 並行算法 (C++17)

使用 `std::execution::par` 或 `std::execution::par_unseq` 可以利用多核 CPU 加速算法。

- **seq**: 順序執行 (默認)
- **par**: 並行執行 (多線程)
- **par_unseq**: 並行 + 向量化 (SIMD)

**注意**: 數據量太小時 (如 < 10000)，並行開銷可能導致性能下降。

## 最佳實踐

1. **優先使用標準算法**: 不要手寫循環，標準算法通常經過高度優化 (如循環展開、SIMD)。
2. **利用有序性**: 如果數據已有序，務必使用 `binary_search`, `lower_bound` 等 O(log N) 算法。
3. **減少拷貝**: 使用 `std::move_iterator` 或在 Lambda 中使用引用。
4. **C++20 Ranges**: 在進行多步數據處理時，優先使用 Ranges Views，避免產生中間容器。
5. **Top-K 優化**: 永遠不要為了取前 K 個元素而對全量數據進行 `sort`，使用 `partial_sort` 或 `nth_element`。
