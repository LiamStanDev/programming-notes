## 1. 左值與右值

### 1.1 基本概念

```cpp
int x = 10;  // x 是左值 (有名字,可取地址)
int y = 20;  // y 是左值

int z = x + y;  // x+y 是右值 (臨時值,無名字)

// 左值引用
int& lref = x;  // OK
// int& bad = 10;  // Error! 不能綁定右值

// const 左值引用可綁定右值
const int& cref = 10;  // OK
const int& cref2 = x + y;  // OK

// 右值引用 (C++11)
int&& rref = 10;  // OK
int&& rref2 = x + y;  // OK
// int&& bad = x;  // Error! 不能綁定左值
```

**記憶技巧**:

- **左值**: 可以出現在賦值號左邊 (有地址)
- **右值**: 只能出現在賦值號右邊 (臨時值)

### 1.2 值類別 (Value Categories)

C++11 引入五種值類別:

```cpp
// lvalue: 有名字的對象
std::string s1 = "hello";
int x = 10;

// prvalue (pure rvalue): 純右值,臨時對象
std::string{"world"};
42;
true;

// xvalue (expiring value): 將亡值,即將銷毀的對象
std::move(s1);
std::string{"temp"}.substr(0, 2);

// glvalue (generalized lvalue) = lvalue + xvalue
// rvalue = prvalue + xvalue
```

**重要規則**:

1. **有名字的為左值**,沒有名字的為右值
2. `A&& arg` 為一個右值引用**類型**,但 arg 本身為**左值** (因為有名字)

```cpp
void process(std::string&& s) {
    // s 的類型是右值引用
    // 但 s 本身是左值 (有名字)

    // 需要 std::move 才能再次作為右值
    std::string s2 = std::move(s);
}
```

## 2. 移動語義基礎

### 2.1 為何需要移動?

```cpp
// C++11 前: 低效的拷貝
std::vector<int> create_large_vector() {
    std::vector<int> v(1'000'000);
    // ... 填充數據
    return v;  // 拷貝整個 vector!
}

std::vector<int> v = create_large_vector();  // O(n) 拷貝

// C++11 後: 高效的移動
std::vector<int> v = create_large_vector();  // O(1) 移動
// 編譯器自動使用移動語義 (RVO/NRVO)
```

### 2.2 std::move - 轉為右值

```cpp
std::vector<int> v1 = {1, 2, 3};
std::vector<int> v2 = std::move(v1);  // 移動,不拷貝

// v1 現在處於"有效但未指定"狀態
// 可以: v1.clear(), v1 = other_vec
// 不要: 訪問 v1 的元素!

std::cout << v1.size() << "\n";  // 可能是 0,也可能不是
```

**std::move 的本質**:

```cpp
// std::move 只是類型轉換,不做任何事
template<typename T>
typename std::remove_reference<T>::type&& move(T&& t) noexcept {
    return static_cast<typename std::remove_reference<T>::type&&>(t);
}

// 等價於:
std::vector<int> v2 = static_cast<std::vector<int>&&>(v1);
```

### 2.3 移動建構函式與移動賦值

```cpp
class String {
    char* data_;
    size_t size_;

public:
    // 建構函式
    String(const char* str) {
        size_ = strlen(str);
        data_ = new char[size_ + 1];
        strcpy(data_, str);
    }

    // 拷貝建構函式
    String(const String& other) {
        size_ = other.size_;
        data_ = new char[size_ + 1];
        strcpy(data_, other.data_);
    }

    // 移動建構函式
    String(String&& other) noexcept {
        data_ = other.data_;
        size_ = other.size_;
        other.data_ = nullptr;  // 重置源對象
        other.size_ = 0;
    }

    // 拷貝賦值
    String& operator=(const String& other) {
        if (this != &other) {
            delete[] data_;
            size_ = other.size_;
            data_ = new char[size_ + 1];
            strcpy(data_, other.data_);
        }
        return *this;
    }

    // 移動賦值
    String& operator=(String&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = other.data_;
            size_ = other.size_;
            other.data_ = nullptr;
            other.size_ = 0;
        }
        return *this;
    }

    ~String() {
        delete[] data_;
    }
};
```

**關鍵點**:

- 移動操作應標記為 `noexcept`
- 移動後源對象應處於有效狀態
- 使用 `std::exchange` 簡化代碼

```cpp
// 使用 std::exchange 簡化移動建構函式
String(String&& other) noexcept
    : data_(std::exchange(other.data_, nullptr))
    , size_(std::exchange(other.size_, 0)) {}
```

## 3. Rule of Five

### 3.1 五大特殊成員函數

如果需要自定義其中一個,通常需要全部:

1. 解構函式
2. 拷貝建構函式
3. 拷貝賦值運算子
4. 移動建構函式
5. 移動賦值運算子

```cpp
class Buffer {
    char* data_;
    size_t size_;

public:
    // 1. 解構函式
    ~Buffer() {
        delete[] data_;
    }

    // 2. 拷貝建構函式
    Buffer(const Buffer& other)
        : data_(new char[other.size_]), size_(other.size_) {
        std::memcpy(data_, other.data_, size_);
    }

    // 3. 拷貝賦值運算符
    Buffer& operator=(const Buffer& other) {
        if (this != &other) {
            Buffer temp(other);  // Copy-and-swap idiom
            swap(temp);
        }
        return *this;
    }

    // 4. 移動建構函式
    Buffer(Buffer&& other) noexcept
        : data_(std::exchange(other.data_, nullptr))
        , size_(std::exchange(other.size_, 0)) {}

    // 5. 移動賦值運算符
    Buffer& operator=(Buffer&& other) noexcept {
        if (this != &other) {
            delete[] data_;
            data_ = std::exchange(other.data_, nullptr);
            size_ = std::exchange(other.size_, 0);
        }
        return *this;
    }

    void swap(Buffer& other) noexcept {
        std::swap(data_, other.data_);
        std::swap(size_, other.size_);
    }
};
```

### 3.2 Rule of Zero

**優先使用 Rule of Zero**: 讓編譯器自動生成

```cpp
// ❌ 不好: 手動管理資源
class BadOrderBook {
    Order* orders_;
    size_t capacity_;
public:
    BadOrderBook() : orders_(new Order[100]), capacity_(100) {}
    ~BadOrderBook() { delete[] orders_; }
    // 需要定義拷貝/移動...
};

// ✅ 好: 使用標準容器
class GoodOrderBook {
    std::vector<Order> orders_;
public:
    GoodOrderBook() : orders_(100) {}
    // 編譯器自動生成正確的拷貝/移動
};
```

### 3.3 = default 與 = delete

```cpp
class NonCopyable {
public:
    NonCopyable() = default;
    ~NonCopyable() = default;

    // 禁止拷貝
    NonCopyable(const NonCopyable&) = delete;
    NonCopyable& operator=(const NonCopyable&) = delete;

    // 允許移動
    NonCopyable(NonCopyable&&) = default;
    NonCopyable& operator=(NonCopyable&&) = default;
};
```

## 4. 完美轉發

### 4.1 萬能引用 (Universal Reference)

```cpp
template<typename T>
void wrapper(T&& arg) {  // T&& 不一定是右值引用!
    // 引用折疊規則:
    // T& && -> T&
    // T&& && -> T&&
    process(std::forward<T>(arg));
}

int x = 10;
wrapper(x);          // T = int&, arg 類型為 int&
wrapper(10);         // T = int,  arg 類型為 int&&
wrapper(std::move(x)); // T = int,  arg 類型為 int&&
```

**萬能引用的條件**:

1. 必須是模板參數 `T&&`
2. 必須有類型推導

```cpp
// ✅ 萬能引用
template<typename T>
void f(T&& arg);

// ❌ 不是萬能引用 (沒有類型推導)
void f(std::string&& arg);

// ❌ 不是萬能引用 (const 修飾)
template<typename T>
void f(const T&& arg);
```

### 4.2 std::forward 實現原理

```cpp
// 簡化版實現
template<typename T>
constexpr T&& forward(std::remove_reference_t<T>& arg) noexcept {
    return static_cast<T&&>(arg);
}

// 使用案例: 工廠函數
template<typename T, typename... Args>
std::unique_ptr<T> make_unique(Args&&... args) {
    return std::unique_ptr<T>(new T(std::forward<Args>(args)...));
}
```

### 4.3 完美轉發的應用

```cpp
// 問題: 如何保持參數的值類別?
template<typename T>
void wrapper(T arg) {
    process(arg);  // 總是拷貝!
}

// ✅ 解決: 完美轉發
template<typename T>
void wrapper(T&& arg) {  // 萬能引用
    process(std::forward<T>(arg));  // 保持值類別
}

void process(int& x) { std::cout << "Lvalue\n"; }
void process(int&& x) { std::cout << "Rvalue\n"; }

int x = 10;
wrapper(x);   // 調用 process(int&)
wrapper(20);  // 調用 process(int&&)
```

### 4.4 變參模板 + 完美轉發

```cpp
// 高頻交易: 訊息構造與轉發
template<typename MsgType, typename... Args>
void send_message(Args&&... args) {
    MsgType msg(std::forward<Args>(args)...);
    network_send(std::move(msg));
}

// 使用
send_message<OrderRequest>(symbol, price, quantity);
send_message<CancelRequest>(order_id);
```

## 5. 移動語義最佳實踐

### 5.1 返回值優化 (RVO/NRVO)

```cpp
// ✅ 按值返回 (依賴 RVO/NRVO)
std::vector<Trade> get_trades() {
    std::vector<Trade> trades;
    // ... 填充
    return trades;  // 不要 std::move(trades)!
}

// ❌ 錯誤: 阻礙 RVO
std::vector<Trade> get_trades_bad() {
    std::vector<Trade> trades;
    return std::move(trades);  // 多餘的 move!
}

// RVO (Return Value Optimization): 直接在調用者的記憶體構造
// NRVO (Named RVO): 對有名字的對象也能優化
```

### 5.2 Sink 參數模式

```cpp
class OrderManager {
    std::vector<Order> pending_orders_;

public:
    // ✅ Sink 參數: 按值傳遞 + 移動
    void add_order(Order order) {
        pending_orders_.push_back(std::move(order));
    }
};

// 使用方式
Order o = create_order();
manager.add_order(std::move(o));  // 移動
manager.add_order(create_order()); // 移動 (臨時對象)
manager.add_order(o);  // 拷貝 (如果還需要 o)
```

### 5.3 移動語義與容器

```cpp
std::vector<std::string> vec;

// ✅ 預分配避免重新分配
vec.reserve(100);

// ✅ 使用 emplace_back (就地構造)
vec.emplace_back("hello");  // 直接構造,無拷貝/移動

// ✅ push_back 右值 (移動)
std::string s = "world";
vec.push_back(std::move(s));

// ❌ push_back 左值 (拷貝)
vec.push_back(s);  // 拷貝
```

### 5.4 移動後的狀態

```cpp
std::vector<int> v1 = {1, 2, 3};
std::vector<int> v2 = std::move(v1);

// v1 處於"有效但未指定"狀態
// ✅ 可以:
v1.clear();           // OK
v1 = {4, 5, 6};       // OK
v1.push_back(7);      // OK

// ❌ 不要:
// int x = v1[0];     // UB! 未指定狀態
// v1.size();         // 可能是 0,也可能不是
```

### 5.5 noexcept 的重要性

```cpp
class Widget {
public:
    // ✅ 移動操作應標記為 noexcept
    Widget(Widget&&) noexcept;
    Widget& operator=(Widget&&) noexcept;
};

// 為什麼重要?
std::vector<Widget> vec;
vec.push_back(Widget{});

// 如果移動建構函式不是 noexcept:
// - vector 重新分配時會拷貝而非移動 (強異常保證)
// - 性能大幅下降!
```

## 6. 高頻交易應用

### 6.1 零拷貝訊息傳遞

```cpp
class Message {
    std::vector<uint8_t> buffer_;

public:
    explicit Message(size_t size) : buffer_(size) {}

    // 移動語義: 零拷貝傳遞
    Message(Message&&) noexcept = default;
    Message& operator=(Message&&) noexcept = default;

    // 禁止拷貝
    Message(const Message&) = delete;
    Message& operator=(const Message&) = delete;

    uint8_t* data() { return buffer_.data(); }
    size_t size() const { return buffer_.size(); }
};

// 使用
Message create_order_message() {
    Message msg(1024);
    // ... 填充數據
    return msg;  // RVO: 零拷貝
}

void send_message(Message msg) {  // 按值接收,移動
    // ... 發送
}

send_message(create_order_message());  // 零拷貝!
```

### 6.2 訂單簿更新

```cpp
class OrderBook {
    std::map<Price, std::vector<Order>> bids_;
    std::map<Price, std::vector<Order>> asks_;

public:
    // ✅ 接受右值,移動插入
    void add_order(Order&& order) {
        if (order.side == Side::BUY) {
            bids_[order.price].push_back(std::move(order));
        } else {
            asks_[order.price].push_back(std::move(order));
        }
    }

    // ✅ 批量更新,移動整個容器
    void update_bids(std::map<Price, std::vector<Order>>&& new_bids) {
        bids_ = std::move(new_bids);  // O(1) 移動
    }
};
```

### 6.3 性能對比

```cpp
#include <benchmark/benchmark.h>

struct LargeData {
    std::vector<int> data;
    LargeData() : data(10000) {}
};

// 拷貝
static void BM_Copy(benchmark::State& state) {
    LargeData src;
    for (auto _ : state) {
        LargeData dst = src;  // 拷貝 10000 個整數
        benchmark::DoNotOptimize(dst);
    }
}

// 移動
static void BM_Move(benchmark::State& state) {
    for (auto _ : state) {
        LargeData src;
        LargeData dst = std::move(src);  // O(1) 移動
        benchmark::DoNotOptimize(dst);
    }
}

BENCHMARK(BM_Copy);  // ~10-20μs
BENCHMARK(BM_Move);  // ~0.5μs (20-40x 更快!)
```

### 6.4 環形緩衝區優化

```cpp
template<typename T, size_t N>
class RingBuffer {
    std::array<T, N> buffer_;
    size_t head_ = 0;
    size_t tail_ = 0;

public:
    // ✅ 接受右值,移動插入
    bool push(T&& item) {
        size_t next = (head_ + 1) % N;
        if (next == tail_) return false;

        buffer_[head_] = std::move(item);  // 移動
        head_ = next;
        return true;
    }

    // ✅ 移動彈出
    bool pop(T& item) {
        if (tail_ == head_) return false;

        item = std::move(buffer_[tail_]);  // 移動
        tail_ = (tail_ + 1) % N;
        return true;
    }
};

// 使用
RingBuffer<Order, 1024> order_queue;
order_queue.push(create_order());  // 移動插入
```
