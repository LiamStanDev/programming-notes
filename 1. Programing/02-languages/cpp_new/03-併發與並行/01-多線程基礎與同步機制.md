## 概述

多線程編程是高頻交易系統的基礎,本章涵蓋:

- **執行緒管理**: std::thread、生命週期、參數傳遞  
- **同步機制**: mutex、condition_variable、barrier
- **執行緒安全**: race condition、data race、memory ordering
- **HFT 最佳實踐**: CPU 綁定、NUMA 優化、實時調度

**延遲需求**: 關鍵路徑 < 100ns，非關鍵路徑 < 1μs

## 1. std::thread 基礎

### 1.1 執行緒創建與管理

**基本用法:**

```cpp
#include <thread>
#include <iostream>

void worker_function(int id) {
    std::cout << "Worker " << id << " running on thread " 
              << std::this_thread::get_id() << std::endl;
}

class Worker {
public:
    void operator()(int id) {
        std::cout << "Functor worker " << id << std::endl;
    }
};

void thread_basics() {
    // 1. 函數指針
    std::thread t1(worker_function, 1);
    
    // 2. Lambda 表達式
    std::thread t2([](int id) {
        std::cout << "Lambda worker " << id << std::endl;
    }, 2);
    
    // 3. 函數物件
    Worker w;
    std::thread t3(w, 3);
    
    // 4. 成員函數
    class MyClass {
    public:
        void method(int id) { 
            std::cout << "Member function worker " << id << std::endl; 
        }
    };
    
    MyClass obj;
    std::thread t4(&MyClass::method, &obj, 4);
    
    // 等待所有執行緒完成
    t1.join();
    t2.join();
    t3.join();
    t4.join();
}
```

### 1.3 執行緒生命週期管理

```cpp
#include <thread>
#include <vector>

class ThreadManager {
public:
    void start_workers(int count) {
        for (int i = 0; i < count; ++i) {
            threads_.emplace_back([this, i]() {
                worker_loop(i);
            });
        }
    }
    
    void stop_all() {
        // 設置停止標誌
        stop_flag_ = true;
        
        // 等待所有執行緒完成
        for (auto& t : threads_) {
            if (t.joinable()) {
                t.join();
            }
        }
        threads_.clear();
    }
    
    ~ThreadManager() {
        stop_all();
    }
    
private:
    void worker_loop(int id) {
        while (!stop_flag_) {
            // 執行工作
            std::this_thread::sleep_for(std::chrono::milliseconds(100));
        }
    }
    
    std::vector<std::thread> threads_;
    std::atomic<bool> stop_flag_{false};
};
```

## 2. 同步機制

### 2.1 互斥量 (Mutex)

**std::mutex 基礎:**

```cpp
#include <mutex>
#include <iostream>

class Counter {
public:
    void increment() {
        std::lock_guard<std::mutex> lock(mtx_);
        ++count_;
    }
    
    void decrement() {
        std::lock_guard<std::mutex> lock(mtx_);
        --count_;
    }
    
    int get() const {
        std::lock_guard<std::mutex> lock(mtx_);
        return count_;
    }
    
private:
    mutable std::mutex mtx_;
    int count_ = 0;
};

// 多執行緒使用
void mutex_example() {
    Counter counter;
    std::vector<std::thread> threads;
    
    // 啟動多個執行緒進行計數
    for (int i = 0; i < 10; ++i) {
        threads.emplace_back([&counter]() {
            for (int j = 0; j < 1000; ++j) {
                counter.increment();
            }
        });
    }
    
    // 等待所有執行緒完成
    for (auto& t : threads) {
        t.join();
    }
    
    std::cout << "Final count: " << counter.get() << std::endl; // 應該是 10000
}
```

**鎖的類型和使用:**

```cpp
#include <mutex>
#include <shared_mutex>

class DataManager {
public:
    // 寫操作 - 獨占鎖
    void update_data(const std::string& new_data) {
        std::unique_lock<std::shared_mutex> lock(rw_mtx_);
        data_ = new_data;
    }
    
    // 讀操作 - 共享鎖
    std::string read_data() const {
        std::shared_lock<std::shared_mutex> lock(rw_mtx_);
        return data_;
    }
    
    // 條件鎖定
    bool try_update(const std::string& new_data) {
        std::unique_lock<std::shared_mutex> lock(rw_mtx_, std::try_to_lock);
        if (lock.owns_lock()) {
            data_ = new_data;
            return true;
        }
        return false;
    }
    
    // 超時鎖定
    bool timed_update(const std::string& new_data, int timeout_ms) {
        std::unique_lock<std::shared_mutex> lock(rw_mtx_, std::defer_lock);
        if (lock.try_lock_for(std::chrono::milliseconds(timeout_ms))) {
            data_ = new_data;
            return true;
        }
        return false;
    }
    
private:
    mutable std::shared_mutex rw_mtx_;
    std::string data_;
};
```

### 2.2 條件變數 (Condition Variable)

**基本生產者-消費者模式:**

```cpp
#include <condition_variable>
#include <queue>

template<typename T>
class ThreadSafeQueue {
public:
    void push(T item) {
        std::lock_guard<std::mutex> lock(mtx_);
        queue_.push(std::move(item));
        cv_.notify_one();
    }
    
    bool pop(T& item) {
        std::unique_lock<std::mutex> lock(mtx_);
        
        // 等待直到有元素或被中斷
        cv_.wait(lock, [this] { return !queue_.empty() || shutdown_; });
        
        if (shutdown_ && queue_.empty()) {
            return false; // 已關閉且無元素
        }
        
        item = std::move(queue_.front());
        queue_.pop();
        return true;
    }
    
    bool pop_timeout(T& item, int timeout_ms) {
        std::unique_lock<std::mutex> lock(mtx_);
        
        if (cv_.wait_for(lock, std::chrono::milliseconds(timeout_ms),
                        [this] { return !queue_.empty() || shutdown_; })) {
            if (shutdown_ && queue_.empty()) {
                return false;
            }
            item = std::move(queue_.front());
            queue_.pop();
            return true;
        }
        return false; // 超時
    }
    
    void shutdown() {
        std::lock_guard<std::mutex> lock(mtx_);
        shutdown_ = true;
        cv_.notify_all();
    }
    
    size_t size() const {
        std::lock_guard<std::mutex> lock(mtx_);
        return queue_.size();
    }
    
private:
    mutable std::mutex mtx_;
    std::condition_variable cv_;
    std::queue<T> queue_;
    bool shutdown_ = false;
};

// 使用範例
void producer_consumer_example() {
    ThreadSafeQueue<int> queue;
    
    // 生產者
    std::thread producer([&queue]() {
        for (int i = 0; i < 100; ++i) {
            queue.push(i);
            std::this_thread::sleep_for(std::chrono::milliseconds(10));
        }
        queue.shutdown();
    });
    
    // 消費者
    std::thread consumer([&queue]() {
        int item;
        while (queue.pop(item)) {
            std::cout << "Consumed: " << item << std::endl;
        }
    });
    
    producer.join();
    consumer.join();
}
```

### 2.3 C++20 Barrier 和 Latch

**std::latch - 一次性同步:**

```cpp
#include <latch>
#include <thread>
#include <vector>

void latch_example() {
    const int num_workers = 4;
    std::latch start_latch(num_workers);
    std::latch done_latch(num_workers);
    
    std::vector<std::thread> workers;
    
    for (int i = 0; i < num_workers; ++i) {
        workers.emplace_back([&, i]() {
            // 初始化工作
            std::cout << "Worker " << i << " initialized\n";
            
            // 等待所有工作執行緒初始化完成
            start_latch.count_down();
            start_latch.wait();
            
            // 開始主要工作
            std::cout << "Worker " << i << " starting main work\n";
            std::this_thread::sleep_for(std::chrono::milliseconds(100));
            
            // 通知完成
            done_latch.count_down();
        });
    }
    
    // 等待所有工作完成
    done_latch.wait();
    std::cout << "All workers completed\n";
    
    for (auto& t : workers) {
        t.join();
    }
}
```

**std::barrier - 可重複使用的同步點:**

```cpp
#include <barrier>

void barrier_example() {
    const int num_phases = 3;
    const int num_workers = 4;
    
    // 創建 barrier，每個階段完成後執行回調
    std::barrier sync_point(num_workers, []() noexcept {
        std::cout << "Phase completed by all workers\n";
    });
    
    std::vector<std::thread> workers;
    
    for (int i = 0; i < num_workers; ++i) {
        workers.emplace_back([&, i]() {
            for (int phase = 0; phase < num_phases; ++phase) {
                // 執行階段工作
                std::cout << "Worker " << i << " working on phase " << phase << "\n";
                std::this_thread::sleep_for(std::chrono::milliseconds(100));
                
                // 等待所有工作執行緒完成此階段
                sync_point.arrive_and_wait();
            }
        });
    }
    
    for (auto& t : workers) {
        t.join();
    }
}
```

## 3. 執行緒安全與競態條件

### 3.1 競態條件 (Race Condition)

**資料競態範例:**

```cpp
#include <thread>
#include <vector>

// ❌ 不安全的程式碼
class UnsafeCounter {
public:
    void increment() {
        // 這三個操作不是原子的:
        // 1. 讀取 count_
        // 2. 增加值
        // 3. 寫入 count_
        ++count_; // 競態條件!
    }
    
    int get() const { return count_; }
    
private:
    int count_ = 0;
};

// ✅ 安全的程式碼 - 使用 mutex
class SafeCounter {
public:
    void increment() {
        std::lock_guard<std::mutex> lock(mtx_);
        ++count_;
    }
    
    int get() const {
        std::lock_guard<std::mutex> lock(mtx_);
        return count_;
    }
    
private:
    mutable std::mutex mtx_;
    int count_ = 0;
};

// ✅ 安全的程式碼 - 使用原子操作
class AtomicCounter {
public:
    void increment() {
        count_.fetch_add(1, std::memory_order_relaxed);
    }
    
    int get() const {
        return count_.load(std::memory_order_relaxed);
    }
    
private:
    std::atomic<int> count_{0};
};
```

### 3.2 死鎖預防

**死鎖範例與解決方案:**

```cpp
#include <mutex>

class Account {
public:
    Account(int id, int balance) : id_(id), balance_(balance) {}
    
    int id() const { return id_; }
    int balance() const { 
        std::lock_guard<std::mutex> lock(mtx_);
        return balance_; 
    }
    
    // ❌ 可能造成死鎖的轉帳
    void transfer_to_deadlock(Account& other, int amount) {
        std::lock_guard<std::mutex> lock1(mtx_);        // 鎖定自己
        std::lock_guard<std::mutex> lock2(other.mtx_);  // 鎖定對方 - 可能死鎖!
        
        if (balance_ >= amount) {
            balance_ -= amount;
            other.balance_ += amount;
        }
    }
    
    // ✅ 避免死鎖的轉帳 - 按 ID 順序鎖定
    void transfer_to_safe(Account& other, int amount) {
        if (id_ < other.id_) {
            std::lock_guard<std::mutex> lock1(mtx_);
            std::lock_guard<std::mutex> lock2(other.mtx_);
            do_transfer(other, amount);
        } else {
            std::lock_guard<std::mutex> lock1(other.mtx_);
            std::lock_guard<std::mutex> lock2(mtx_);
            do_transfer(other, amount);
        }
    }
    
    // ✅ 使用 std::lock 同時鎖定
    void transfer_to_lock(Account& other, int amount) {
        std::lock(mtx_, other.mtx_);
        std::lock_guard<std::mutex> lock1(mtx_, std::adopt_lock);
        std::lock_guard<std::mutex> lock2(other.mtx_, std::adopt_lock);
        
        do_transfer(other, amount);
    }
    
private:
    void do_transfer(Account& other, int amount) {
        if (balance_ >= amount) {
            balance_ -= amount;
            other.balance_ += amount;
        }
    }
    
    int id_;
    int balance_;
    mutable std::mutex mtx_;
};
```

## 4. HFT 專用最佳化

### 4.1 CPU 親和性綁定

```cpp
#include <pthread.h>
#include <sched.h>

class CPUAffinity {
public:
    // 將當前執行緒綁定到指定 CPU
    static bool bind_to_cpu(int cpu_id) {
        cpu_set_t cpuset;
        CPU_ZERO(&cpuset);
        CPU_SET(cpu_id, &cpuset);
        
        return pthread_setaffinity_np(pthread_self(), sizeof(cpuset), &cpuset) == 0;
    }
    
    // 將執行緒綁定到指定 CPU
    static bool bind_thread_to_cpu(std::thread& thread, int cpu_id) {
        cpu_set_t cpuset;
        CPU_ZERO(&cpuset);
        CPU_SET(cpu_id, &cpuset);
        
        return pthread_setaffinity_np(thread.native_handle(), 
                                     sizeof(cpuset), &cpuset) == 0;
    }
    
    // 獲取當前執行緒的 CPU 親和性
    static std::vector<int> get_cpu_affinity() {
        cpu_set_t cpuset;
        CPU_ZERO(&cpuset);
        
        std::vector<int> cpus;
        if (pthread_getaffinity_np(pthread_self(), sizeof(cpuset), &cpuset) == 0) {
            for (int i = 0; i < CPU_SETSIZE; ++i) {
                if (CPU_ISSET(i, &cpuset)) {
                    cpus.push_back(i);
                }
            }
        }
        return cpus;
    }
};

// HFT 執行緒設置範例
void setup_hft_thread(int cpu_id, int priority) {
    // 1. 綁定到指定 CPU
    if (!CPUAffinity::bind_to_cpu(cpu_id)) {
        std::cerr << "Failed to bind to CPU " << cpu_id << std::endl;
        return;
    }
    
    // 2. 設置實時調度策略
    struct sched_param param;
    param.sched_priority = priority;
    
    if (pthread_setschedparam(pthread_self(), SCHED_FIFO, &param) != 0) {
        std::cerr << "Failed to set real-time priority" << std::endl;
    }
    
    // 3. 鎖定記憶體頁面，避免換頁
    if (mlockall(MCL_CURRENT | MCL_FUTURE) != 0) {
        std::cerr << "Failed to lock memory pages" << std::endl;
    }
    
    std::cout << "HFT thread setup complete on CPU " << cpu_id 
              << " with priority " << priority << std::endl;
}
```

### 4.3 實時調度策略

**調度策略比較:**

| 策略          | 延遲      | 確定性 | 適用場景       |
| ------------- | --------- | ------ | -------------- |
| SCHED_OTHER   | ~1-10ms   | 低     | 一般應用       |
| SCHED_BATCH   | ~10-100ms | 低     | 批次處理       |
| SCHED_IDLE    | 不定      | 極低   | 背景任務       |
| SCHED_FIFO    | ~1-100μs  | 高     | HFT 關鍵路徑   |
| SCHED_RR      | ~10-1000μs| 中等   | 多媒體處理     |

```cpp
#include <sched.h>

class SchedulingManager {
public:
    enum class Policy {
        NORMAL = SCHED_OTHER,
        BATCH = SCHED_BATCH,
        IDLE = SCHED_IDLE,
        FIFO = SCHED_FIFO,
        ROUND_ROBIN = SCHED_RR
    };
    
    static bool set_thread_policy(std::thread& thread, Policy policy, int priority = 0) {
        struct sched_param param;
        param.sched_priority = priority;
        
        int policy_int = static_cast<int>(policy);
        return pthread_setschedparam(thread.native_handle(), 
                                   policy_int, &param) == 0;
    }
    
    static bool set_current_policy(Policy policy, int priority = 0) {
        struct sched_param param;
        param.sched_priority = priority;
        
        int policy_int = static_cast<int>(policy);
        return sched_setscheduler(0, policy_int, &param) == 0;
    }
    
    static std::pair<Policy, int> get_current_policy() {
        struct sched_param param;
        int policy = sched_getscheduler(0);
        sched_getparam(0, &param);
        
        return {static_cast<Policy>(policy), param.sched_priority};
    }
};

// HFT 執行緒優先級管理
class HFTPriorityManager {
public:
    static void setup_critical_thread() {
```

```cpp
#include <chrono>

class HighResolutionTimer {
public:
    HighResolutionTimer() : start_(std::chrono::high_resolution_clock::now()) {}
    
    void reset() {
        start_ = std::chrono::high_resolution_clock::now();
    }
    
    double elapsed_ns() const {
        auto end = std::chrono::high_resolution_clock::now();
        return std::chrono::duration<double, std::nano>(end - start_).count();
    }
    
    double elapsed_us() const {
        return elapsed_ns() / 1000.0;
    }
    
    double elapsed_ms() const {
        return elapsed_us() / 1000.0;
    }
    
private:
    std::chrono::high_resolution_clock::time_point start_;
};

// 使用 RDTSC 進行超高精度測量
class RDTSCTimer {
public:
    RDTSCTimer() {
        start_ = rdtsc();
    }
    
    void reset() {
        start_ = rdtsc();
    }
    
    uint64_t elapsed_cycles() const {
        return rdtsc() - start_;
    }
    
    double elapsed_ns() const {
        uint64_t cycles = elapsed_cycles();
        return cycles * ns_per_cycle_;
    }
    
private:
    uint64_t start_;
    static constexpr double ns_per_cycle_ = 0.4; // 2.5 GHz CPU
    
    static uint64_t rdtsc() {
        uint32_t lo, hi;
        __asm__ volatile ("rdtsc" : "=a" (lo), "=d" (hi));
        return ((uint64_t)hi << 32) | lo;
    }
};
```

### 5.2 延遲統計分析

```cpp
#include <vector>
#include <algorithm>
#include <numeric>

class LatencyStatistics {
public:
    void record(double latency_ns) {
        latencies_.push_back(latency_ns);
    }
    
    void print_report() const {
        if (latencies_.empty()) {
            std::cout << "No latency data available\n";
            return;
        }
        
        auto sorted_latencies = latencies_;
        std::sort(sorted_latencies.begin(), sorted_latencies.end());
        
        double sum = std::accumulate(sorted_latencies.begin(), 
                                   sorted_latencies.end(), 0.0);
        double mean = sum / sorted_latencies.size();
        
        size_t count = sorted_latencies.size();
        
        std::cout << "=== 延遲統計報告 ===\n";
        std::cout << "樣本數量: " << count << "\n";
        std::cout << "最小值: " << sorted_latencies[0] << " ns\n";
        std::cout << "平均值: " << mean << " ns\n";
        std::cout << "P50: " << percentile(sorted_latencies, 0.50) << " ns\n";
        std::cout << "P90: " << percentile(sorted_latencies, 0.90) << " ns\n";
        std::cout << "P99: " << percentile(sorted_latencies, 0.99) << " ns\n";
        std::cout << "P99.9: " << percentile(sorted_latencies, 0.999) << " ns\n";
        std::cout << "最大值: " << sorted_latencies.back() << " ns\n";
        
        // 計算標準差
        double variance = 0.0;
        for (double latency : sorted_latencies) {
            variance += (latency - mean) * (latency - mean);
        }
        variance /= count;
        double stddev = std::sqrt(variance);
        std::cout << "標準差: " << stddev << " ns\n";
    }
    
    void clear() {
        latencies_.clear();
    }
    
private:
    std::vector<double> latencies_;
    
    double percentile(const std::vector<double>& sorted_data, double p) const {
        size_t index = static_cast<size_t>(sorted_data.size() * p);
        if (index >= sorted_data.size()) {
            index = sorted_data.size() - 1;
        }
        return sorted_data[index];
    }
};

// 執行緒同步延遲測試
void thread_sync_latency_test() {
    constexpr int NUM_ITERATIONS = 100000;
    LatencyStatistics stats;
    
    std::mutex mtx;
    std::condition_variable cv;
    bool ready = false;
    
    // 測試 mutex + condition_variable 延遲
    std::thread producer([&]() {
        for (int i = 0; i < NUM_ITERATIONS; ++i) {
            RDTSCTimer timer;
            
            // 獲取鎖並通知
            {
                std::lock_guard<std::mutex> lock(mtx);
                ready = true;
            }
            cv.notify_one();
            
            // 重置狀態
            std::this_thread::sleep_for(std::chrono::microseconds(1));
            {
                std::lock_guard<std::mutex> lock(mtx);
                ready = false;
            }
        }
    });
    
    std::thread consumer([&]() {
        for (int i = 0; i < NUM_ITERATIONS; ++i) {
            RDTSCTimer timer;
            
            std::unique_lock<std::mutex> lock(mtx);
            cv.wait(lock, [&] { return ready; });
            
            double latency_ns = timer.elapsed_ns();
            stats.record(latency_ns);
        }
    });
    
    producer.join();
    consumer.join();
    
    stats.print_report();
}
```

```cpp
#include <array>

struct MarketData {
    uint64_t timestamp;
    uint32_t symbol_id;
    double price;
    uint32_t volume;
    char side; // 'B' for bid, 'A' for ask

// 高性能循環緩衝區
template<typename T, size_t Size>
class LockFreeRingBuffer {
public:
    static_assert((Size & (Size - 1)) == 0, "Size must be power of 2");
    
    bool try_push(const T& item) {
        size_t head = head_.load(std::memory_order_relaxed);
        size_t next_head = (head + 1) & (Size - 1);
        
        if (next_head == tail_.load(std::memory_order_acquire)) {
            return false; // 緩衝區滿
        }
        
        buffer_[head] = item;
        head_.store(next_head, std::memory_order_release);
        return true;
    }
    
    bool try_pop(T& item) {
        size_t tail = tail_.load(std::memory_order_relaxed);
        
        if (tail == head_.load(std::memory_order_acquire)) {
            return false; // 緩衝區空
        }
        
        item = buffer_[tail];
        tail_.store((tail + 1) & (Size - 1), std::memory_order_release);
        return true;
    }
    
private:
    alignas(64) std::atomic<size_t> head_{0};
    alignas(64) std::atomic<size_t> tail_{0};
    std::array<T, Size> buffer_;
};

// HFT 市場數據處理系統
class HFTMarketDataSystem {
public:
    HFTMarketDataSystem() {
        // 初始化 NUMA
        NUMAManager::init();
    }
    
    void start() {
        running_ = true;
        
        // 啟動市場數據接收執行緒 (CPU 0, 最高優先級)
        receiver_thread_ = std::thread([this]() {
            setup_hft_thread(0, 99); // CPU 0, priority 99
            receive_market_data();
        });
        
        // 啟動策略執行執行緒 (CPU 1, 高優先級)
        strategy_thread_ = std::thread([this]() {
            setup_hft_thread(1, 90); // CPU 1, priority 90
            process_strategy();
        });
        
        // 啟動訂單發送執行緒 (CPU 2, 高優先級)
        order_thread_ = std::thread([this]() {
            setup_hft_thread(2, 85); // CPU 2, priority 85
            send_orders();
        });
        
        // 啟動風險監控執行緒 (CPU 3, 中等優先級)
        risk_thread_ = std::thread([this]() {
            setup_hft_thread(3, 70); // CPU 3, priority 70
            monitor_risk();
        });
    }
    
    void stop() {
        running_ = false;
        
        if (receiver_thread_.joinable()) receiver_thread_.join();
        if (strategy_thread_.joinable()) strategy_thread_.join();
        if (order_thread_.joinable()) order_thread_.join();
        if (risk_thread_.joinable()) risk_thread_.join();
    }
    
private:
    std::atomic<bool> running_{false};
    
    // 執行緒間通信的無鎖佇列
    LockFreeRingBuffer<MarketData, 65536> md_buffer_;
    LockFreeRingBuffer<Order, 1024> order_buffer_;
    
    // 執行緒
    std::thread receiver_thread_;
    std::thread strategy_thread_;
    std::thread order_thread_;
    std::thread risk_thread_;
    
    // 延遲統計
    LatencyStatistics md_latency_stats_;
    LatencyStatistics order_latency_stats_;
    
    void receive_market_data() {
        std::cout << "市場數據接收執行緒啟動 (CPU 0)\n";
        
        while (running_) {
            // 模擬從網路接收市場數據
            MarketData md;
            if (receive_from_network(md)) {
                RDTSCTimer timer;
                
                // 嘗試推入緩衝區
                while (!md_buffer_.try_push(md) && running_) {
                    // 緩衝區滿，稍作等待
                    std::this_thread::sleep_for(std::chrono::nanoseconds(1));
                }
                
                double latency_ns = timer.elapsed_ns();
                md_latency_stats_.record(latency_ns);
            }
        }
    }
    
    void process_strategy() {
        std::cout << "策略處理執行緒啟動 (CPU 1)\n";
        
        MarketData md;
        while (running_) {
            if (md_buffer_.try_pop(md)) {
                RDTSCTimer timer;
                
                // 執行交易策略
                auto signal = calculate_trading_signal(md);
                
                if (signal.should_trade) {
                    Order order = create_order(signal);
                    
                    // 推入訂單佇列
                    while (!order_buffer_.try_push(order) && running_) {
                        std::this_thread::sleep_for(std::chrono::nanoseconds(1));
                    }
                }
                
                double latency_ns = timer.elapsed_ns();
                // 記錄策略延遲...
            } else {
                // 沒有數據，短暫等待
                std::this_thread::sleep_for(std::chrono::nanoseconds(10));
            }
        }
    }
    
    void send_orders() {
        std::cout << "訂單發送執行緒啟動 (CPU 2)\n";
        
        Order order;
        while (running_) {
            if (order_buffer_.try_pop(order)) {
                RDTSCTimer timer;
                
                // 發送訂單到交易所
                bool success = send_to_exchange(order);
                
                double latency_ns = timer.elapsed_ns();
                order_latency_stats_.record(latency_ns);
                
                if (!success) {
                    std::cerr << "訂單發送失敗\n";
                }
            } else {
                std::this_thread::sleep_for(std::chrono::nanoseconds(10));
            }
        }
    }
    
    void monitor_risk() {
        std::cout << "風險監控執行緒啟動 (CPU 3)\n";
        
        while (running_) {
            // 執行風險檢查
            check_position_limits();
            check_pnl_limits();
            
            // 每毫秒檢查一次
            std::this_thread::sleep_for(std::chrono::milliseconds(1));
        }
    }
    
    // 輔助函數 (模擬實現)
    bool receive_from_network(MarketData& md) {
        // 模擬網路接收
        static uint64_t counter = 0;
        md.timestamp = ++counter;
        md.symbol_id = 1;
        md.price = 100.0 + (counter % 100) * 0.01;
        md.volume = 100;
        md.side = (counter % 2) ? 'B' : 'A';
        
        std::this_thread::sleep_for(std::chrono::microseconds(100));
        return true;
    }
    
    struct TradingSignal {
        bool should_trade = false;
        char side = 'B';
        double price = 0.0;
        uint32_t quantity = 0;
    };
    
    TradingSignal calculate_trading_signal(const MarketData& md) {
        TradingSignal signal;
        
        // 簡單的策略邏輯
        static double last_price = 0.0;
        if (last_price > 0.0) {
            double price_change = md.price - last_price;
            if (std::abs(price_change) > 0.05) {
                signal.should_trade = true;
                signal.side = (price_change > 0) ? 'S' : 'B';
                signal.price = md.price;
                signal.quantity = 100;
            }
        }
        last_price = md.price;
        
        return signal;
    }
    
    struct Order {
        uint32_t symbol_id;
        char side;
        double price;
        uint32_t quantity;
        uint64_t timestamp;

        order.symbol_id = 1;
        order.side = signal.side;
        order.price = signal.price;
        order.quantity = signal.quantity;
        order.timestamp = std::chrono::high_resolution_clock::now()
                           .time_since_epoch().count();
        return order;
```

## 7. 總結

### 7.1 最佳實踐總結

**執行緒管理:**
- ✅ 使用 RAII 管理執行緒生命週期
- ✅ 避免執行緒頻繁創建/銷毀
- ✅ 合理設計執行緒數量 (通常等於 CPU 核心數)

**同步機制選擇:**

| 場景               | 推薦方案         | 延遲      |
| ------------------ | ---------------- | --------- |
| 短期保護           | std::mutex       | ~25ns     |
| 高競爭環境         | std::shared_mutex| ~15ns     |
| 生產者-消費者      | condition_variable| ~1μs      |
| 一次性同步         | std::latch       | ~10ns     |
| 階段性同步         | std::barrier     | ~50ns     |
| 極低延遲           | std::atomic      | ~2-10ns   |

**HFT 特定優化:**
- ✅ CPU 親和性綁定
- ✅ NUMA 感知記憶體分配
- ✅ 實時調度策略 (SCHED_FIFO)
- ✅ 記憶體頁面鎖定
- ✅ 無鎖數據結構
- ✅ 高精度延遲測量
