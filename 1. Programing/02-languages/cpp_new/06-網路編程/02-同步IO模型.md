# 同步 I/O 模型 (Synchronous I/O Models)

## 概述

網路 I/O 模型決定了應用程式如何等待與處理資料,直接影響並發效能與延遲。本章涵蓋 select、poll、epoll 三大 I/O 多路復用機制,以及 Reactor 模式在 HFT 系統中的應用。

## Unix I/O 模型分類

### 五種 I/O 模型

```
1. 阻塞 I/O (Blocking I/O)
   - recv() 阻塞直到資料到達
   - 簡單但無法處理高並發

2. 非阻塞 I/O (Non-blocking I/O)
   - recv() 立即返回 EAGAIN
   - 需要輪詢,浪費 CPU

3. I/O 多路復用 (I/O Multiplexing)
   - select/poll/epoll 監控多個 FD
   - 高並發標準方案

4. 信號驅動 I/O (Signal-driven I/O)
   - SIGIO 信號通知
   - 較少使用

5. 異步 I/O (Asynchronous I/O)
   - io_uring (內核完成資料複製)
   - 真正的零拷貝異步
```

### I/O 模型對比

| 模型 | 第一階段 (等待資料) | 第二階段 (複製資料) | 適用場景 |
|------|-------------------|-------------------|---------|
| 阻塞 I/O | 阻塞 | 阻塞 | 低並發 |
| 非阻塞 I/O | 立即返回 (輪詢) | 阻塞 | 不推薦 (浪費 CPU) |
| I/O 多路復用 | 阻塞 (select/epoll) | 阻塞 | **高並發主流方案** |
| 異步 I/O | 立即返回 | **內核完成** | **HFT 未來趨勢** |

## select - 傳統 I/O 多路復用

### select 基礎

```cpp
#include <sys/select.h>
#include <unistd.h>
#include <iostream>
#include <vector>
#include <algorithm>

// select 系統調用原型
int select(int nfds,                // 最大 fd + 1
          fd_set *readfds,          // 可讀 fd 集合
          fd_set *writefds,         // 可寫 fd 集合
          fd_set *exceptfds,        // 異常 fd 集合
          struct timeval *timeout); // 超時時間

// fd_set 操作巨集
void fd_set_example() {
    fd_set readfds;
    
    FD_ZERO(&readfds);        // 清空集合
    FD_SET(5, &readfds);      // 加入 fd=5
    FD_CLR(5, &readfds);      // 移除 fd=5
    bool isset = FD_ISSET(5, &readfds); // 檢查 fd=5 是否在集合中
}
```

### select 實作範例

```cpp
#include <sys/select.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <cstring>
#include <iostream>
#include <vector>
#include <algorithm>

class SelectServer {
    int listen_fd_;
    std::vector<int> client_fds_;
    
public:
    void start(uint16_t port) {
        // 建立 listening socket
        listen_fd_ = socket(AF_INET, SOCK_STREAM, 0);
        
        int optval = 1;
        setsockopt(listen_fd_, SOL_SOCKET, SO_REUSEADDR, &optval, sizeof(optval));
        
        sockaddr_in server_addr{};
        server_addr.sin_family = AF_INET;
        server_addr.sin_addr.s_addr = INADDR_ANY;
        server_addr.sin_port = htons(port);
        
        bind(listen_fd_, (sockaddr*)&server_addr, sizeof(server_addr));
        listen(listen_fd_, 128);
        
        std::cout << "Server started on port " << port << "\n";
    }
    
    void run() {
        while (true) {
            fd_set readfds;
            FD_ZERO(&readfds);
            
            // 加入 listening socket
            FD_SET(listen_fd_, &readfds);
            int max_fd = listen_fd_;
            
            // 加入所有客戶端 socket
            for (int fd : client_fds_) {
                FD_SET(fd, &readfds);
                max_fd = std::max(max_fd, fd);
            }
            
            // 設定超時 (可選)
            timeval tv{};
            tv.tv_sec = 5;
            tv.tv_usec = 0;
            
            // 等待事件
            int ret = select(max_fd + 1, &readfds, nullptr, nullptr, &tv);
            
            if (ret < 0) {
                std::cerr << "select() failed\n";
                break;
            } else if (ret == 0) {
                // 超時
                std::cout << "Timeout\n";
                continue;
            }
            
            // 檢查 listening socket
            if (FD_ISSET(listen_fd_, &readfds)) {
                int client_fd = accept(listen_fd_, nullptr, nullptr);
                if (client_fd >= 0) {
                    client_fds_.push_back(client_fd);
                    std::cout << "New client: fd=" << client_fd << "\n";
                }
            }
            
            // 檢查客戶端 socket
            for (auto it = client_fds_.begin(); it != client_fds_.end(); ) {
                int fd = *it;
                
                if (FD_ISSET(fd, &readfds)) {
                    char buffer[1024];
                    ssize_t n = recv(fd, buffer, sizeof(buffer), 0);
                    
                    if (n <= 0) {
                        // 連線關閉或錯誤
                        close(fd);
                        it = client_fds_.erase(it);
                        std::cout << "Client disconnected: fd=" << fd << "\n";
                        continue;
                    }
                    
                    // 處理資料
                    send(fd, buffer, n, 0);  // Echo
                }
                
                ++it;
            }
        }
    }
};
```

### select 缺點

```
1. 效能瓶頸:
   - FD_SETSIZE 限制 (通常 1024)
   - 每次呼叫需複製 fd_set (user → kernel)
   - 內核需線性掃描整個 fd_set (O(N))

2. 使用不便:
   - fd_set 會被修改,每次需重新設定
   - 需手動維護 max_fd

3. HFT 不適用:
   - 高並發下效能差 (C10K 問題)
   - 延遲不可預測
```

## poll - select 改良版

### poll 基礎

```cpp
#include <poll.h>

// poll 系統調用原型
int poll(struct pollfd *fds,    // pollfd 陣列
        nfds_t nfds,            // 陣列大小
        int timeout);           // 超時 (毫秒)

// pollfd 結構
struct pollfd {
    int   fd;        // 檔案描述符
    short events;    // 監控的事件
    short revents;   // 實際發生的事件 (由內核填寫)
};

// events / revents 可用值
POLLIN      // 可讀
POLLOUT     // 可寫
POLLERR     // 錯誤
POLLHUP     // 斷開連線
POLLNVAL    // 無效 fd
```

### poll 實作範例

```cpp
#include <poll.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <vector>
#include <iostream>

class PollServer {
    int listen_fd_;
    std::vector<pollfd> pollfds_;
    
public:
    void start(uint16_t port) {
        listen_fd_ = socket(AF_INET, SOCK_STREAM, 0);
        
        int optval = 1;
        setsockopt(listen_fd_, SOL_SOCKET, SO_REUSEADDR, &optval, sizeof(optval));
        
        sockaddr_in server_addr{};
        server_addr.sin_family = AF_INET;
        server_addr.sin_addr.s_addr = INADDR_ANY;
        server_addr.sin_port = htons(port);
        
        bind(listen_fd_, (sockaddr*)&server_addr, sizeof(server_addr));
        listen(listen_fd_, 128);
        
        // 加入 listening socket
        pollfd pfd{};
        pfd.fd = listen_fd_;
        pfd.events = POLLIN;
        pollfds_.push_back(pfd);
        
        std::cout << "Server started on port " << port << "\n";
    }
    
    void run() {
        while (true) {
            // 等待事件 (1 秒超時)
            int ret = poll(pollfds_.data(), pollfds_.size(), 1000);
            
            if (ret < 0) {
                std::cerr << "poll() failed\n";
                break;
            } else if (ret == 0) {
                // 超時
                continue;
            }
            
            // 遍歷所有 pollfd
            for (size_t i = 0; i < pollfds_.size(); ++i) {
                pollfd& pfd = pollfds_[i];
                
                if (pfd.revents == 0) {
                    continue;  // 無事件
                }
                
                if (pfd.fd == listen_fd_) {
                    // Listening socket 可讀 → 新連線
                    if (pfd.revents & POLLIN) {
                        int client_fd = accept(listen_fd_, nullptr, nullptr);
                        if (client_fd >= 0) {
                            pollfd client_pfd{};
                            client_pfd.fd = client_fd;
                            client_pfd.events = POLLIN;
                            pollfds_.push_back(client_pfd);
                            
                            std::cout << "New client: fd=" << client_fd << "\n";
                        }
                    }
                } else {
                    // 客戶端 socket
                    if (pfd.revents & POLLIN) {
                        char buffer[1024];
                        ssize_t n = recv(pfd.fd, buffer, sizeof(buffer), 0);
                        
                        if (n <= 0) {
                            // 連線關閉
                            close(pfd.fd);
                            pollfds_.erase(pollfds_.begin() + i);
                            --i;  // 調整索引
                            std::cout << "Client disconnected\n";
                        } else {
                            send(pfd.fd, buffer, n, 0);  // Echo
                        }
                    }
                    
                    if (pfd.revents & (POLLERR | POLLHUP)) {
                        // 錯誤或斷線
                        close(pfd.fd);
                        pollfds_.erase(pollfds_.begin() + i);
                        --i;
                    }
                }
            }
        }
    }
};
```

### poll vs select

| 特性 | select | poll |
|------|--------|------|
| FD 數量限制 | 有 (FD_SETSIZE = 1024) | 無 (理論上) |
| 介面 | fd_set (位元陣列) | pollfd 陣列 |
| fd_set 修改 | 是 (需重新設定) | 否 (events/revents 分離) |
| 內核掃描 | O(N) | O(N) |
| HFT 適用性 | ❌ 不推薦 | ❌ 不推薦 |

**poll 改進**:
- 移除 FD 數量限制
- 介面更清晰 (events/revents 分離)

**poll 缺點**:
- 仍需 O(N) 掃描
- 高並發效能差

## epoll - Linux 高效能 I/O 多路復用

### epoll 核心優勢

```
1. 內核資料結構:
   - 紅黑樹: 儲存所有監控的 fd (O(log N) 插入/刪除)
   - 就緒鏈表: 儲存就緒的 fd (O(1) 取得)

2. 效能特性:
   - epoll_wait 僅返回就緒的 fd (不需掃描全部)
   - 時間複雜度: O(就緒 fd 數量)

3. HFT 適用:
   - 支援百萬級並發連線 (C10M)
   - 延遲穩定且低
```

### epoll 三大系統調用

```cpp
#include <sys/epoll.h>

// 1. epoll_create1: 建立 epoll 實例
int epoll_create1(int flags);
// flags: 0 或 EPOLL_CLOEXEC

// 2. epoll_ctl: 控制 epoll 實例
int epoll_ctl(int epfd,              // epoll fd
             int op,                 // 操作
             int fd,                 // 目標 fd
             struct epoll_event *event);

// op 可用值
EPOLL_CTL_ADD   // 新增監控
EPOLL_CTL_MOD   // 修改監控
EPOLL_CTL_DEL   // 移除監控

// 3. epoll_wait: 等待事件
int epoll_wait(int epfd,
              struct epoll_event *events,  // 輸出緩衝區
              int maxevents,               // 最大事件數
              int timeout);                // 超時 (毫秒)

// epoll_event 結構
struct epoll_event {
    uint32_t     events;    // 事件類型
    epoll_data_t data;      // 使用者資料
};

typedef union epoll_data {
    void    *ptr;
    int      fd;
    uint32_t u32;
    uint64_t u64;
} epoll_data_t;

// events 可用值
EPOLLIN     // 可讀
EPOLLOUT    // 可寫
EPOLLERR    // 錯誤
EPOLLHUP    // 斷線
EPOLLET     // Edge-Triggered 模式
EPOLLONESHOT // 一次性觸發
```

### epoll 基本實作

```cpp
#include <sys/epoll.h>
#include <sys/socket.h>
#include <netinet/in.h>
#include <unistd.h>
#include <fcntl.h>
#include <cstring>
#include <iostream>

class EpollServer {
    int listen_fd_;
    int epoll_fd_;
    
public:
    ~EpollServer() {
        if (epoll_fd_ >= 0) close(epoll_fd_);
        if (listen_fd_ >= 0) close(listen_fd_);
    }
    
    void start(uint16_t port) {
        // 建立 listening socket
        listen_fd_ = socket(AF_INET, SOCK_STREAM, 0);
        
        int optval = 1;
        setsockopt(listen_fd_, SOL_SOCKET, SO_REUSEADDR, &optval, sizeof(optval));
        
        sockaddr_in server_addr{};
        server_addr.sin_family = AF_INET;
        server_addr.sin_addr.s_addr = INADDR_ANY;
        server_addr.sin_port = htons(port);
        
        bind(listen_fd_, (sockaddr*)&server_addr, sizeof(server_addr));
        listen(listen_fd_, 128);
        
        // 建立 epoll 實例
        epoll_fd_ = epoll_create1(EPOLL_CLOEXEC);
        if (epoll_fd_ < 0) {
            throw std::runtime_error("epoll_create1() failed");
        }
        
        // 監控 listening socket (Level-Triggered)
        epoll_event ev{};
        ev.events = EPOLLIN;
        ev.data.fd = listen_fd_;
        
        if (epoll_ctl(epoll_fd_, EPOLL_CTL_ADD, listen_fd_, &ev) < 0) {
            throw std::runtime_error("epoll_ctl(ADD) failed");
        }
        
        std::cout << "Server started on port " << port << "\n";
    }
    
    void run() {
        constexpr int MAX_EVENTS = 64;
        epoll_event events[MAX_EVENTS];
        
        while (true) {
            // 等待事件 (無限超時)
            int n = epoll_wait(epoll_fd_, events, MAX_EVENTS, -1);
            
            if (n < 0) {
                if (errno == EINTR) continue;  // 被信號中斷
                std::cerr << "epoll_wait() failed\n";
                break;
            }
            
            // 處理所有就緒事件
            for (int i = 0; i < n; ++i) {
                int fd = events[i].data.fd;
                uint32_t ev = events[i].events;
                
                if (fd == listen_fd_) {
                    // 新連線
                    handle_accept();
                } else {
                    // 客戶端資料
                    if (ev & EPOLLIN) {
                        handle_read(fd);
                    }
                    if (ev & (EPOLLERR | EPOLLHUP)) {
                        handle_close(fd);
                    }
                }
            }
        }
    }
    
private:
    void handle_accept() {
        int client_fd = accept(listen_fd_, nullptr, nullptr);
        if (client_fd < 0) return;
        
        // 加入 epoll 監控
        epoll_event ev{};
        ev.events = EPOLLIN;
        ev.data.fd = client_fd;
        
        epoll_ctl(epoll_fd_, EPOLL_CTL_ADD, client_fd, &ev);
        
        std::cout << "New client: fd=" << client_fd << "\n";
    }
    
    void handle_read(int fd) {
        char buffer[1024];
        ssize_t n = recv(fd, buffer, sizeof(buffer), 0);
        
        if (n <= 0) {
            handle_close(fd);
        } else {
            send(fd, buffer, n, 0);  // Echo
        }
    }
    
    void handle_close(int fd) {
        epoll_ctl(epoll_fd_, EPOLL_CTL_DEL, fd, nullptr);
        close(fd);
        std::cout << "Client closed: fd=" << fd << "\n";
    }
};
```

## epoll 觸發模式: LT vs ET

### Level-Triggered (水平觸發)

```cpp
// 預設模式: EPOLLIN (無 EPOLLET)

// 行為:
// - 只要 fd 有未讀資料,每次 epoll_wait 都返回
// - 允許部分讀取 (不需一次讀完)

// 優點:
// - 編程簡單,不易遺漏資料
// - 相容傳統阻塞 I/O 邏輯

// 缺點:
// - 可能造成 "驚群" (多次觸發)
// - 高並發下效能略差

void level_triggered_example(int epoll_fd, int client_fd) {
    epoll_event ev{};
    ev.events = EPOLLIN;  // 無 EPOLLET
    ev.data.fd = client_fd;
    epoll_ctl(epoll_fd, EPOLL_CTL_ADD, client_fd, &ev);
    
    // 處理邏輯: 可部分讀取
    char buffer[1024];
    ssize_t n = recv(client_fd, buffer, sizeof(buffer), 0);
    
    // 如果剩餘資料,下次 epoll_wait 仍會觸發
}
```

### Edge-Triggered (邊緣觸發)

```cpp
// 高效能模式: EPOLLIN | EPOLLET

// 行為:
// - 僅在 fd 狀態**變化**時觸發 (無資料 → 有資料)
// - 必須讀取**所有資料**直到 EAGAIN

// 要求:
// 1. fd 必須設為非阻塞 (Non-blocking)
// 2. 必須循環讀取直到 EAGAIN

// 優點:
// - 減少系統調用,效能更高
// - HFT 推薦模式

// 缺點:
// - 編程複雜,容易遺漏資料

void edge_triggered_example(int epoll_fd, int client_fd) {
    // 1. 設定非阻塞
    int flags = fcntl(client_fd, F_GETFL, 0);
    fcntl(client_fd, F_SETFL, flags | O_NONBLOCK);
    
    // 2. 註冊 ET 模式
    epoll_event ev{};
    ev.events = EPOLLIN | EPOLLET;  // 邊緣觸發
    ev.data.fd = client_fd;
    epoll_ctl(epoll_fd, EPOLL_CTL_ADD, client_fd, &ev);
    
    // 3. 處理邏輯: 必須循環讀取直到 EAGAIN
    char buffer[1024];
    while (true) {
        ssize_t n = recv(client_fd, buffer, sizeof(buffer), 0);
        
        if (n < 0) {
            if (errno == EAGAIN || errno == EWOULDBLOCK) {
                break;  // 讀完了
            } else {
                // 錯誤處理
                break;
            }
        } else if (n == 0) {
            // 連線關閉
            break;
        } else {
            // 處理資料
            process_data(buffer, n);
        }
    }
}
```

### LT vs ET 完整對比

| 特性 | Level-Triggered (LT) | Edge-Triggered (ET) |
|------|---------------------|---------------------|
| 預設模式 | ✅ 是 | ❌ 否 (需指定 EPOLLET) |
| 觸發條件 | 有未讀資料 | 狀態變化 |
| 觸發次數 | 多次 (直到讀完) | 一次 (除非新資料) |
| 非阻塞要求 | 可選 | **必須** |
| 讀取要求 | 可部分讀取 | **必須讀完** (直到 EAGAIN) |
| 編程難度 | 低 | 高 |
| 效能 | 較低 | **高** (HFT 推薦) |
| 風險 | 低 | 容易遺漏資料 |

## Reactor 模式

### Reactor 核心概念

```
Reactor 是事件驅動架構的標準模式:

┌─────────────────────────────────────────────┐
│             Reactor (Event Loop)            │
│                                             │
│  while (true) {                             │
│      events = epoll_wait(...)               │
│      for event in events:                   │
│          handler = handlers[event.fd]       │
│          handler.handle(event)              │
│  }                                          │
└─────────────────────────────────────────────┘
         ↓                ↓                ↓
    ┌────────┐      ┌────────┐      ┌────────┐
    │Handler1│      │Handler2│      │Handler3│
    └────────┘      └────────┘      └────────┘
```

### 單執行緒 Reactor

```cpp
#include <sys/epoll.h>
#include <unordered_map>
#include <functional>
#include <iostream>

class Reactor {
public:
    using EventHandler = std::function<void(uint32_t events)>;
    
private:
    int epoll_fd_;
    bool running_ = false;
    std::unordered_map<int, EventHandler> handlers_;
    
public:
    Reactor() {
        epoll_fd_ = epoll_create1(EPOLL_CLOEXEC);
        if (epoll_fd_ < 0) {
            throw std::runtime_error("epoll_create1() failed");
        }
    }
    
    ~Reactor() {
        close(epoll_fd_);
    }
    
    // 註冊事件處理器
    void register_handler(int fd, uint32_t events, EventHandler handler) {
        epoll_event ev{};
        ev.events = events;
        ev.data.fd = fd;
        
        if (epoll_ctl(epoll_fd_, EPOLL_CTL_ADD, fd, &ev) < 0) {
            throw std::runtime_error("epoll_ctl(ADD) failed");
        }
        
        handlers_[fd] = std::move(handler);
    }
    
    void unregister_handler(int fd) {
        epoll_ctl(epoll_fd_, EPOLL_CTL_DEL, fd, nullptr);
        handlers_.erase(fd);
    }
    
    // 事件循環
    void run() {
        constexpr int MAX_EVENTS = 1024;
        epoll_event events[MAX_EVENTS];
        running_ = true;
        
        while (running_) {
            int n = epoll_wait(epoll_fd_, events, MAX_EVENTS, -1);
            
            if (n < 0) {
                if (errno == EINTR) continue;
                std::cerr << "epoll_wait() failed\n";
                break;
            }
            
            for (int i = 0; i < n; ++i) {
                int fd = events[i].data.fd;
                uint32_t ev = events[i].events;
                
                auto it = handlers_.find(fd);
                if (it != handlers_.end()) {
                    it->second(ev);  // 呼叫處理器
                }
            }
        }
    }
    
    void stop() {
        running_ = false;
    }
};

// 使用範例
void reactor_example() {
    Reactor reactor;
    
    int server_fd = create_tcp_server(8080);
    
    // 註冊 accept 處理器
    reactor.register_handler(server_fd, EPOLLIN, [&](uint32_t events) {
        if (events & EPOLLIN) {
            int client_fd = accept(server_fd, nullptr, nullptr);
            
            // 註冊客戶端處理器
            reactor.register_handler(client_fd, EPOLLIN, [&, client_fd](uint32_t ev) {
                if (ev & EPOLLIN) {
                    char buffer[1024];
                    ssize_t n = recv(client_fd, buffer, sizeof(buffer), 0);
                    
                    if (n <= 0) {
                        reactor.unregister_handler(client_fd);
                        close(client_fd);
                    } else {
                        send(client_fd, buffer, n, 0);
                    }
                }
            });
        }
    });
    
    reactor.run();
}
```

## 效能對比

### Benchmark: select vs poll vs epoll

```cpp
#include <chrono>
#include <iostream>

// 測試場景: 10,000 個連線,100 個就緒
void benchmark_io_multiplexing(int num_fds, int num_ready) {
    using namespace std::chrono;
    
    // select
    {
        auto start = high_resolution_clock::now();
        
        for (int i = 0; i < 1000; ++i) {
            fd_set readfds;
            FD_ZERO(&readfds);
            for (int j = 0; j < num_fds; ++j) {
                FD_SET(j, &readfds);
            }
            select(num_fds, &readfds, nullptr, nullptr, nullptr);
        }
        
        auto duration = duration_cast<microseconds>(
            high_resolution_clock::now() - start).count();
        
        std::cout << "select: " << duration / 1000 << " μs/op\n";
    }
    
    // poll
    {
        std::vector<pollfd> pollfds(num_fds);
        for (int i = 0; i < num_fds; ++i) {
            pollfds[i].fd = i;
            pollfds[i].events = POLLIN;
        }
        
        auto start = high_resolution_clock::now();
        
        for (int i = 0; i < 1000; ++i) {
            poll(pollfds.data(), pollfds.size(), 0);
        }
        
        auto duration = duration_cast<microseconds>(
            high_resolution_clock::now() - start).count();
        
        std::cout << "poll: " << duration / 1000 << " μs/op\n";
    }
    
    // epoll
    {
        int epoll_fd = epoll_create1(0);
        
        for (int i = 0; i < num_fds; ++i) {
            epoll_event ev{};
            ev.events = EPOLLIN;
            ev.data.fd = i;
            epoll_ctl(epoll_fd, EPOLL_CTL_ADD, i, &ev);
        }
        
        auto start = high_resolution_clock::now();
        
        epoll_event events[128];
        for (int i = 0; i < 1000; ++i) {
            epoll_wait(epoll_fd, events, 128, 0);
        }
        
        auto duration = duration_cast<microseconds>(
            high_resolution_clock::now() - start).count();
        
        std::cout << "epoll: " << duration / 1000 << " μs/op\n";
        
        close(epoll_fd);
    }
}

// 典型結果 (10,000 fds, 100 ready):
// select: ~5000 μs/op (O(N) 掃描)
// poll:   ~3000 μs/op (O(N) 掃描)
// epoll:  ~50 μs/op   (O(就緒數))  ← 100x 快!
```

### 效能總結

| 機制 | 時間複雜度 | FD 限制 | 延遲 | HFT 推薦 |
|------|-----------|---------|------|---------|
| select | O(N) | 1024 | 高 | ❌ 不推薦 |
| poll | O(N) | 無限制 | 高 | ❌ 不推薦 |
| epoll (LT) | O(就緒數) | 無限制 | 低 | ⚠️ 可用 |
| epoll (ET) | O(就緒數) | 無限制 | **極低** | ✅ **強烈推薦** |

## 檢查清單

- [ ] HFT 系統使用 epoll (Linux) 或 kqueue (BSD)
- [ ] 優先使用 Edge-Triggered 模式 (EPOLLET)
- [ ] ET 模式下 fd 必須設為非阻塞
- [ ] ET 模式下必須循環讀取直到 EAGAIN
- [ ] 使用 Reactor 模式組織事件處理邏輯
- [ ] 避免在事件處理器中執行耗時操作
- [ ] 監控 epoll_wait 返回的就緒 fd 數量
- [ ] 設定合理的 maxevents (通常 64-1024)
- [ ] 錯誤處理覆蓋 EINTR, EPOLLERR, EPOLLHUP
- [ ] 考慮使用 EPOLLONESHOT 避免多執行緒競態
