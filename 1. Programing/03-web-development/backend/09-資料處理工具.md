## jq

> 詳細用法請參考 [08-日誌分析工具.md](08-日誌分析工具.md#jq)

### 進階操作

#### 多檔案合併

```bash
$ jq -s '.' file1.json file2.json

[
  {"name": "Alice"},
  {"name": "Bob"}
]
```

#### 轉換為 CSV

```bash
$ cat users.json | jq -r '.[] | [.id, .name, .email] | @csv'

1,"Alice","alice@example.com"
2,"Bob","bob@example.com"
```

#### 修改 JSON

```bash
# 更新欄位
$ jq '.version = "2.0.0"' package.json

# 添加欄位
$ jq '. + {"new_field": "value"}' data.json

# 刪除欄位
$ jq 'del(.unwanted_field)' data.json
```

#### 條件更新

```bash
$ jq '.users[] | if .status == "inactive" then .status = "archived" else . end' data.json
```

## yq

### 命令說明

yq 是 YAML/XML 處理工具,語法類似 jq。

**基本語法:**
```bash
yq [options] <expression> [file]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-i` | 原地修改 |
| `-o` | 輸出格式 |
| `-P` | 美化輸出 |

### 使用場景

1. **設定檔處理**: 讀取/修改 YAML 設定
2. **格式轉換**: YAML/JSON/XML 互轉
3. **CI/CD**: 自動化設定更新

---

### 操作範例

#### 讀取 YAML

```bash
$ cat config.yaml
server:
  host: localhost
  port: 8080
database:
  url: postgres://localhost:5432/db

$ yq '.server.port' config.yaml
8080
```

#### 修改 YAML

```bash
$ yq -i '.server.port = 9090' config.yaml
```

#### YAML 轉 JSON

```bash
$ yq -o json config.yaml

{
  "server": {
    "host": "localhost",
    "port": 8080
  }
}
```

#### JSON 轉 YAML

```bash
$ yq -P -o yaml data.json
```

#### 合併 YAML

```bash
$ yq '. *= load("override.yaml")' base.yaml
```

#### 遍歷和過濾

```bash
# 列出所有 key
$ yq 'keys' config.yaml

# 條件過濾
$ yq '.services[] | select(.enabled == true)' docker-compose.yaml
```

## base64

### 命令說明

base64 進行 Base64 編碼和解碼。

**基本語法:**
```bash
base64 [options] [file]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-d` | 解碼 |
| `-w` | 每行字元數 (0=不換行) |

### 使用場景

1. **資料傳輸**: 編碼二進位資料
2. **認證**: Basic Auth 編碼
3. **設定**: Kubernetes secrets

---

### 操作範例

#### 編碼字串

```bash
$ echo -n "Hello World" | base64
SGVsbG8gV29ybGQ=

# 不換行
$ echo -n "Long string..." | base64 -w 0
```

#### 解碼

```bash
$ echo "SGVsbG8gV29ybGQ=" | base64 -d
Hello World
```

#### 編碼檔案

```bash
$ base64 image.png > image.b64
$ base64 -d image.b64 > image_decoded.png
```

#### Basic Auth

```bash
$ echo -n "username:password" | base64
dXNlcm5hbWU6cGFzc3dvcmQ=

$ curl -H "Authorization: Basic dXNlcm5hbWU6cGFzc3dvcmQ=" https://api.example.com
```

#### Kubernetes Secret

```bash
# 編碼
$ echo -n "my-password" | base64
bXktcGFzc3dvcmQ=

# 在 YAML 中使用
apiVersion: v1
kind: Secret
data:
  password: bXktcGFzc3dvcmQ=
```

## openssl

### 命令說明

openssl 是加密工具箱,用於加解密、憑證管理、雜湊計算等。

**基本語法:**
```bash
openssl <command> [options]
```

### 常用命令

| 命令 | 說明 |
|------|------|
| `enc` | 對稱加解密 |
| `dgst` | 雜湊計算 |
| `genrsa` | 生成 RSA 金鑰 |
| `req` | 憑證請求 |
| `x509` | 憑證管理 |
| `s_client` | SSL 客戶端 |
| `rand` | 生成隨機數 |

### 使用場景

1. **加解密**: 資料保護
2. **憑證管理**: 生成/檢查憑證
3. **雜湊**: 計算摘要
4. **SSL 測試**: 檢查 SSL 連接

---

### 操作範例

#### 雜湊計算

```bash
# MD5
$ echo -n "test" | openssl md5
098f6bcd4621d373cade4e832627b4f6

# SHA256
$ echo -n "test" | openssl dgst -sha256
9f86d081884c7d659a2feaa0c55ad015a3bf4f1b2b0b822cd15d6c15b0f00a08

# 檔案雜湊
$ openssl sha256 file.txt
```

#### 對稱加解密

```bash
# 加密
$ openssl enc -aes-256-cbc -salt -in file.txt -out file.enc -pbkdf2

# 解密
$ openssl enc -aes-256-cbc -d -in file.enc -out file.txt -pbkdf2
```

#### 生成隨機數

```bash
# 生成 32 位元組隨機數 (hex)
$ openssl rand -hex 32
a1b2c3d4e5f6...

# Base64 格式
$ openssl rand -base64 32
```

#### 生成 RSA 金鑰對

```bash
# 生成私鑰
$ openssl genrsa -out private.pem 2048

# 從私鑰導出公鑰
$ openssl rsa -in private.pem -pubout -out public.pem
```

#### 生成自簽憑證

```bash
$ openssl req -x509 -newkey rsa:2048 -keyout key.pem -out cert.pem -days 365 -nodes
```

#### 檢查憑證

```bash
# 查看憑證資訊
$ openssl x509 -in cert.pem -text -noout

# 查看到期日
$ openssl x509 -in cert.pem -enddate -noout
notAfter=Jan 15 10:30:00 2025 GMT
```

#### 測試 SSL 連接

```bash
$ openssl s_client -connect example.com:443

CONNECTED(00000003)
depth=2 O = DigiCert Inc, ...
verify return:1
---
Certificate chain
 0 s:/CN=example.com
   i:/C=US/O=DigiCert Inc/CN=DigiCert SHA2
...
```

#### 檢查憑證鏈

```bash
$ openssl s_client -connect example.com:443 -showcerts
```

## xxd

### 命令說明

xxd 將檔案轉換為十六進位格式,或反向轉換。

**基本語法:**
```bash
xxd [options] [file]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-r` | 反向轉換 (hex 轉 binary) |
| `-p` | 純十六進位輸出 |
| `-l` | 輸出長度 |
| `-s` | 開始位置 |
| `-c` | 每行位元組數 |

### 使用場景

1. **二進位分析**: 查看二進位內容
2. **資料除錯**: 檢查資料格式
3. **Hex 編輯**: 修改二進位檔案

---

### 操作範例

#### 查看十六進位

```bash
$ echo "Hello" | xxd

00000000: 4865 6c6c 6f0a                           Hello.
```

#### 純 Hex 輸出

```bash
$ echo -n "Hello" | xxd -p
48656c6c6f
```

#### Hex 轉二進位

```bash
$ echo "48656c6c6f" | xxd -r -p
Hello
```

#### 查看檔案部分

```bash
# 前 64 位元組
$ xxd -l 64 binary_file

# 從第 100 位元組開始
$ xxd -s 100 -l 32 binary_file
```

#### 修改二進位檔案

```bash
# 1. 轉為 hex
$ xxd file.bin > file.hex

# 2. 編輯 hex
$ vi file.hex

# 3. 轉回 binary
$ xxd -r file.hex > file_modified.bin
```

## 實戰技巧

### API 回應處理

```bash
# 提取並格式化 JSON 回應
$ curl -s https://api.example.com/users | jq '.data[] | {id, name}'

# 轉換為 CSV
$ curl -s https://api.example.com/users | jq -r '.data[] | [.id, .name] | @csv'
```

### 設定檔更新腳本

```bash
#!/bin/bash
# update_config.sh

CONFIG_FILE="config.yaml"

# 更新版本
yq -i '.version = "2.0.0"' "$CONFIG_FILE"

# 更新埠號
yq -i '.server.port = env(PORT)' "$CONFIG_FILE"

# 添加新設定
yq -i '.new_feature.enabled = true' "$CONFIG_FILE"
```

### 憑證到期檢查

```bash
#!/bin/bash
# check_cert.sh

HOST=${1:-example.com}
PORT=${2:-443}

EXPIRY=$(echo | openssl s_client -connect "$HOST:$PORT" 2>/dev/null | \
         openssl x509 -noout -enddate | cut -d= -f2)

EXPIRY_EPOCH=$(date -d "$EXPIRY" +%s)
NOW_EPOCH=$(date +%s)
DAYS_LEFT=$(( (EXPIRY_EPOCH - NOW_EPOCH) / 86400 ))

echo "Certificate for $HOST expires in $DAYS_LEFT days"

if [ "$DAYS_LEFT" -lt 30 ]; then
    echo "WARNING: Certificate expiring soon!"
fi
```
