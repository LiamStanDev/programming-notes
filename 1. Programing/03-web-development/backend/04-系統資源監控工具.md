## htop

### 命令說明

htop 是互動式進程監控工具,提供彩色界面和即時更新,是 top 的增強版本。

**基本語法:**
```bash
htop [options]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-d` | 更新間隔 (十分之一秒) |
| `-u` | 只顯示特定用戶 |
| `-p` | 只顯示特定 PID |
| `-s` | 排序欄位 |
| `-t` | 樹狀顯示 |

### 互動式操作

| 按鍵 | 功能 |
|------|------|
| `F1` | 說明 |
| `F2` | 設定 |
| `F3` | 搜尋 |
| `F4` | 過濾 |
| `F5` | 樹狀顯示 |
| `F6` | 排序 |
| `F9` | 終止進程 |
| `F10` | 退出 |
| `Space` | 標記進程 |
| `u` | 篩選用戶 |
| `k` | 發送信號 |
| `l` | 顯示打開的檔案 |
| `s` | 追蹤系統調用 |

### 使用場景

1. **即時監控**: 查看系統資源使用
2. **進程管理**: 終止或調整進程
3. **效能分析**: 找出資源大戶
4. **故障排查**: 診斷系統問題

---

### 操作範例

#### 基本使用

```bash
$ htop
```

顯示界面:
```
  CPU[||||||||||||||||||||  45.2%]   Tasks: 123, 456 thr; 2 running
  Mem[||||||||||       3.2G/16.0G]   Load average: 1.23 0.98 0.87
  Swp[                   0K/2.0G]   Uptime: 12 days, 03:45:67

  PID USER      PRI  NI  VIRT   RES   SHR S CPU% MEM%   TIME+  Command
12345 www-data   20   0  500M  200M  50M S 45.2  1.2  10:23.45 nginx: worker
12346 mysql      20   0  2.0G  1.5G 100M S 23.4  9.4  45:12.34 mysqld
12347 root       20   0  100M   50M  10M S  5.6  0.3   1:23.45 python app.py
```

**輸出說明:**
- 頂部: CPU、記憶體、Swap 使用率條
- `PRI`: 優先級
- `NI`: Nice 值
- `VIRT`: 虛擬記憶體
- `RES`: 實際記憶體
- `SHR`: 共享記憶體
- `S`: 狀態 (S=睡眠, R=運行, Z=殭屍)

#### 只顯示特定用戶

```bash
$ htop -u www-data
```

#### 樹狀顯示

```bash
$ htop -t
```

或在界面中按 `F5`

#### 按 CPU 排序

```bash
$ htop -s PERCENT_CPU
```

#### 只顯示特定進程

```bash
$ htop -p 12345,12346,12347
```

## vmstat

### 命令說明

vmstat (Virtual Memory Statistics) 報告系統的虛擬記憶體、進程、CPU 活動等統計資訊。

**基本語法:**
```bash
vmstat [options] [interval [count]]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-a` | 顯示活躍/非活躍記憶體 |
| `-s` | 顯示記憶體統計表 |
| `-d` | 顯示磁碟統計 |
| `-w` | 寬輸出格式 |
| `-t` | 添加時間戳 |

### 使用場景

1. **記憶體分析**: 監控記憶體使用和 swap
2. **CPU 分析**: 查看 CPU 使用分佈
3. **系統概覽**: 快速了解系統狀態
4. **瓶頸判斷**: 識別記憶體或 CPU 瓶頸

---

### 操作範例

#### 基本使用

```bash
$ vmstat 1 5

procs -----------memory---------- ---swap-- -----io---- -system-- ------cpu-----
 r  b   swpd   free   buff  cache   si   so    bi    bo   in   cs us sy id wa st
 2  0      0 8388608 102400 4194304  0    0     5    10  100  200  5  2 92  1  0
 1  0      0 8388000 102400 4194500  0    0     0    20  110  220  8  3 88  1  0
 2  0      0 8387500 102400 4194800  0    0     0    15  105  210  6  2 91  1  0
```

**輸出說明:**

**procs (進程)**
- `r`: 運行隊列中的進程數 (等待 CPU)
- `b`: 阻塞等待 I/O 的進程數

**memory (記憶體, KB)**
- `swpd`: 使用的 swap
- `free`: 空閒記憶體
- `buff`: 緩衝區
- `cache`: 快取

**swap**
- `si`: 每秒從 swap 讀入 (swap in)
- `so`: 每秒寫入 swap (swap out)

**io (區塊 I/O)**
- `bi`: 每秒讀取區塊數
- `bo`: 每秒寫入區塊數

**system**
- `in`: 每秒中斷數
- `cs`: 每秒上下文切換數

**cpu (百分比)**
- `us`: 用戶空間
- `sy`: 核心空間
- `id`: 閒置
- `wa`: I/O 等待
- `st`: 被虛擬機偷走

#### 判斷瓶頸

```bash
$ vmstat 1

# CPU 瓶頸: r > CPU 核心數, us+sy 很高
# 記憶體瓶頸: si/so > 0, free 很低
# I/O 瓶頸: wa > 20%, b > 0
```

#### 記憶體統計表

```bash
$ vmstat -s

     16777216 K total memory
      3145728 K used memory
      1048576 K active memory
      2097152 K inactive memory
      8388608 K free memory
       102400 K buffer memory
      5140480 K swap cache
      2097152 K total swap
            0 K used swap
      2097152 K free swap
```

#### 磁碟統計

```bash
$ vmstat -d

disk- ------------reads------------ ------------writes----------- -----IO------
       total merged sectors      ms  total merged sectors      ms    cur    sec
sda   123456   1234 9876543   12345 234567   2345 8765432   23456      0    123
```

## iostat

### 命令說明

iostat (I/O Statistics) 報告 CPU 和磁碟 I/O 統計資訊,用於分析儲存效能。

**基本語法:**
```bash
iostat [options] [interval [count]]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-x` | 顯示擴展統計 |
| `-d` | 只顯示磁碟統計 |
| `-c` | 只顯示 CPU 統計 |
| `-k` | 以 KB 為單位 |
| `-m` | 以 MB 為單位 |
| `-p` | 顯示分區統計 |
| `-t` | 顯示時間戳 |

### 使用場景

1. **磁碟效能分析**: 測量讀寫速度
2. **瓶頸定位**: 找出 I/O 瓶頸
3. **容量規劃**: 評估儲存需求
4. **故障排查**: 診斷 I/O 問題

---

### 操作範例

#### 基本使用

```bash
$ iostat 1 3

Linux 5.15.0-generic (server)     01/15/2024     _x86_64_    (4 CPU)

avg-cpu:  %user   %nice %system %iowait  %steal   %idle
           5.23    0.00    2.34    1.23    0.00   91.20

Device             tps    kB_read/s    kB_wrtn/s    kB_read    kB_wrtn
sda              45.67       234.56       456.78    1234567    2345678
```

**輸出說明:**
- `tps`: 每秒傳輸次數 (I/O 請求數)
- `kB_read/s`: 每秒讀取 KB
- `kB_wrtn/s`: 每秒寫入 KB

#### 擴展統計 (重要)

```bash
$ iostat -x 1

Device  r/s   w/s   rkB/s   wkB/s  rrqm/s wrqm/s %rrqm %wrqm r_await w_await aqu-sz rareq-sz wareq-sz svctm  %util
sda    10.5  20.3  200.0   400.0    0.5    2.3   4.5   10.2   5.2    10.3    0.15    19.0     19.7   2.3   25.5
```

**關鍵指標說明:**
- `r/s, w/s`: 每秒讀/寫次數
- `rkB/s, wkB/s`: 每秒讀/寫 KB
- `r_await, w_await`: 平均讀/寫等待時間 (ms)
- `aqu-sz`: 平均佇列長度
- `%util`: 裝置使用率

#### 判斷 I/O 瓶頸

```bash
$ iostat -x 1

# 瓶頸指標:
# %util > 80%: 裝置繁忙
# await > 10ms (SSD) 或 > 20ms (HDD): 延遲高
# aqu-sz > 1: 佇列堆積
```

#### 只顯示特定裝置

```bash
$ iostat -x sda sdb 1
```

## iotop

### 命令說明

iotop 顯示各進程的 I/O 使用情況,類似 top 但專注於 I/O。

**基本語法:**
```bash
sudo iotop [options]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-o` | 只顯示有 I/O 的進程 |
| `-b` | 批次模式 (非互動) |
| `-n` | 迭代次數 |
| `-d` | 更新間隔 |
| `-p` | 監控特定 PID |
| `-u` | 監控特定用戶 |
| `-a` | 累積模式 |

### 使用場景

1. **找出 I/O 大戶**: 識別高 I/O 進程
2. **效能分析**: 分析進程 I/O 行為
3. **故障排查**: 診斷 I/O 瓶頸原因

---

### 操作範例

#### 基本使用

```bash
$ sudo iotop

Total DISK READ:       5.23 M/s | Total DISK WRITE:      10.45 M/s
Current DISK READ:     5.00 M/s | Current DISK WRITE:    10.00 M/s
  TID  PRIO  USER     DISK READ  DISK WRITE  SWAPIN     IO>    COMMAND
12345 be/4  mysql        4.5 M/s    8.0 M/s  0.00 %  5.23 %  mysqld
12346 be/4  www-data   512.0 K/s    2.0 M/s  0.00 %  2.34 %  nginx
12347 be/4  root       256.0 K/s  512.0 K/s  0.00 %  1.23 %  rsync
```

**輸出說明:**
- `PRIO`: I/O 優先級
- `DISK READ/WRITE`: 讀寫速率
- `SWAPIN`: swap 讀取百分比
- `IO>`: I/O 等待百分比

#### 只顯示活躍進程

```bash
$ sudo iotop -o
```

#### 批次模式輸出

```bash
$ sudo iotop -b -n 3
```

#### 監控特定進程

```bash
$ sudo iotop -p 12345
```

#### 累積模式

```bash
$ sudo iotop -a
# 顯示自啟動以來的累積 I/O
```

## dstat

### 命令說明

dstat 是多功能系統資源統計工具,可同時顯示 CPU、磁碟、網路、記憶體等資訊。

**基本語法:**
```bash
dstat [options] [interval [count]]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-c` | CPU 統計 |
| `-d` | 磁碟統計 |
| `-n` | 網路統計 |
| `-m` | 記憶體統計 |
| `-g` | 分頁統計 |
| `-y` | 系統統計 |
| `-l` | 負載統計 |
| `-p` | 進程統計 |
| `-t` | 顯示時間 |
| `--top-cpu` | 顯示最耗 CPU 的進程 |
| `--top-io` | 顯示最耗 I/O 的進程 |
| `--top-mem` | 顯示最耗記憶體的進程 |

### 使用場景

1. **全面監控**: 同時查看多種資源
2. **效能分析**: 關聯不同指標
3. **報告生成**: 輸出到檔案

---

### 操作範例

#### 基本使用 (預設所有)

```bash
$ dstat

You did not select any stats, using -cdngy by default.
--total-cpu-usage-- -dsk/total- -net/total- ---paging-- ---system--
usr sys idl wai stl| read  writ| recv  send|  in   out | int   csw
  5   2  92   1   0| 200k  400k| 100k  50k |   0     0 | 100   200
  8   3  88   1   0| 150k  300k|  80k  40k |   0     0 | 110   210
```

**輸出說明:**
- 每欄對應不同資源類型
- 數值持續更新

#### 自訂顯示

```bash
$ dstat -cdnm 1

--total-cpu-usage-- -dsk/total- -net/total- ------memory-usage-----
usr sys idl wai stl| read  writ| recv  send| used  buff  cach  free
  5   2  92   1   0| 200k  400k| 100k  50k |3.0G  100M  5.0G  8.0G
```

#### 顯示最耗資源進程

```bash
$ dstat --top-cpu --top-io --top-mem

-most-expensive- ----most-expensive---- --most-expensive-
  cpu process   |     i/o process      |  memory process
mysqld      45.2|mysqld     10M   15M  |mysqld      1.5G
```

#### 輸出到檔案

```bash
$ dstat -t -cdnm --output stats.csv 1 60
```

## sar

### 命令說明

sar (System Activity Reporter) 收集、報告系統活動資訊,可查看歷史數據。

**基本語法:**
```bash
sar [options] [interval [count]]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-u` | CPU 使用率 |
| `-r` | 記憶體使用率 |
| `-b` | I/O 統計 |
| `-d` | 磁碟統計 |
| `-n DEV` | 網路統計 |
| `-q` | 負載和佇列 |
| `-f` | 讀取歷史檔案 |
| `-s` | 開始時間 |
| `-e` | 結束時間 |

### 使用場景

1. **歷史分析**: 查看過去的效能數據
2. **趨勢分析**: 長期效能趨勢
3. **事後分析**: 問題發生後的診斷
4. **報告生成**: 效能報告

---

### 操作範例

#### CPU 使用率

```bash
$ sar -u 1 3

10:30:00        CPU     %user     %nice   %system   %iowait    %steal     %idle
10:30:01        all      5.23      0.00      2.34      1.23      0.00     91.20
10:30:02        all      8.45      0.00      3.12      0.98      0.00     87.45
10:30:03        all      6.78      0.00      2.56      1.45      0.00     89.21
Average:        all      6.82      0.00      2.67      1.22      0.00     89.29
```

#### 記憶體使用率

```bash
$ sar -r 1 3

10:30:00    kbmemfree   kbavail kbmemused  %memused kbbuffers  kbcached
10:30:01      8388608  12582912   3145728     18.75    102400   4194304
```

#### 磁碟 I/O

```bash
$ sar -d 1 3

10:30:01          sda     45.67    234.56    456.78     15.12      0.15
```

#### 網路統計

```bash
$ sar -n DEV 1 3
```

```bash
# 查看今天的數據
```

## 實戰技巧

### 系統健康檢查腳本

```bash
#!/bin/bash
echo "=== System Health Check ==="
echo "Date: $(date)"
echo

echo "=== CPU ==="
mpstat 1 1 | tail -1

echo "=== Memory ==="
free -h

echo "=== Disk I/O ==="
iostat -x 1 1 | grep -E "^Device|^sd"

echo "=== Top Processes ==="
ps aux --sort=-%cpu | head -6
```

### 監控告警腳本

```bash
#!/bin/bash
# 檢查 CPU 使用率
CPU_USAGE=$(vmstat 1 2 | tail -1 | awk '{print 100-$15}')
if (( $(echo "$CPU_USAGE > 80" | bc -l) )); then
    echo "WARNING: High CPU usage: ${CPU_USAGE}%"
fi

# 檢查記憶體
MEM_USAGE=$(free | grep Mem | awk '{print $3/$2 * 100.0}')
if (( $(echo "$MEM_USAGE > 90" | bc -l) )); then
    echo "WARNING: High memory usage: ${MEM_USAGE}%"
fi

# 檢查磁碟 I/O
DISK_UTIL=$(iostat -x 1 2 | grep "^sda" | tail -1 | awk '{print $NF}')
if (( $(echo "$DISK_UTIL > 80" | bc -l) )); then
    echo "WARNING: High disk utilization: ${DISK_UTIL}%"
fi
```
