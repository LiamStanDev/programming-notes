## strace

### 命令說明

strace 追蹤進程的系統調用 (system call) 和信號,是診斷程式行為的利器。

**基本語法:**
```bash
strace [options] <command>
strace [options] -p <pid>
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-p` | 附加到運行中的進程 |
| `-f` | 追蹤子進程 |
| `-c` | 統計模式 |
| `-e` | 過濾系統調用 |
| `-o` | 輸出到檔案 |
| `-T` | 顯示系統調用耗時 |
| `-t` | 顯示時間戳 |
| `-s` | 字串最大長度 |
| `-y` | 顯示檔案路徑 |

### 常用過濾器

```bash
-e trace=file       # 檔案操作
-e trace=network    # 網路操作
-e trace=process    # 進程操作
-e trace=signal     # 信號
-e trace=ipc        # IPC
-e trace=memory     # 記憶體映射
```

### 使用場景

1. **問題診斷**: 找出程式失敗原因
2. **效能分析**: 找出慢的系統調用
3. **行為分析**: 了解程式做什麼
4. **安全分析**: 檢查程式行為

---

### 操作範例

#### 追蹤程式執行

```bash
$ strace ls -l /tmp

execve("/usr/bin/ls", ["ls", "-l", "/tmp"], ...) = 0
brk(NULL)                               = 0x55a1234
openat(AT_FDCWD, "/etc/ld.so.cache", O_RDONLY|O_CLOEXEC) = 3
...
openat(AT_FDCWD, "/tmp", O_RDONLY|O_NONBLOCK|O_CLOEXEC|O_DIRECTORY) = 3
getdents64(3, /* 5 entries */, 32768)   = 160
write(1, "total 12\n-rw-r--r-- 1 root root"..., 123) = 123
close(3)                                = 0
exit_group(0)                           = ?
+++ exited with 0 +++
```

**輸出說明:**
- 左邊: 系統調用名稱和參數
- 右邊: 返回值 (= 後面)
- 負數返回值通常表示錯誤

#### 附加到運行中的進程

```bash
$ sudo strace -p 12345

strace: Process 12345 attached
read(5, "GET / HTTP/1.1\r\nHost: example.c"..., 8192) = 234
write(5, "HTTP/1.1 200 OK\r\nContent-Type: "..., 567) = 567
epoll_wait(4, [{EPOLLIN, {u32=5, u64=5}}], 1024, 30000) = 1
```

#### 統計模式

```bash
$ strace -c ls -l /tmp

% time     seconds  usecs/call     calls    errors syscall
------ ----------- ----------- --------- --------- ----------------
 45.23    0.001234          12       100           read
 23.45    0.000678           6       100           write
 15.67    0.000456           4       100           openat
 10.12    0.000345           3       100           close
  5.53    0.000123           1       100           fstat
------ ----------- ----------- --------- --------- ----------------
100.00    0.002836                   500           total
```

**輸出說明:**
- `% time`: 時間佔比
- `seconds`: 總耗時
- `usecs/call`: 平均每次耗時
- `calls`: 調用次數
- `errors`: 錯誤次數

#### 過濾特定系統調用

```bash
# 只看檔案操作
$ strace -e trace=file ./myapp

openat(AT_FDCWD, "/etc/config.json", O_RDONLY) = 3
read(3, "{\n  \"port\": 8080\n}", 4096) = 18
close(3)                                = 0

# 只看網路操作
$ strace -e trace=network ./myapp

socket(AF_INET, SOCK_STREAM, IPPROTO_TCP) = 3
connect(3, {sa_family=AF_INET, sin_port=htons(3306), sin_addr=inet_addr("127.0.0.1")}, 16) = 0
```

#### 顯示時間資訊

```bash
$ strace -T ./myapp

read(3, "data", 1024)                   = 4 <0.000123>
write(1, "output", 6)                   = 6 <0.000045>
```

`<0.000123>` 表示該調用耗時 123 微秒

#### 追蹤子進程

```bash
$ strace -f ./myapp

[pid 12345] clone(...) = 12346
[pid 12346] execve("/bin/sh", ...) = 0
[pid 12346] read(0, "input", 1024) = 5
```

### 常見問題診斷

#### 檔案找不到

```bash
$ strace ./myapp 2>&1 | grep -E "open|ENOENT"

openat(AT_FDCWD, "/etc/myapp/config.yaml", O_RDONLY) = -1 ENOENT (No such file or directory)
```

**解決**: 建立缺少的檔案或修正路徑

#### 權限問題

```bash
$ strace ./myapp 2>&1 | grep -E "open|EACCES"

openat(AT_FDCWD, "/var/log/myapp.log", O_WRONLY|O_CREAT|O_APPEND) = -1 EACCES (Permission denied)
```

**解決**: 修正檔案權限或以正確用戶執行

#### 連接超時

```bash
$ strace -e trace=network ./myapp

connect(3, {sa_family=AF_INET, sin_port=htons(3306), sin_addr=inet_addr("10.0.0.1")}, 16) = -1 ETIMEDOUT (Connection timed out)
```

**解決**: 檢查網路連通性和防火牆

#### 效能問題

```bash
$ strace -c ./slow_app

% time     seconds  usecs/call     calls    errors syscall
------ ----------- ----------- --------- --------- ----------------
 95.23    5.123456       51234       100           nanosleep
```

**解決**: 檢查程式中的 sleep 或阻塞調用

## ltrace

### 命令說明

ltrace 追蹤程式的函式庫調用,與 strace 類似但追蹤的是 library call。

**基本語法:**
```bash
ltrace [options] <command>
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-c` | 統計模式 |
| `-e` | 過濾函數 |
| `-o` | 輸出到檔案 |
| `-p` | 附加進程 |
| `-S` | 同時顯示系統調用 |

### 使用場景

1. **函式庫除錯**: 追蹤函式庫調用
2. **效能分析**: 找出慢的函數
3. **逆向分析**: 了解程式行為

---

### 操作範例

#### 基本使用

```bash
$ ltrace ./myapp

malloc(1024)                             = 0x55a1234
strcpy(0x55a1234, "Hello")               = 0x55a1234
strlen("Hello")                          = 5
printf("Message: %s\n", "Hello")         = 15
free(0x55a1234)                          = <void>
```

#### 統計模式

```bash
$ ltrace -c ./myapp

% time     seconds  usecs/call     calls      function
------ ----------- ----------- --------- --------------------
 45.23    0.001234          12       100 malloc
 23.45    0.000678           6       100 free
 15.67    0.000456           4       100 strlen
 10.12    0.000345           3       100 strcpy
------ ----------- ----------- --------- --------------------
100.00    0.002713                   400 total
```

#### 過濾特定函數

```bash
$ ltrace -e malloc+free ./myapp

malloc(1024)                             = 0x55a1234
malloc(2048)                             = 0x55a5678
free(0x55a1234)                          = <void>
```

## perf

### 命令說明

perf 是 Linux 核心提供的效能分析工具,用於 CPU profiling、熱點分析、火焰圖生成等。

**基本語法:**
```bash
perf <command> [options]
```

### 常用子命令

| 子命令 | 說明 |
|--------|------|
| `top` | 即時顯示熱點函數 |
| `stat` | 統計效能計數器 |
| `record` | 記錄效能數據 |
| `report` | 分析記錄的數據 |
| `list` | 列出可用事件 |

### 使用場景

1. **CPU 熱點分析**: 找出 CPU 密集函數
2. **效能計數**: 統計 CPU 事件
3. **火焰圖生成**: 視覺化效能數據

---

### 操作範例

#### 即時熱點分析

```bash
$ sudo perf top

Samples: 10K of event 'cycles:ppp', 4000 Hz
Overhead  Shared Object       Symbol
  15.23%  myapp               [.] process_request
  10.45%  libc-2.31.so        [.] __memcpy_avx
   8.67%  myapp               [.] parse_json
   5.34%  libssl.so           [.] EVP_EncryptUpdate
```

**輸出說明:**
- `Overhead`: CPU 佔比
- `Shared Object`: 所屬模組
- `Symbol`: 函數名稱

#### 效能計數

```bash
$ perf stat ./myapp

 Performance counter stats for './myapp':

          1,234.56 msec task-clock                #    0.987 CPUs utilized
               123      context-switches          #    0.100 K/sec
                12      cpu-migrations            #    0.010 K/sec
             5,678      page-faults               #    0.005 M/sec
     3,456,789,012      cycles                    #    2.800 GHz
     1,234,567,890      instructions              #    0.36  insn per cycle
       234,567,890      branches                  #  190.000 M/sec
         1,234,567      branch-misses             #    0.53% of all branches

       1.250456789 seconds time elapsed
```

#### 記錄和分析

```bash
# 記錄
$ sudo perf record -g ./myapp

# 分析
$ sudo perf report

Samples: 10K of event 'cycles:ppp'
Children      Self  Command  Shared Object  Symbol
+ 45.23%    15.23%  myapp    myapp          [.] process_request
+ 30.12%    10.45%  myapp    libc-2.31.so   [.] __memcpy_avx
```

#### 生成火焰圖

```bash
# 記錄
$ sudo perf record -F 99 -g ./myapp

# 轉換格式
$ sudo perf script > out.perf

# 生成火焰圖 (需要 FlameGraph 工具)
$ stackcollapse-perf.pl out.perf > out.folded
$ flamegraph.pl out.folded > flame.svg
```

## pmap

### 命令說明

pmap 顯示進程的記憶體映射情況。

**基本語法:**
```bash
pmap [options] <pid>
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-x` | 擴展格式 |
| `-d` | 設備格式 |
| `-q` | 安靜模式 |

### 使用場景

1. **記憶體分析**: 查看記憶體使用詳情
2. **洩漏診斷**: 找出記憶體增長
3. **載入分析**: 查看載入的庫

---

### 操作範例

#### 基本使用

```bash
$ pmap 12345

12345:   ./myapp
0000555555554000     16K r---- myapp
0000555555558000     32K r-x-- myapp
0000555555560000      8K r---- myapp
0000555555562000      4K r---- myapp
0000555555563000      4K rw--- myapp
00007ffff7d00000   1948K r-x-- libc-2.31.so
...
 total           123456K
```

#### 擴展格式

```bash
$ pmap -x 12345

Address           Kbytes     RSS   Dirty Mode  Mapping
0000555555554000      16      16       0 r---- myapp
0000555555558000      32      32       0 r-x-- myapp
00007ffff7d00000    1948    1024       0 r-x-- libc-2.31.so
...
---------------- ------- ------- -------
total kB          123456   45678    1234
```

**輸出說明:**
- `Kbytes`: 虛擬記憶體大小
- `RSS`: 實際使用的實體記憶體
- `Dirty`: 修改過的頁面
- `Mode`: 權限 (r=讀, w=寫, x=執行)

## 實戰技巧

### 追蹤程式卡住

```bash
# 1. 找出進程 PID
$ pgrep myapp
12345

# 2. 查看在做什麼
$ sudo strace -p 12345

# 常見輸出:
# futex(..., FUTEX_WAIT, ...) -> 等待鎖
# read(fd, ...) -> 等待 I/O
# epoll_wait(...) -> 等待事件
```

### 追蹤網路問題

```bash
$ strace -e trace=network -T ./myapp 2>&1 | grep -E "connect|send|recv"

connect(3, ..., 16) = -1 ECONNREFUSED <0.000123>
```

### 追蹤檔案問題

```bash
$ strace -e trace=file -y ./myapp 2>&1 | grep -E "open|ENOENT|EACCES"
```
