## nc (netcat)

### 命令說明

netcat 被稱為「網路瑞士刀」,是最基礎且強大的網路工具。可用於 TCP/UDP 連接測試、埠掃描、簡易伺服器、檔案傳輸等。

**基本語法:**
```bash
nc [options] <host> <port>
```

### 常用選項

| 選項   | 說明            |
| ---- | ------------- |
| `-l` | 監聽模式 (作為伺服器)  |
| `-p` | 指定本地埠         |
| `-v` | 詳細輸出          |
| `-z` | 掃描模式 (不發送資料)  |
| `-w` | 超時時間 (秒)      |
| `-u` | 使用 UDP        |
| `-n` | 不做 DNS 解析     |
| `-k` | 保持監聽 (接受多個連接) |
| `-e` | 執行程式 (部分版本)   |

### 使用場景

1. **埠連通性測試**: 檢查服務是否可達
2. **簡易伺服器**: 快速建立測試伺服器
3. **檔案傳輸**: 快速傳輸檔案
4. **網路除錯**: 手動發送/接收資料
5. **埠掃描**: 檢查開放埠

---

### 操作範例

#### 測試 TCP 埠連通性

```bash
$ nc -zv 192.168.1.100 80
Connection to 192.168.1.100 80 port [tcp/http] succeeded!

$ nc -zv 192.168.1.100 3306
Connection to 192.168.1.100 3306 port [tcp/mysql] succeeded!

$ nc -zv 192.168.1.100 9999
nc: connect to 192.168.1.100 port 9999 (tcp) failed: Connection refused
```

**輸出說明:**
- `succeeded`: 埠開放且可連接
- `Connection refused`: 埠關閉或服務未啟動
- `timed out`: 網路不通或被防火牆擋住

#### 掃描埠範圍

```bash
$ nc -zv 192.168.1.100 20-25
Connection to 192.168.1.100 21 port [tcp/ftp] succeeded!
Connection to 192.168.1.100 22 port [tcp/ssh] succeeded!
nc: connect to 192.168.1.100 port 20 (tcp) failed: Connection refused
nc: connect to 192.168.1.100 port 23 (tcp) failed: Connection refused
nc: connect to 192.168.1.100 port 24 (tcp) failed: Connection refused
nc: connect to 192.168.1.100 port 25 (tcp) failed: Connection refused
```

#### 設定超時

```bash
$ nc -zv -w 3 192.168.1.100 8080
nc: connect to 192.168.1.100 port 8080 (tcp) failed: Connection timed out
```

#### 測試 UDP 埠

```bash
$ nc -zuv 8.8.8.8 53
Connection to 8.8.8.8 53 port [udp/domain] succeeded!
```

### 簡易伺服器

#### 建立 TCP 伺服器

終端 1 (伺服器):
```bash
$ nc -l -p 8080
# 等待連接...
Hello from client
# 輸入回應:
Hello from server
```

終端 2 (客戶端):
```bash
$ nc localhost 8080
# 輸入訊息:
Hello from client
# 收到回應:
Hello from server
```

#### 持續監聽模式

```bash
$ nc -lk -p 8080
# 持續接受多個連接
```

#### 簡易 HTTP 伺服器

```bash
$ while true; do \
    echo -e "HTTP/1.1 200 OK\r\nContent-Type: text/html\r\n\r\n<h1>Hello</h1>" | \
    nc -l -p 8080 -q 1; \
  done
```

### 檔案傳輸

#### 傳輸檔案

接收端:
```bash
$ nc -l -p 1234 > received_file.tar.gz
```

發送端:
```bash
$ nc 192.168.1.100 1234 < file_to_send.tar.gz
```

#### 傳輸目錄 (配合 tar)

接收端:
```bash
$ nc -l -p 1234 | tar xzvf -
```

發送端:
```bash
$ tar czvf - /path/to/directory | nc 192.168.1.100 1234
```

### 實戰技巧

#### 埠轉發

```bash
# 將本地 8080 轉發到遠端 80
$ nc -l -p 8080 -c "nc example.com 80"
```

#### 聊天室

伺服器:
```bash
$ nc -l -p 1234
```

客戶端:
```bash
$ nc server_ip 1234
```

#### 快速連接測試腳本

```bash
#!/bin/bash
HOST=$1
PORT=$2

if nc -z -w 3 "$HOST" "$PORT" 2>/dev/null; then
    echo "OK: $HOST:$PORT is reachable"
    exit 0
else
    echo "FAIL: $HOST:$PORT is not reachable"
    exit 1
fi
```

## socat

### 命令說明

socat (SOcket CAT) 是 netcat 的進階版本,支援更多協議和功能,包括 SSL/TLS、代理、雙向資料流等。

**基本語法:**
```bash
socat [options] <address1> <address2>
```

### 常用地址類型

| 地址類型 | 說明 |
|----------|------|
| `TCP:host:port` | TCP 客戶端連接 |
| `TCP-LISTEN:port` | TCP 伺服器監聽 |
| `UDP:host:port` | UDP 客戶端 |
| `UDP-LISTEN:port` | UDP 伺服器 |
| `OPENSSL:host:port` | SSL 客戶端 |
| `OPENSSL-LISTEN:port` | SSL 伺服器 |
| `UNIX:path` | Unix socket 客戶端 |
| `UNIX-LISTEN:path` | Unix socket 伺服器 |
| `EXEC:command` | 執行命令 |
| `STDIN` | 標準輸入 |
| `STDOUT` | 標準輸出 |
| `-` | 標準輸入/輸出 |

### 使用場景

1. **SSL/TLS 連接**: 加密連接測試
2. **協議轉換**: 不同協議間轉換
3. **代理**: 連接轉發
4. **Unix socket**: 本地 socket 測試

---

### 操作範例

#### 基本 TCP 連接

```bash
$ socat - TCP:example.com:80
GET / HTTP/1.1
Host: example.com

HTTP/1.1 200 OK
...
```

#### SSL/TLS 連接

```bash
$ socat - OPENSSL:example.com:443,verify=0
GET / HTTP/1.1
Host: example.com

HTTP/1.1 200 OK
...
```

#### 簡易 TCP 伺服器

```bash
$ socat TCP-LISTEN:8080,reuseaddr,fork -
# 接受多個連接
```

#### 埠轉發

```bash
# 將本地 8080 轉發到遠端 80
$ socat TCP-LISTEN:8080,reuseaddr,fork TCP:example.com:80
```

#### SSL 終止代理

```bash
# 接受 SSL 連接,轉發到明文後端
$ socat OPENSSL-LISTEN:443,reuseaddr,fork,cert=server.pem,key=server.key \
        TCP:localhost:80
```

#### Unix Socket 連接

```bash
# 連接 Docker socket
$ socat - UNIX-CONNECT:/var/run/docker.sock
GET /version HTTP/1.1
Host: localhost

{"Version":"20.10.17",...}
```

#### TCP 轉 Unix Socket

```bash
$ socat TCP-LISTEN:2375,reuseaddr,fork UNIX-CONNECT:/var/run/docker.sock
```

---

### 實戰技巧

#### 建立加密通道

伺服器:
```bash
$ socat OPENSSL-LISTEN:4443,reuseaddr,fork,cert=server.pem,key=server.key EXEC:/bin/bash
```

客戶端:
```bash
$ socat - OPENSSL:server:4443,verify=0
```

#### 網路除錯代理

```bash
# 記錄所有流量到檔案
$ socat -v TCP-LISTEN:8080,reuseaddr,fork TCP:backend:80 2>&1 | tee traffic.log
```

#### 模擬慢速網路

```bash
# 限制傳輸速度
$ socat TCP-LISTEN:8080,reuseaddr,fork SYSTEM:'sleep 1; cat' | \
  socat - TCP:backend:80
```

## nmap

### 命令說明

nmap (Network Mapper) 是專業的網路探測和安全稽核工具,用於埠掃描、服務探測、作業系統識別等。

**基本語法:**
```bash
nmap [scan type] [options] <target>
```

### 常用選項

| 選項            | 說明                         |
| ------------- | -------------------------- |
| `-sT`         | TCP connect 掃描             |
| `-sS`         | TCP SYN 掃描 (需 root)        |
| `-sU`         | UDP 掃描                     |
| `-sV`         | 服務版本探測                     |
| `-O`          | 作業系統探測                     |
| `-p`          | 指定埠                        |
| `-F`          | 快速掃描 (常用埠)                 |
| `--top-ports` | 掃描最常用的 N 個埠                |
| `-A`          | 全面掃描 (OS, 版本, 腳本)          |
| `-T`          | 時間模板 (0-5, 越高越快)           |
| `-oN/-oX/-oG` | 輸出格式 (Normal/XML/Grepable) |
| `-sn`         | Ping 掃描 (不掃埠)              |

### 使用場景

1. **埠掃描**: 發現開放服務
2. **服務探測**: 識別服務版本
3. **安全稽核**: 檢查暴露的服務
4. **網路盤點**: 發現網路中的主機

---

### 操作範例

#### 基本埠掃描

```bash
$ nmap 192.168.1.100

Starting Nmap 7.92 ( https://nmap.org )
Nmap scan report for 192.168.1.100
Host is up (0.0010s latency).
Not shown: 997 closed tcp ports (conn-refused)
PORT     STATE SERVICE
22/tcp   open  ssh
80/tcp   open  http
3306/tcp open  mysql

Nmap done: 1 IP address (1 host up) scanned in 0.15 seconds
```

**輸出說明:**
- `open`: 埠開放,有服務監聽
- `closed`: 埠關閉,但可達
- `filtered`: 被防火牆過濾

#### 掃描指定埠

```bash
$ nmap -p 80,443,8080 192.168.1.100

PORT     STATE  SERVICE
80/tcp   open   http
443/tcp  closed https
8080/tcp open   http-proxy
```

#### 掃描埠範圍

```bash
$ nmap -p 1-1000 192.168.1.100
$ nmap -p- 192.168.1.100  # 全部 65535 埠
```

#### 快速掃描常用埠

```bash
$ nmap -F 192.168.1.100
$ nmap --top-ports 100 192.168.1.100
```

#### 服務版本探測

```bash
$ nmap -sV 192.168.1.100

PORT     STATE SERVICE VERSION
22/tcp   open  ssh     OpenSSH 8.2p1 Ubuntu 4ubuntu0.5
80/tcp   open  http    nginx 1.18.0
3306/tcp open  mysql   MySQL 8.0.28
```

#### 作業系統探測

```bash
$ sudo nmap -O 192.168.1.100

OS details: Linux 5.4 - 5.10
```

#### 全面掃描

```bash
$ sudo nmap -A 192.168.1.100

PORT     STATE SERVICE VERSION
22/tcp   open  ssh     OpenSSH 8.2p1
| ssh-hostkey:
|   3072 ...
80/tcp   open  http    nginx 1.18.0
|_http-server-header: nginx/1.18.0
|_http-title: Welcome
```

```bash
$ nmap -oX scan_result.xml 192.168.1.100
```

```bash
$ nmap -oN scan_result.txt 192.168.1.100
```

#### 多種格式

```bash
$ nmap -oA scan_result 192.168.1.100
# 產生 .nmap, .xml, .gnmap 三個檔案
```

### 實戰技巧

#### 快速檢查服務

```bash
#!/bin/bash
# 檢查關鍵服務是否運行
nmap -p 22,80,443,3306,6379 --open 192.168.1.100 | grep "open"
```

#### 掃描多個主機

```bash
$ nmap 192.168.1.100 192.168.1.101 192.168.1.102
$ nmap 192.168.1.100-110
$ nmap -iL hosts.txt  # 從檔案讀取
```

#### 排除主機

```bash
$ nmap 192.168.1.0/24 --exclude 192.168.1.1
```

#### UDP 服務探測

```bash
$ sudo nmap -sU -p 53,123,161 192.168.1.100

PORT    STATE SERVICE
53/udp  open  domain
123/udp open  ntp
161/udp open  snmp
```

#### 防火牆繞過

```bash
# 分片封包
$ sudo nmap -f 192.168.1.100

# 偽裝來源
$ sudo nmap -D RND:10 192.168.1.100
```
