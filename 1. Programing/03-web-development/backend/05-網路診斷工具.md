## ss

### 命令說明

ss (Socket Statistics) 是現代化的 socket 統計工具,用於查看網路連接狀態,比 netstat 更快速。

**基本語法:**
```bash
ss [options] [filter]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-t` | TCP socket |
| `-u` | UDP socket |
| `-l` | 只顯示監聽 |
| `-a` | 所有 socket |
| `-n` | 不解析名稱 |
| `-p` | 顯示進程資訊 |
| `-e` | 顯示擴展資訊 |
| `-i` | 顯示內部 TCP 資訊 |
| `-s` | 顯示摘要統計 |
| `-o` | 顯示計時器資訊 |

### 使用場景

1. **連接狀態查看**: 檢查服務監聽和連接
2. **問題診斷**: 找出連接問題
3. **效能分析**: 查看 TCP 內部狀態
4. **安全檢查**: 檢查異常連接

---

### 操作範例

#### 查看監聽埠

```bash
$ ss -tuln

Netid State  Recv-Q Send-Q Local Address:Port  Peer Address:Port
tcp   LISTEN 0      128    0.0.0.0:22          0.0.0.0:*
tcp   LISTEN 0      511    0.0.0.0:80          0.0.0.0:*
tcp   LISTEN 0      128    127.0.0.1:3306      0.0.0.0:*
udp   UNCONN 0      0      0.0.0.0:53          0.0.0.0:*
```

**輸出說明:**
- `Recv-Q`: 接收佇列 (監聽時為等待 accept 的連接數)
- `Send-Q`: 發送佇列 (監聽時為 backlog 大小)
- `0.0.0.0`: 所有介面
- `127.0.0.1`: 僅本地

#### 顯示進程資訊

```bash
$ sudo ss -tulnp

Netid State  Local Address:Port  Process
tcp   LISTEN 0.0.0.0:80          users:(("nginx",pid=1234,fd=6))
tcp   LISTEN 127.0.0.1:3306      users:(("mysqld",pid=2345,fd=22))
```

#### 查看已建立連接

```bash
$ ss -tn

State  Recv-Q Send-Q Local Address:Port    Peer Address:Port
ESTAB  0      0      192.168.1.100:80      203.0.113.50:54321
ESTAB  0      36     192.168.1.100:22      203.0.113.60:45678
```

#### 按狀態過濾

```bash
# 已建立連接
$ ss -t state established

# TIME-WAIT 連接
$ ss -t state time-wait

# 所有非監聽連接
$ ss -t state connected
```

#### 按埠過濾

```bash
# 來源埠 80
$ ss -tn sport = :80

# 目的埠 3306
$ ss -tn dport = :3306

# 埠範圍
$ ss -tn sport \>= :1024
```

#### 按 IP 過濾

```bash
# 特定目的 IP
$ ss -tn dst 192.168.1.100

# 特定來源 IP
$ ss -tn src 10.0.0.0/8
```

#### 查看 TCP 內部資訊

```bash
$ ss -ti

ESTAB 0 0 192.168.1.100:80 203.0.113.50:54321
     cubic wscale:7,7 rto:204 rtt:1.234/0.567 ato:40 mss:1448 cwnd:10 ssthresh:7 send 94.1Mbps
```

**關鍵指標:**
- `rtt`: 往返時間
- `cwnd`: 擁塞視窗
- `ssthresh`: 慢啟動閾值
- `retrans`: 重傳次數

#### 連接統計摘要

```bash
$ ss -s

Total: 500
TCP:   300 (estab 150, closed 50, orphaned 5, timewait 30)
Transport Total     IP        IPv6
RAW       0         0         0
UDP       20        15        5
TCP       250       200       50
```

## lsof

### 命令說明

lsof (List Open Files) 列出打開的檔案,在 Linux 中網路連接也是檔案。

**基本語法:**
```bash
lsof [options]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-i` | 網路連接 |
| `-p` | 指定 PID |
| `-u` | 指定用戶 |
| `-c` | 指定命令名稱 |
| `-n` | 不解析主機名 |
| `-P` | 不解析埠名 |

### 使用場景

1. **找出埠佔用**: 哪個進程佔用埠
2. **檔案鎖定**: 找出鎖定檔案的進程
3. **連接分析**: 查看進程的網路連接

---

### 操作範例

#### 查看所有網路連接

```bash
$ sudo lsof -i

COMMAND    PID   USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
nginx     1234  nginx    6u  IPv4  12345      0t0  TCP *:http (LISTEN)
mysqld    2345  mysql   22u  IPv4  23456      0t0  TCP localhost:mysql (LISTEN)
sshd      3456   root    3u  IPv4  34567      0t0  TCP 192.168.1.100:ssh->203.0.113.50:54321 (ESTABLISHED)
```

#### 查看特定埠

```bash
$ sudo lsof -i :80

COMMAND  PID  USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
nginx   1234 nginx    6u  IPv4  12345      0t0  TCP *:http (LISTEN)
nginx   1235 nginx    6u  IPv4  12345      0t0  TCP *:http (LISTEN)
```

#### 查看特定進程的連接

```bash
$ sudo lsof -p 1234 -i

COMMAND  PID  USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
nginx   1234 nginx    6u  IPv4  12345      0t0  TCP *:http (LISTEN)
nginx   1234 nginx    7u  IPv4  12346      0t0  TCP 192.168.1.100:http->203.0.113.50:54321 (ESTABLISHED)
```

#### 查看監聽的 TCP

```bash
$ sudo lsof -i TCP -sTCP:LISTEN
```

#### 查看特定用戶的連接

```bash
$ sudo lsof -u www-data -i
```

#### 查看進程打開的檔案

```bash
$ sudo lsof -p 1234

COMMAND  PID USER   FD   TYPE DEVICE  SIZE/OFF    NODE NAME
nginx   1234 root  cwd    DIR    8,1      4096       2 /
nginx   1234 root  txt    REG    8,1   1234567  123456 /usr/sbin/nginx
nginx   1234 root    4u   REG    8,1     12345  234567 /var/log/nginx/access.log
```

## tcpdump

### 命令說明

tcpdump 是命令行封包擷取工具,用於捕獲和分析網路流量。

**基本語法:**
```bash
tcpdump [options] [expression]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-i` | 指定介面 |
| `-n` | 不解析主機名 |
| `-nn` | 不解析主機名和埠名 |
| `-v/-vv/-vvv` | 詳細程度 |
| `-c` | 捕獲封包數 |
| `-w` | 寫入檔案 |
| `-r` | 讀取檔案 |
| `-A` | ASCII 顯示 |
| `-X` | 十六進位+ASCII |
| `-s` | 擷取長度 |

### 使用場景

1. **網路除錯**: 分析請求/回應
2. **問題診斷**: 找出連接問題
3. **安全分析**: 檢查可疑流量
4. **效能分析**: 查看重傳等

---

### 操作範例

#### 基本捕獲

```bash
$ sudo tcpdump -i eth0

tcpdump: verbose output suppressed, use -v[v]... for full protocol decode
listening on eth0, link-type EN10MB (Ethernet), snapshot length 262144 bytes
10:30:15.123456 IP 192.168.1.100.54321 > 8.8.8.8.53: 12345+ A? example.com. (30)
10:30:15.134567 IP 8.8.8.8.53 > 192.168.1.100.54321: 12345 1/0/0 A 93.184.216.34 (46)
```

#### 過濾 host

```bash
$ sudo tcpdump -i eth0 host 192.168.1.100
$ sudo tcpdump -i eth0 src host 192.168.1.100
$ sudo tcpdump -i eth0 dst host 192.168.1.100
```

#### 過濾 port

```bash
$ sudo tcpdump -i eth0 port 80
$ sudo tcpdump -i eth0 src port 80
$ sudo tcpdump -i eth0 dst port 3306
```

#### 過濾協議

```bash
$ sudo tcpdump -i eth0 tcp
$ sudo tcpdump -i eth0 udp
$ sudo tcpdump -i eth0 icmp
```

#### 組合過濾

```bash
# HTTP 流量
$ sudo tcpdump -i eth0 'tcp port 80'

# 特定主機的 HTTP
$ sudo tcpdump -i eth0 'host 192.168.1.100 and tcp port 80'

# 排除 SSH
$ sudo tcpdump -i eth0 'not port 22'

# 多個條件
$ sudo tcpdump -i eth0 'tcp and (port 80 or port 443)'
```

#### 查看封包內容

```bash
# ASCII 內容
$ sudo tcpdump -i eth0 -A 'tcp port 80'

# 十六進位 + ASCII
$ sudo tcpdump -i eth0 -X 'tcp port 80'
```

#### 儲存和讀取

```bash
# 儲存到檔案
$ sudo tcpdump -i eth0 -w capture.pcap

# 讀取檔案
$ tcpdump -r capture.pcap

# 讀取並過濾
$ tcpdump -r capture.pcap 'tcp port 80'
```

#### 進階過濾

```bash
# SYN 封包
$ sudo tcpdump -i eth0 'tcp[tcpflags] & tcp-syn != 0'

# SYN+ACK 封包
$ sudo tcpdump -i eth0 'tcp[tcpflags] & (tcp-syn|tcp-ack) == (tcp-syn|tcp-ack)'

# RST 封包
$ sudo tcpdump -i eth0 'tcp[tcpflags] & tcp-rst != 0'
```

## tshark

### 命令說明

tshark 是 Wireshark 的命令行版本,提供強大的協議解析能力。

**基本語法:**
```bash
tshark [options]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-i` | 指定介面 |
| `-f` | 捕獲過濾器 |
| `-Y` | 顯示過濾器 |
| `-T` | 輸出格式 |
| `-e` | 指定欄位 |
| `-r` | 讀取檔案 |
| `-w` | 寫入檔案 |
| `-q` | 安靜模式 |
| `-z` | 統計選項 |

### 使用場景

1. **協議分析**: 深度協議解析
2. **統計分析**: 流量統計
3. **欄位提取**: 提取特定資料
4. **自動化**: 腳本化分析

---

### 操作範例

#### 基本捕獲

```bash
$ sudo tshark -i eth0
```

#### HTTP 請求分析

```bash
$ sudo tshark -i eth0 -Y "http.request" \
    -T fields -e ip.src -e http.host -e http.request.uri

192.168.1.100    example.com    /api/users
192.168.1.100    example.com    /api/products
```

#### 提取特定欄位

```bash
$ tshark -r capture.pcap -T fields \
    -e frame.time -e ip.src -e ip.dst -e tcp.port
```

#### 統計分析

```bash
# 對話統計
$ tshark -r capture.pcap -q -z conv,tcp

# I/O 統計
$ tshark -r capture.pcap -q -z io,stat,1

# HTTP 請求統計
$ tshark -r capture.pcap -q -z http,tree
```

#### 找出問題

```bash
# TCP 重傳
$ tshark -r capture.pcap -Y "tcp.analysis.retransmission"

# TCP 亂序
$ tshark -r capture.pcap -Y "tcp.analysis.out_of_order"

# TCP 重複 ACK
$ tshark -r capture.pcap -Y "tcp.analysis.duplicate_ack"
```

## dig

### 命令說明

dig (Domain Information Groper) 是 DNS 查詢工具,用於診斷 DNS 問題。

**基本語法:**
```bash
dig [@server] <name> [type]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `+short` | 簡短輸出 |
| `+trace` | 追蹤查詢路徑 |
| `+noall +answer` | 只顯示答案 |
| `-x` | 反向查詢 |

### 使用場景

1. **DNS 查詢**: 解析域名
2. **問題診斷**: DNS 故障排查
3. **記錄檢查**: 查看各類 DNS 記錄

---

### 操作範例

#### 基本查詢

```bash
$ dig example.com

; <<>> DiG 9.16.1 <<>> example.com
;; QUESTION SECTION:
;example.com.                   IN      A

;; ANSWER SECTION:
example.com.            300     IN      A       93.184.216.34

;; Query time: 12 msec
;; SERVER: 8.8.8.8#53(8.8.8.8)
```

#### 簡短輸出

```bash
$ dig +short example.com
93.184.216.34
```

#### 查詢不同記錄類型

```bash
$ dig example.com MX      # 郵件記錄
$ dig example.com NS      # 名稱伺服器
$ dig example.com TXT     # 文字記錄
$ dig example.com AAAA    # IPv6
$ dig example.com CNAME   # 別名
```

#### 指定 DNS 伺服器

```bash
$ dig @8.8.8.8 example.com
$ dig @1.1.1.1 example.com
```

#### 反向查詢

```bash
$ dig -x 8.8.8.8
;; ANSWER SECTION:
8.8.8.8.in-addr.arpa.   21599   IN      PTR     dns.google.
```

#### 追蹤查詢路徑

```bash
$ dig +trace example.com

; <<>> DiG 9.16.1 <<>> +trace example.com
.                       518400  IN      NS      a.root-servers.net.
com.                    172800  IN      NS      a.gtld-servers.net.
example.com.            172800  IN      NS      ns1.example.com.
example.com.            300     IN      A       93.184.216.34
```

## mtr

### 命令說明

mtr 結合 ping 和 traceroute 功能,持續監控路由路徑和延遲。

**基本語法:**
```bash
mtr [options] <host>
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-r` | 報告模式 |
| `-c` | 發送次數 |
| `-n` | 不解析主機名 |
| `-w` | 寬報告模式 |
| `--tcp` | 使用 TCP |
| `-P` | 指定埠 |

### 使用場景

1. **路由分析**: 查看網路路徑
2. **延遲定位**: 找出高延遲節點
3. **丟包分析**: 找出丟包位置

---

### 操作範例

#### 互動模式

```bash
$ mtr google.com

                             My traceroute  [v0.94]
Host:                                         Loss%   Snt   Last   Avg  Best  Wrst StDev
 1. gateway                                    0.0%    10    1.2   1.3   1.1   1.5   0.1
 2. isp-router                                 0.0%    10    5.6   5.8   5.2   6.5   0.4
 3. core-router                                0.0%    10   10.2  10.5   9.8  11.2   0.5
 4. google-edge                                0.0%    10   15.3  15.8  14.9  16.5   0.6
```

**輸出說明:**
- `Loss%`: 丟包率
- `Snt`: 發送封包數
- `Last`: 最後一次延遲
- `Avg`: 平均延遲
- `Best/Wrst`: 最佳/最差延遲
- `StDev`: 標準差

#### 報告模式

```bash
$ mtr -r -c 100 google.com

Start: 2024-01-15T10:30:00
HOST: server                     Loss%   Snt   Last   Avg  Best  Wrst StDev
  1.|-- gateway                   0.0%   100    1.2   1.3   1.0   2.0   0.2
  2.|-- isp-router                0.0%   100    5.5   5.8   5.0   7.0   0.5
```

#### TCP 模式

```bash
$ sudo mtr --tcp -P 80 example.com
```

## iftop

### 命令說明

iftop 即時顯示網路介面的帶寬使用情況。

**基本語法:**
```bash
sudo iftop [options]
```

### 常用選項

| 選項 | 說明 |
|------|------|
| `-i` | 指定介面 |
| `-n` | 不解析主機名 |
| `-N` | 不解析埠名 |
| `-P` | 顯示埠 |
| `-B` | 以位元組顯示 |

### 互動式操作

| 按鍵 | 功能 |
|------|------|
| `h` | 說明 |
| `n` | 切換主機名解析 |
| `s` | 切換來源顯示 |
| `d` | 切換目的顯示 |
| `p` | 切換埠顯示 |
| `P` | 暫停 |
| `t` | 切換顯示模式 |
| `l` | 設定過濾器 |

### 使用場景

1. **帶寬監控**: 即時查看流量
2. **流量分析**: 找出流量大戶
3. **異常檢測**: 發現異常連接

---

### 操作範例

#### 基本使用

```bash
$ sudo iftop -i eth0

                   12.5Kb         25.0Kb         37.5Kb         50.0Kb
└──────────────────┴──────────────────┴──────────────────┴──────────────────
192.168.1.100                    => 203.0.113.50                    1.23Mb  1.00Mb  0.89Mb
                                 <=                                  234Kb   200Kb   180Kb
192.168.1.100                    => 198.51.100.10                   456Kb   400Kb   350Kb
                                 <=                                  123Kb   100Kb    90Kb

────────────────────────────────────────────────────────────────────────────
TX:             cum:   12.3MB   peak:   2.34Mb                  rates:   1.89Mb  1.56Mb  1.34Mb
RX:                    3.45MB            567Kb                           456Kb   400Kb   350Kb
TOTAL:                15.8MB            2.90Mb                          2.34Mb  1.96Mb  1.69Mb
```

**輸出說明:**
- 三列數值: 2秒、10秒、40秒平均值
- `=>`: 發送流量
- `<=`: 接收流量
- `TX/RX/TOTAL`: 總計發送/接收/總流量

#### 顯示埠

```bash
$ sudo iftop -i eth0 -P
```

#### 不解析名稱

```bash
$ sudo iftop -i eth0 -n
```
